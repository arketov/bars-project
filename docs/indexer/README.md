# indexer

Статус: требования · Спека: нет

## Назначение

Находит изменения в документах, режет Markdown на чанки, получает векторы и пишет их в индекс проекта. Первый раз индексирует всё, дальше — только изменившееся.

## Требования

- Сначала полная индексация, потом инкрементальная — `[требование Т-9]`.
- Четыре источника изменений — `[требование Т-10]`.
- Обычный Markdown, заголовок из frontmatter `title` — `[требование Т-11]`.
- Модуль — подпапка первого уровня под корнем, файлы `**/*.md` — `[требование Т-7]`.
- Размер чанка по умолчанию 250–6000 знаков — `[требование Т-18]`.
- Правка раздела не вызывает повторного эмбеддинга неизменившихся чанков — НФТ-1.

## Идеи из образца

Нарезка по заголовкам с дорезкой по абзацам и склейкой мелких. Текст для эмбеддинга «документ + раздел + чанк» с сохранением `embedded_text`. Переиспользование векторов по `embedded_text`. Гейт по хешу файла и модели.

## Уроки образца

1 (CRLF ломал регулярки), 2 (удаление выходило за свою область), 3 (неверный корень → массовое удаление), 5 (переэмбеддинг файла целиком), 6 (слишком мелкие и гигантские чанки).

## Вопросы

OQ-08 (массовое удаление), OQ-10 (черновики), OQ-13 (нарезка).
