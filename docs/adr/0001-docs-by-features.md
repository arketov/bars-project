# ADR-0001. Документация bars по фичам и журнал сессий

- Статус: принято
- Дата: 15-10-2026
- Вопросы: OQ-39…OQ-43, раунд 13 MAIN_IDEA

## Контекст решения о раскладке docs

`docs/` bars была разложена по частям приложения: `indexing`, `storage`, `integrations`, `design`. Автору так неудобно: ТЗ читается по фичам, как в Gramax. Ход работы и причины решений жили в PLAN.md, коммитах и QUESTIONS.md; что не получилось, нигде не записывалось. Заодно автор хочет, чтобы bars советовал такую раскладку другим проектам ([docs-convention](../features/docs-convention/Index.md)), и проверить её на самом bars.

## Решение о раскладке docs

- Фичи — `docs/features/<name>/`: `indexing`, `search`, `models`, `settings`, `projects`, `agent-tools`, `clients`, `window`, `docs-convention`.
- Общее устройство — `docs/architecture/`: стек, компоненты, канал, протокол, воркер, ключи, схема индекса, файлы на диске.
- Решения — `docs/adr/`, начиная с этого. Старые решения остаются в QUESTIONS.md и в документах и в ADR не переносятся.
- База знаний — `docs/knowledge/` без изменений.
- Журнал сессий — `docs/chats/<YYYY-MM-DD>-<тема>/` с `log.md` и `handoff.md`.
- `MAIN_IDEA.md` остаётся одним файлом с требованиями всего проекта и переезжает в `docs/`. У фичи может появиться свой `requirements.md`.
- PLAN.md остаётся общим планом в корне.

## Последствия решения о раскладке docs

- `docs/` больше не совпадает с крейтами и модулями кода: документ ищется по фиче, а не по папке исходников. Комментарии в коде ссылаются на новые пути.
- Модулей поиска стало меньше: `features`, `architecture`, `knowledge`, `adr`, `chats` и корень. Отбор внутри `features` — по папкам и файлам.
- Журнал сессий растёт с каждой сессией и попадает в индекс как модуль `chats`. Если он начнёт мешать поиску или стоить много токенов, это видно по самим журналам — это и есть проверка соглашения.

## Отклонённые варианты раскладки docs

- Тип документа во frontmatter (`kind: log`) вместо папок — не нужно: модули-папки уже дают отбор (OQ-41).
- Журнал на день `chats/<date>/` — две сессии за день писали бы в один файл (OQ-43).
- Разнести требования MAIN_IDEA по фичам — автор оставил MAIN_IDEA целым (OQ-42).
