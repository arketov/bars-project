# Руководство пользователя bars

Как пользоваться bars простыми словами: что сделать, как это работает и какие есть нюансы. Для всех, кто пользуется bars, — и для человека с окном, и для того, кто подключает агента. Технические подробности и контракты живут в `features/` и `architecture/`; руководство ссылается на них, а не заменяет.

## С чего начать пользоваться bars

1. Установите bars (`manual/install.md`) и откройте его.
2. Добавьте проект (`manual/projects.md`) — папку, где лежит `docs/` с Markdown.
3. Дождитесь индексации и ищите (`manual/search.md`).
4. По желанию подключите агента (`manual/agents.md`) — Claude Code или Codex.
