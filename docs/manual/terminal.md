# bars в терминале — основные команды bars-cli

Статус: пересказ простыми словами на 19-10-2026, сверен с [командами bars-cli](../features/agent-tools/cli.md); там же полный список параметров. Те же операции для агентов — [инструменты MCP](../features/agent-tools/mcp-tools.md) и [руководство по агентам](agents.md); то же самое в окне — [поиск](search.md).

## Как запустить bars-cli

`bars-cli.exe` лежит в папке установки bars (по умолчанию `%LOCALAPPDATA%\bars`). Установщик не добавляет её в `PATH`, поэтому либо добавьте папку в `PATH` сами, либо вызывайте по полному пути:

```powershell
& "$env:LOCALAPPDATA\bars\bars-cli.exe" status
```

Если bars не запущен, `bars-cli` запустит его в фоне сам и подождёт до 15 секунд.

## Какой проект использует bars-cli

По умолчанию — проект текущей папки: ближайший зарегистрированный вверх по дереву. Поэтому удобно запускать команды из папки проекта. Как добавить проект — [руководство по проектам](projects.md). Другой проект — флаг `--project <путь или имя>`.

## Как искать и читать документы из терминала

```powershell
bars-cli search "как обновить индекс"
bars-cli search "порог rerank" --module features --limit 3
bars-cli similar 1842-9f3a1c07
bars-cli outline features/search/hybrid-search.md
bars-cli read overview.md
```

- `search` — поиск; `--module` и `--file` сужают область (можно повторять), `--limit` — число результатов, `--min-score` — порог.
- `similar` — похожие фрагменты. Принимает `id` фрагмента: он напечатан под путём каждого результата `search`. `id` действует, пока документ не изменился; после правки документа команда ответит «неизвестен или устарел» — найдите фрагмент поиском заново. `--module` сужает область кандидатов, `--limit` — число результатов. Похожий не значит дубль: прочитайте оба фрагмента.
- `outline` — оглавление документа: строки с номером и заголовком.
- `read` — документ целиком с номерами строк; `read overview.md --lines 10-20` читает диапазон, `--lines 10-` — до конца, `--under "Обзор/Раздел"` — раздел с вложенными и все повторы полной цепочки. Номера строк исходные, часть явно помечена; `--lines` и `--under` вместе недопустимы.

Пути пишутся от папки документации: `overview.md`, а не `docs/overview.md`. Запрос лучше брать в кавычки.

## Как добавить проект и проверить индекс из терминала

```powershell
bars-cli register .
bars-cli projects
bars-cli status
bars-cli reindex
```

- `register [путь]` — добавить проект; без пути — текущую папку.
- `projects` — все проекты и их модули.
- `status` — состояние индекса: готов ли, сколько ждёт, последняя ошибка.
- `reindex` — независимо проверить изменения сейчас; найденное передаётся в очередь обновления. Команда сразу возвращается, работа идёт в фоне; ход смотрите через `status`, отдельный итог проверки — в уведомлениях окна.
- `reindex --full` — перестроить индекс с нуля.
- `reindex --accept-model-change` — ваше согласие на переиндексацию после смены embed-модели. Агенту эту команду давать нельзя.
- `unregister` — убрать проект из bars (индекс в `.bars/` остаётся).

## Подключение агентов и автозапуск из терминала

```powershell
bars-cli install --client claude-code
bars-cli uninstall --client codex
bars-cli install --print-instruction
bars-cli autostart on
```

Подробно — [агенты](agents.md) и [установка](install.md).

## Команды графа связей

`relations`, `paths`, `impact`, `context`, `explore`, `graph show|status|build|cancel` и режимы поиска `--mode hybrid|mix|graph`. Простыми словами — [граф](graph.md).

## Что значат коды выхода bars-cli

| Код | Значит |
|---|---|
| `0` | успех |
| `1` | ошибка в запросе (неверный путь, модуль, параметр) |
| `2` | bars недоступен: не запустился за 15 секунд |
| `3` | проекту нужна переиндексация после смены модели |

Флаг `--json` выводит ответ в машинном виде — тот же, что получает агент. Удобно для скриптов.
