# mcp-proxy

Статус: требования · Спека: нет

## Назначение

`bars-mcp` — маленький stdio-MCP exe. Агентский клиент запускает его на каждую сессию. Прокси пересылает вызовы в общий воркер; если воркер не запущен, запускает его и ждёт готовности.

## Требования

- Отдельный маленький exe, stdio-MCP, запуск воркера при необходимости — `[требование Т-2]`.
- Не держит индекс и не грузит модели — НФТ-3.
- Проект по умолчанию — по cwd сессии, можно указать явно — `[требование Т-15]`.
- Инструменты: поиск; список проектов и модулей; состояние индекса; переиндексация по запросу; чтение документа целиком — `[требование Т-19]`.
- Агент может переопределить числовые параметры в вызове — `[требование Т-18]`.

## Границы

Входит: MCP-протокол, схемы инструментов, проверка и запуск воркера, передача cwd.

Не входит: любая обработка документов.

## Вопросы

OQ-02 (зависимости крейта), OQ-03 (канал), OQ-04 (не живут ли здесь же CLI-команды). Ещё нужно решить, как прокси узнаёт cwd сессии, если клиент запускает его из другой папки.
