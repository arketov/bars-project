## Ограничения поиска и моделей bars

ISS-02 остаётся открытой: порядок без rerank задаётся слиянием кандидатов, а отображаемая оценка — косинусная близость, поэтому проценты могут возрастать вниз по списку. ISS-03 остаётся открытой: слишком низкие оценки rerank на другой машине требуют диагностики именно на ней. ISS-08 — агент в Claude Code может не обращаться к bars; установка интеграции сама по себе этого не гарантирует. Актуальные описания — [issues.md](backlog/issues.md).

Первые замеры качества на небольшом корпусе bars недостаточны для выбора глубины rerank. Более широкий benchmark и ускорение инференса исследуются; исследовательские варианты не означают доступные настройки продукта. Текущие умолчания — [settings.md](features/settings/settings.md); материалы исследований — [knowledge/Index.md](knowledge/Index.md).

## Какие проверки bars ещё открыты

На Windows остаются ручные проверки трея, системного выбора папки, смены модели с согласием, установки интеграций на настоящих профилях, оконного сценария установщика, автозапуска и отказа IPC другому пользователю. Для исправления загрузки моделей нужна проверка с настоящим чистым кэшем; для слежения — реальный поток массовых файловых изменений.

Ускорение поиска при индексации измерялось на доступе к embed-модели; полный путь `search` с SQLite и rerank этим замером не подтверждён. Основание и границы — [search-during-indexing.md](knowledge/search-during-indexing.md).

macOS предусмотрена требованиями, но сборка, CoreML, `.dmg`, нотаризация и LaunchAgent на Mac ещё не проверены. Файловый журнал с ротацией и просмотром в настройках описан в [logs.md](features/window/logs.md).
