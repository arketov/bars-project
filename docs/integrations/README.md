# integrations

Статус: требования · Спека: нет

## Назначение

Прописывает bars в агентских клиентах и кладёт в проекты инструкцию для моделей.

## Требования

- Три пути подключения: CLI, пункт «Установить» в окне, текстовая инструкция для агента — `[требование Т-21]`.
- Установка прописывает MCP-прокси и хук начала сессии в Claude Code и Codex; в любом другом MCP-клиенте прокси работает без хука — `[требование Т-21]`.
- Удаление убирает свои записи и не трогает чужие — критерий приёмки Т-21.
- Регистрация проекта по хуку — `[требование Т-6]`.
- `BARS_INSTRUCTION.md` в корне документации при регистрации — `[требование Т-8]`.

## Решено по умолчанию

`BARS_INSTRUCTION.md` кладётся, только если его нет; не перезаписывается; в индекс не попадает; текст зашит в bars — `[предложение]` (В-16).

## Где пишутся записи

Claude Code: `~/.claude.json` (MCP) и `~/.claude/settings.json` (хук `SessionStart`). Codex: конфиг MCP и `hooks.json`; проектный `.codex/` грузится только для доверенных проектов. Образец — подключение serena.
