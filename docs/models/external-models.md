# Внешние модели bars

Кроме встроенных моделей, embed и rerank подключаются по HTTP (Т-17). Удалённый провайдер и локальный сервер (llama-server, Ollama, vLLM) различаются только адресом и наличием ключа.

## Embed через OpenAI-совместимый API

Запрос `POST <base_url>/v1/embeddings` с телом `{"model": "...", "input": [...]}`. Чанки отправляются пачками; размер пачки задаётся в настройках провайдера. Размерность bars узнаёт по первому ответу и записывает в отпечаток модели.

## Rerank через API в формате Cohere

Запрос `POST <base_url>/rerank` (или `/v1/rerank`) с телом `{"model": "...", "query": "...", "documents": [...], "top_n": N}`. Так отвечают routerai, Cohere, llama-server с `--reranking`.

## Ключи внешних провайдеров

Ключ хранится в хранилище ОС, а не в настройках: см. [architecture/secrets.md](../architecture/secrets.md). Для локального адреса ключ не нужен.

## Ошибки внешнего провайдера

- Индексация: при сетевой ошибке или ответе 5xx — до трёх повторов с паузой; если не помогло, документ остаётся в очереди, и состояние индекса показывает ошибку. Уже проиндексированное не трогается.
- Поиск: если embed недоступен, поиск возвращает ошибку с причиной. Если недоступен только rerank, выдача возвращается без реранка и с пометкой об этом.
