# models

Статус: требования · Спека: нет

## Назначение

Даёт индексатору и поиску векторы и оценки реранка из выбранного источника.

## Требования

- В настройках приложения: embed-модель, rerank-модель, включён ли rerank, числовые параметры — `[требование Т-16]`.
- Три способа подключить embed: удалённый провайдер; встроенная модель через fastembed-rs; внешний локальный OpenAI-совместимый адрес — `[требование Т-17]`.
- Конкретную встроенную модель выбирает автор — `[требование Т-17]`.

## Решено по умолчанию

- Модель записана в индексе; при несовпадении — полная переиндексация, которую видно в окне и в состоянии индекса — `[предложение]` (MAIN_IDEA, «Решение»).
- Ключи провайдеров — в настройках приложения, не в `.bars` — `[предложение]`.

## Уроки образца

4 (смена модели делает векторы несравнимыми), 12 (токен открытым текстом рядом с exe).
