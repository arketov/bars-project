# Гибридный поиск

Как воркер отвечает на поисковый запрос (Т-12…Т-15, Т-18, Т-24, Т-25). Все числа ниже — значения по умолчанию из Т-18; их меняют настройки и вызов агента.

## Область поиска

1. **Проект.** Явно заданный проект или проект сессии: ближайшая к cwd агента папка, которая зарегистрирована в bars (Т-15). Поиск никогда не выходит за один проект (урок 9 образца).
2. **Отбор внутри проекта.** Список модулей и/или файлов (Т-14). Пустой список — весь проект.
3. **Состояние проекта.** Если проекту нужна переиндексация из-за смены модели, поиск возвращает ошибку «нужна переиндексация» и ничего не ищет (Т-25).

## Кандидаты из двух поисков

- **Полнотекстовый:** FTS5 по цепочке заголовков и тексту чанков, ранжирование `bm25`, первые 30. Запрос разбивается на слова, и каждое слово ищется и целиком, и как префикс (`слово*`) — это частично заменяет русскую морфологию, которой у FTS5 нет.
- **Векторный:** запрос эмбеддится моделью проекта (с префиксом запроса, если он у модели есть); точный перебор в sqlite-vec по косинусной близости, первые 30 ([architecture/vector-search.md](../architecture/vector-search.md)).

Оба списка сливаются через Reciprocal Rank Fusion: оценка кандидата — сумма `1 / (60 + место)` по спискам, где он есть. Точное совпадение идентификатора поднимается полнотекстовым поиском, смысловое — векторным (Т-12).

## Реранк кандидатов

Если rerank включён, слитые кандидаты (до 30) переоцениваются rerank-моделью, и выдача упорядочивается по её оценке. По умолчанию возвращается 3 результата. Без реранка — 5 по RRF.

## Оценка результата и порог

Порог применяется к оценке, у которой есть абсолютный смысл. Оценка RRF его не имеет:

- **С реранком** — оценка реранка, порог `min_score_rerank`.
- **Без реранка** — косинусная близость чанка к запросу, порог `min_score_vector`. Близость считается для всех кандидатов, включая найденных только полнотекстовым поиском.

Порог задаёт пользователь в настройках, там же — пределы, в которых его может менять агент (Т-24). Порог агента вне пределов прижимается к ближайшей границе, и в ответе сказано, какой порог применён.

## Состав результата

Каждый результат (Т-13): путь, модуль, `title` документа, цепочка заголовков, строки начала и конца, текст чанка, оценка и её вид (`rerank` или `cosine`). Ответ в целом несёт применённые параметры, флаг «идёт индексация» и число документов в очереди. Текста, сгенерированного LLM, в ответе нет.
