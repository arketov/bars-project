# search

Статус: требования · Спека: нет

## Назначение

Ищет по индексу проекта: полнотекстовый и векторный поиск, слияние в один ранжированный список, реранк, если он включён.

## Требования

- Гибридный поиск, слияние, затем реранк — `[требование Т-12]`.
- Результат: фрагмент, путь, модуль, заголовок раздела, оценка; ответа LLM нет — `[требование Т-13]`.
- Фильтр по выбранным модулям и файлам; пустой выбор — весь выбранный проект — `[требование Т-14]`.
- Проект по умолчанию — проект сессии — `[требование Т-15]`.
- По умолчанию: 30 кандидатов на реранк; 5 результатов без реранка, 3 с реранком; агент может переопределить — `[требование Т-18]`.
- Меньше 1 с на 5 000 чанков без реранка на CPU — НФТ-2, проверяется на прототипе.

## Уроки образца

7 (размерность исключила ANN), 8 (шум в хвосте выдачи без порога), 9 (пустой фильтр захватывал чужие проекты), 10 (черновики наравне с актуальными).

## Вопросы

OQ-09 (порог), OQ-10 (черновики), OQ-11 (перебор или ANN). Ещё нужно выбрать способ слияния (RRF или взвешенная сумма) и решить, как FTS5 справится с русской морфологией.
