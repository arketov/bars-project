# Первый запуск bars — установка, проект, поиск и MCP

Статус: инструкция по текущим интерфейсам на 18-10-2026; команды сверены с CLI, весь сценарий установки в этой сессии не запускался.

## Установка и запуск bars на Windows

Установщик Windows содержит `bars.exe`, `bars-cli.exe` и `bars-mcp.exe`. Откройте установленный bars через ярлык: появятся окно и иконка в трее. Закрытие окна оставляет воркер работающим; завершение — через «Выход» в трее.

Команды примеров выполняются в PowerShell из папки проекта. Если `bars-cli` не доступен через `PATH`, используйте полный путь к установленному `bars-cli.exe` с оператором `&`. Состав поставки и сборка установщика из исходников — [installer.md](features/distribution/installer.md). Статус macOS — [project-status.md](project-status.md).

## Регистрация документации проекта в bars

Подготовьте папку проекта с Markdown-документами в `docs/`. В окне добавьте именно корень проекта. Для другого расположения документации выберите корень документации в настройках проекта. CLI-вариант для текущей папки:

```powershell
bars-cli register .
bars-cli status
```

Регистрация ставит проект в очередь проверки; готовность смотрите в окне или `status`. Встроенной модели при первом использовании понадобятся скачивание и загрузка. Состояние `model_loading` означает, что модель ещё готовится; повторите поиск после окончания загрузки. Устройство регистрации — [projects.md](features/projects/projects.md), состояния — [worker.md](architecture/worker.md).

## Поиск и чтение документов через bars-cli

```powershell
bars-cli search "как устроено обновление индекса"
bars-cli outline Index.md
bars-cli read overview.md
```

`Index.md` и `overview.md` в примере относятся к документации самого bars; для другого проекта подставьте существующие Markdown-файлы. Поиск возвращает фрагменты с путём, заголовком, строками и оценкой. `outline` показывает структуру, `read` — полный текст с номерами строк. В окне те же действия начинаются с выбора проекта и ввода запроса.

Для явного выбора проекта используйте `--project <путь>`, для отбора — `--module <имя>` или `--file <путь>`. Пути фильтра файлов считаются от корня документации. Все команды и параметры — [cli.md](features/agent-tools/cli.md), смысл оценки — [hybrid-search.md](features/search/hybrid-search.md).

## Подключение bars к агенту через MCP

Пользователь подключает нужный клиент в окне bars или командой:

```powershell
bars-cli install --client codex
# Для Claude Code вместо codex укажите claude-code.
```

Установка добавляет MCP-сервер, хук начала сессии и skills bars. В Codex пользователь одобряет новый или изменённый хук командой `/hooks`; MCP доступен и без одобренного хука, но проект тогда регистрируется окном или CLI. Другой stdio-MCP-клиент можно настроить вручную. Форматы записей и пути — [clients.md](features/clients/clients.md).

Агент начинает с `bars_rag_search`, затем уточняет структуру через `bars_outline` и читает нужный документ через `bars_read`. Список проектов и модулей — `bars_projects`, состояние — `bars_status`. Если выбор проекта по рабочей папке неоднозначен, укажите `project` явно. Параметры инструментов — [mcp-tools.md](features/agent-tools/mcp-tools.md).

## Проверка актуальности индекса bars

Изменения `.md` подхватывает слежение; защитная периодическая проверка выполняется раз в 15 минут. Для проверки сейчас нажмите «Проверить сейчас» у проекта или выполните:

```powershell
bars-cli reindex
bars-cli status
```

`reindex` без `--full` проверяет изменения инкрементально и возвращается до окончания работы. Во время индексации выдача может быть неполной. При `reindex_required` после смены embed-модели пользователь подтверждает перестроение в окне; агент не обходит `reindex_needs_consent`. Подробности — [updates.md](features/indexing/updates.md), [protocol.md](architecture/protocol.md).

## Если bars не находит документ

Проверьте выбранный проект, модуль и файл; затем состояние индекса, очередь и `last_error`. Файл должен быть Markdown под настроенным корнем документации и читаться как UTF-8. Исключения обхода перечислены в [updates.md](features/indexing/updates.md). Уменьшение порога поиска и включение rerank меняют выдачу; параметры описаны в [settings.md](features/settings/settings.md).

Известные дефекты и доступные обходы — [issues.md](backlog/issues.md). Пустая выдача сама по себе не доказывает отсутствие сведений: проверьте индекс и прочитайте оглавление документации.
