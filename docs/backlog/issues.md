# Известные проблемы bars

Баги, найденные автором при использовании. Открытые описаны отдельными разделами; исправленные сведены в таблицу «Исправленные проблемы» в конце: причина, проверки и коммит остаются в документах фич, `docs/chats/` и git. Проблема считается исправленной, когда реализация и автоматические проверки готовы, даже если осталась только приёмка в установленной сборке. Новые записи дописываются с номером ISS-NN подряд.

Открытых проблем нет.
