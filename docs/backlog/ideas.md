## IDEA-18: Подключённая документация — ссылки на git и другие проекты bars

- [ ] Сделано
- Источник: автор, 19-10-2026.

Автор: «Запиши идею после реализации гита. Можно в модули или подмодули ложить мета ссылки на гит или на другие проекты bars. Разумеется только чтение. И индексация после обновления с гита или раз в час к примеру. Не все функции работают с дочерними документациями. Надо ещё название фичи придумать чтоб лего искать было».

Суть: в модуль или подмодуль документации кладётся метассылка — на git-репозиторий или на другой проект bars. Подключённая («дочерняя») документация доступна только для чтения. Индекс обновляется после получения изменений из git или по расписанию, например раз в час. Не все функции работают с дочерней документацией: какие работают, а какие нет, надо определить при сборе требований. Идёт после IDEA-16 (git из bars). Требований нет; название выбрано автором 19-10-2026: «Подключённая документация» (OQ-101).
