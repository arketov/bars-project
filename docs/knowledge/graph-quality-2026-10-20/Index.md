# Независимая оценка GraphRAG 20-10-2026

Статус: исследование пункта 12 завершено; результаты и порядок исправлений — в исходном исследовании (`knowledge/graph-research.md`). GraphRAG качественную приёмку не прошёл. Снимок: 66 документов, 503 чанка, 2587 проверенных source spans. Продуктовые алгоритмы не изменены.

## Протокол до прогона

Корпус — согласованная read-only копия существующего SQLite и соответствующих Markdown. Исключаются журналы, исследования, документы GraphRAG, инструкции агентам и оглавления: они могут содержать формулировки прежних проб. Тексты и векторы не переиндексируются. Файлы, не совпавшие с индексированной ревизией, исключаются до разметки; исключения сохраняются.

Gold размечается по первичным текстам до просмотра результатов нового запуска. Единица — необходимый исходный фрагмент, допустимые альтернативы, направленный факт/условие либо ожидаемое воздержание. Development и holdout разделяются по размечаемым документам; они находятся в одном retrieval-корпусе. Часть первичных документов уже участвовала в прежней development-пробе: это holdout новых вопросов/разметки, **не невиданный корпус**. Независимость означает независимость разметки от выдачи данного раунда, а не независимого человека-рецензента. Один агент размечает и проверяет; это ограничение исследования.

До первого запуска исправлена методика: первоначальный `gold.json` использовал сокращённые query в context/relations. Финальный `gold-matched.json` передаёт туда дословный вопрос baseline; paths/impact используют заранее размеченные endpoints/roots, поскольку эти операции не принимают такой query. Добавлены четыре точечных контроля. Финальный SHA-256: `abc706e3ba6aec611bbeb72f6fbaa5f0d7b773eede5e1ed3be542044915766e5`. По первому набору замеры не выполнялись.

Набор покрывает S1–S8, positive/negative/conditional. Отсутствие факта в закрытой области не переносится на весь проект. Ожидаемые пути размечаются по исходным утверждениям; гиперссылки и similarity не засчитываются как смысловые зависимости.

Сравнения: штатный hybrid FTS/vector/RRF, увеличенные candidates/top-K, структурные ссылки, штатное расширение mix и операции графа. Одинаковые корпус, вопрос, модель запроса, scope и предел **16 KiB UTF-8 нормализованного пакета источников** (текст, пути/диапазоны и причины включения). min_score=0; defaults библиотеки, не настройки установленного профиля. Rerank отключён во всех сравниваемых вариантах; отдельная проверка качества rerank в этот раунд не входит. Query embedding — существующая FP32 bge-m3 на DirectML EP, без скачивания/переиндексации и смены EP на CPU. Векторы запросов сохраняются для повтора без модели. DTO GraphReply ограничен отдельно (262144 bytes); это другой бюджет. Полный путь и доказательства relation атомарны; дополнительные evidence роли/темы можно сокращать по целым цитатам.

Метрики: evidence recall/precision, полный набор источников, Hit@3 точечных контролей; отдельно точность участников/предиката/направления, полнота условий, цепочки, роли, актуальность решений, темы и структурный аудит. Source span сверяется с замороженными байтами. Пустые знаменатели — N/A, не 100%. Ресурсные времена — описательные, не SLA.

Пороги из `implementation.md` сохраняются без подгонки. При провале вывод — фича не принята, с конкретными потерянными источниками и предложением исправлений для следующего этапа. Продуктовые контракты не сокращаются под результат.

## Воспроизведение

Исходники стенда: заморозка, разметка, Rust driver, оценщик, проверка оценщика, ручные вердикты.

Распаковать gzip из таблицы в **новую изолированную папку** с исходными именами без `.gz`. Не подменять `.bars` проекта. Сборка: `cargo build --release -p bars-core --example graph_quality --offline -j 2`, с настроенной штатной Windows/MSVC/Vulkan средой проекта. Для повтора без модели:

```text
graph_quality.exe run <snapshot> <gold-matched.json> <несуществующая-папка-моделей> <новый-results.json>
node scripts/graph-quality-analyze.mjs <snapshot> <gold-matched.json> <новый-results.json> <новый-analysis.json.gz>
```

Сохранённые query vectors обязательны; без них запуск требует локальный FP32-кэш BAAI/bge-m3 и Windows/DirectML. Повтор после переноса папки и после `VACUUM` копии воспроизвёл все 36 пакетов и сводки. Для нового раунда: новый snapshot/gold, не переиспользовать просмотренный holdout как независимый. После публикации графа архивируемую SQLite-копию уплотнить `VACUUM`, чтобы в свободных страницах не осталось исключённых старых строк.

Подтверждено: 23 существующих source/acceptance теста `bars-graph`; проверка оценщика (UTF-8, роли, атомарный budget, пустой знаменатель, отказ при повреждённой цитате); успешная release-сборка и настоящий локальный query embedding. Сбой промежуточной сборки из-за отсутствия места C: и остановленный сетевой загрузчик описаны в журнале (`chats/2026-10-20-graph-quality/log.md`), не скрыты за итоговым успехом.
