# Данные исследования определения железа

| Файл | Когда читать |
|---|---|
| `windows-runs.jsonl` | Двадцать отдельных запусков Windows Rust-спайка, API-значения и времена в микросекундах |
| `independent.json` | Версия ОС, CPU, WMI/NVIDIA-сверка, Rust и SHA-256 исходника, manifest, lock и бинарника |
| `timing-summary.json` | Min, медиана, nearest-rank p95 и max стадий в миллисекундах |
