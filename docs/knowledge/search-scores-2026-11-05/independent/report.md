# Независимая проверка весов схемы баллов 05-11-2026 — отчёт второго аналитика

Расчёт по тому же [дампу](../Index.md) выполнил отдельный агент своим конвейером (`common.mjs`): его сверка с основным (`check.mjs`) совпала до знака (RRF → rerank 65 / 88 / 0,763, старт 68 / 86 / 0,774, без rerank 69 / 86 / 0,779). Разбор основного сеанса — в [исследовании схемы баллов](../../search-scores.md), раздел «Замер 2.3.7». Метрики везде: первым / Hit@3 / MRR@10.

**Вывод:** весов лучше стартовых агент не нашёл — на запросах, которых подбор не видел, все найденные варианты не лучше старта. Менять стоит только порог с rerank: 0,1 → 0,2. Приёмку против RRF в строгой форме не проходит ни одна схема, включая старт.

## Перекрёстная проверка

Δ MRR — выбранная схема минус старт на проверочных запросах:

| Сетка | Нечётные → чётные | Чётные → нечётные | Выбор по 4 проектам, проверка на пятом | 200 случайных делений пополам |
|---|---|---|---|---|
| rerank, 756 схем | −0,007 | −0,022 | −0,011 | −0,016, хуже старта в 170 из 200 |
| rerank, K от 10 до 30 | −0,001 | −0,024 | −0,008 | −0,009, хуже в 141 из 200 |
| без rerank | −0,033 | 0 | −0,008 | −0,016, лучше ни разу |
| 8 вариантов, названных заранее | +0,005 | +0,001 | ≈ 0 | +0,0005 (5–95 %: −0,008 … +0,010) |

На обучающей половине выбранная схема выглядит лучше старта в среднем на +0,020 — подгонка под шум. Лучшая схема на всех 168 сразу (`w_c` 0,1, `w_p` 0,05) даёт 0,791 (Δ +0,009 [−0,001; +0,022]), но это максимум из 756 на тех же данных.

## Порог θ

| 0,3 | 7 % | + `ag-14` | 0,766 |
| 0,35–0,5 | 4–6 % | 4 запроса | 0,751–0,754 |

Точность низкая: 5 из 54 дают 95 % интервал Уилсона 4–20 %; на чётной половине 3 из 25 (12 %). Ложными остаются `bn-24`, `bn-32`, `bn-34`, `od-081`, `od-084`. По максимальной оценке rerank запросы с ответом и без разделяются хорошо (AUC 0,99). Без rerank порог по косинусу не работает: до 0,3 не режет ничего, 0,45 — 74 % ложных при 1 потере, 0,55 — 35 % при 10 потерях, 0,6 — 15 % при 27 потерях. Медиана максимума косинуса у запросов без ответа 0,53, у 5 % запросов с ответом максимум ниже 0,56.

## Рекомендация и приёмка

| Вариант | Все 168 | Чётные | Ложные |
|---|---|---|---|
| RRF → rerank, θ 0,1 (база приёмки) | 65 / 88 / 0,763 | 61 / 89 / 0,749 | 17 % |
| старт, θ 0,1 | 68 / 86 / 0,774 | 65 / 86 / 0,755 | 15 % |
| **рекомендация: старт, θ 0,2** | 68 / 86 / 0,773 | 65 / 86 / 0,755 | **9 %** |
| опция: K = 25, θ 0,2 | 69 / 88 / 0,784 | 67 / 89 / 0,777 | 9 % |

Против RRF на всех 168 рекомендация даёт Hit@3 −5 (`bp-28 bp-36 bp-38 ob-20 ob-35`) / +3 (`rg-05 bp-10 bp-27`), тест знаков p = 0,73; первым −6 / +12; Δ MRR +0,010 [−0,020; +0,039]. Нарушены: в целом Hit@3 −1,2 п.п.; группы «синонимы» (`bp-38`, место 2 → 4) и «агентские запросы»; bars-project (−2,4 п.п.) и overdrive-bots (−5 п.п.). На чётной половине −4 / +1 по Hit@3. `K` = 25 против RRF: Hit@3 −3 (`bp-38`, `ob-20`, `ob-35`) / +4, Δ MRR +0,021 [−0,010; +0,052], нарушены только «синонимы» и overdrive-bots. Без rerank `c + 0,1·f + 0,1·p` против RRF: Hit@3 −3 (`bp-32`, `ob-08`, `ob-36`) / +6, Δ MRR +0,027 [−0,001; +0,058]; нарушены «синонимы» (MRR −0,024) и tmc-opovechenie («первым» −8,3 п.п.).

Из 600 схем (окно по `S0` или по RRF × `K` 15–30 × `w_c` × `w_f` × `w_p`) строгую приёмку против RRF проходят две — случайность на тех же данных; группу «синонимы» валит один запрос `bp-38`, на нём проваливаются 572 схемы из 600.

## Ограничения

Стартовые 0,1 / 0,1 выбраны опытами 03-11-2026 на этих же 168 запросах, перевес над RRF отчасти завышен; ни одна разница между стартом и RRF не значима (интервалы MRR содержат 0, тесты знаков p ≥ 0,3); 54 запроса без ответа дают долю ложных с точностью ±8 п.п.; кривая порога по косинусу верна только для embed-модели дампа. Стоимость `K` = 25: rerank дороже в 1,67 раза (по дампу около 4,5 → 7,5 с на запрос на iGPU).
