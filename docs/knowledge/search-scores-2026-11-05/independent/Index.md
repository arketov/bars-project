# Независимая проверка схемы баллов 05-11-2026

Расчёт по [дампу замера 2.3.7](../Index.md) отдельным агентом: собственный конвейер, перекрёстная проверка, бутстрап, порог, варианты вне сетки. Запуск скриптов — `node <файл>.mjs`, пути к дампу заданы в `common.mjs`; `lib.mjs` — копия `../scripts/lib.mjs`.

| Файл | Когда читать |
|---|---|
| `report.md` | итог независимой проверки: перекрёстная проверка, варианты вне сетки, порог, рекомендация и приёмка |
| `final.out.md` | таблицы «RRF / старт / рекомендация / K = 25» по группам и проектам, нарушения правила приёмки поимённо, тест знаков и бутстрап |
| `cv.out.md` | перекрёстная проверка выбора весов: половины, проекты, случайные деления |
| `variants.out.md` | варианты вне сетки: окно rerank, нормирование `f` и `p`, `w_c`, идентификаторы |
| `theta.out.md` | кривые порога с rerank и с косинусом, доверительные интервалы |
| `lib.mjs`, `common.mjs`, `check.mjs`, `cv.mjs`, `variants.mjs`, `theta.mjs`, `final.mjs`, `links.mjs` | скрипты расчётов; `check.mjs` сверяет конвейер с основным выводом |
