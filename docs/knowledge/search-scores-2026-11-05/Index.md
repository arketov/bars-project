# Данные замера схемы баллов 05-11-2026 (шаг 2.3.7)

Данные и скрипты к [исследованию схемы баллов](../search-scores.md), раздел «Замер 2.3.7». Дамп снят одним прогоном `bench_quality dump` с настоящими моделями (bge-m3, bge-reranker-v2-m3): по каждому запросу весь пул кандидатов со всеми сырыми сигналами, rerank оценил весь пул. По дампу веса, порог и сравнение с RRF считаются без моделей за секунды (`scripts/tune.mjs`). Тексты чанков в дамп не входят; пути и заголовки есть только у bars-project, у остальных проектов — номера документов и разделов и имя модуля.

## Как воспроизвести

Снять дамп повторно можно только с моделями и сборкой `bench_quality` (одна сессия на свободном ПК): `scripts/setup.mjs` готовит каталоги, `bench_quality dump <каталог> <набор.json> <модели> <файл.jsonl> auto <метка> [paths]` пишет строки. Рабочие каталоги (`.bars/bench-237/`, копии индексов около 700 МБ) в репозиторий не входят и после замера удалены. Подбор из готового дампа: `node scripts/tune.mjs dump . all > results.md`.
