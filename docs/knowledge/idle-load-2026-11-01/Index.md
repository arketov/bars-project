# Доказательства фоновой нагрузки bars 01–02-11-2026

| Файл | Когда читать |
|---|---|
| `passive-1.json` | Семь пассивных снимков CPU, логического I/O, памяти и общесистемного физического диска |
| `summary.json` | Расчёт нагрузки bars и список параллельных компиляторов |
| `provenance.json` | SHA-256 бинарников, checkout, PID, родительские процессы и ограничения вмешательства |
| `sample-log.json` | События worker в интервале пассивной серии |
| `status-1.json` | Активные задания графа четырёх проектов после серии |
| `stacks.json` | Пять стеков горячего потока в публикации графа |
| `sql-schema.json` | Схема, триггеры, число объектов, длины TEXT и планы DELETE двух рабочих индексов; без содержимого документов |
| `synthetic.json` | Сравнение 100 удалений с большими/малыми метаданными и rowid-таблицей |
| `checkpoint-v2.jsonl` | Парные повторы v1/v2: DELETE, миграция, вся публикация и последующее чтение на bundled SQLite; CPU, логический I/O и память |
| `checkpoint-v2-provenance.json` | SHA-256 бинарника стенда, настройки SQLite и границы изолированных опытов |
| `idle-stack.ps1` | Метод снимка стека; PID/TID относятся к наблюдаемому процессу, возобновление в finally |
| `idle-db.cjs` | Read-only получение структуры индексов, размеров и планов SQL |
| `idle-synthetic.cjs` | Искусственная база и триггер; данные проектов не копируются |
| `idle-synthetic.ps1` | Запуск трёх конфигураций и процессные I/O-счётчики; временные базы только в `.bars/` checkout |
