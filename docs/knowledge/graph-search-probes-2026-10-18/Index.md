# Пробы текущего поиска для сценариев GraphRAG 18-10-2026

← База знаний (`knowledge/Index.md`) · Выводы по пробам (`knowledge/graph-research.md`)

Три качественных read-only запроса обычного `bars_rag_search` для сценариев S1, S3 и S6. Это форма нынешней выдачи, а не сравнительный бенч GraphRAG: корпус не заморожен, независимой разметки нет. В списке файлов и в записи «первой попытки» названы исследования графа в прежних именах; со временем они слиты в `graph-research.md`.

| Файл | Когда читать |
|---|---|
| `probes.json` | Дата, область (явный список файлов), параметры вызова, выдача по каждому из трёх сценариев и запись о первой неудачной попытке по всему проекту |
