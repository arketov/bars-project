# Пробы текущего поиска для сценариев GraphRAG 18-10-2026

[← База знаний](../Index.md) · [Выводы по пробам](../graph-research.md#наблюдения-текущего-поиска-на-сценарных-запросах)

Три качественных read-only запроса обычного `bars_rag_search` для сценариев S1, S3 и S6. Это форма нынешней выдачи, а не сравнительный бенч GraphRAG: корпус не заморожен, независимой разметки нет. В списке файлов и в записи «первой попытки» названы исследования графа в прежних именах; со временем они слиты в [graph-research.md](../graph-research.md).

|---|---|
