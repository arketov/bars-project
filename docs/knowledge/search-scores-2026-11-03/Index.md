# Данные опытов схемы баллов

Метод, выводы и рекомендации — [search-scores.md](../search-scores.md). Здесь — скрипты на node и результаты без текстов закрытых проектов (tmc-opovechenie, firetech): в `exp*.json` только номера запросов, ранги и агрегаты; в `exp*.txt` — таблицы метрик и номера запросов. Запросы, эталоны, копии индексов и выдачи CLI читаются из `%USERPROFILE%\.bars\bench\` (вне репозитория), нужен `node` 24; ничего не собирается и пакеты не ставятся (стемминг — `search-bench-2026-11-03/scripts/stem.mjs`). Запуск из `scripts/`: `TOK_NPM=$PWD node expN.mjs > ../expN.txt`, затем `mv expN.json ..`; `TOK_NPM` нужна только как абсолютный путь для общего `lib.mjs` токенизации.

| Файл | Что внутри |
|---|---|
| `scripts/feat.mjs` | загрузка копий индексов, FTS5 с четырьмя колонками, пул кандидатов, признаки: баллы колонок, покрытие, фраза |
| `scripts/exp1.mjs`, `exp1.txt`, `exp1.json` | сумма отдельно нормированных полей против одного составного bm25; нормирования rrf, rank10, max, saturation, z-score |
| `scripts/exp2.mjs`, `exp2.txt`, `exp2.json` | составной bm25 + покрытие + фраза; сумма rerank и FTS на выдачах `cli-full.json` против RRF; порог по оценке rerank; свёртка кусков раздела |
| `scripts/exp3.mjs`, `exp3.txt`, `exp3.json` | абсолютная шкала полнотекстового балла (доля идеального bm25), порог без rerank, сумма с rerank |
