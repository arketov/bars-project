# Сырые данные исследования поиска противоречий (3.8.1)

← База знаний (`knowledge/Index.md`) · Выводы (`knowledge/contradictions.md`)

Снимок 22-10-2026. Воспроизведение — `scripts/contradictions-probe.mjs`: `export` выгружает чанки индекса (векторы не сохранены), `run` и `dump` ищут кандидатов, `history` разбирает правки утверждений в git, `evalset` строит наборы оценки, `report` считает метрики. NLI запускалась `scripts/contradictions-nli.mjs` (модель и npm-пакет лежат вне репозитория; `mDeBERTa-v3-base-xnli`, 8-битная, оба направления пары, максимум вероятности «противоречие»). JSON.gz распаковывается стандартным gzip.

| Файл | Когда читать |
|---|---|
| `corpus/snapshot.json.gz` | Тексты 1 497 чанков снимка, из которых строились все наборы |
| `hand-pairs.json` | 40 пар, написанных агентом: 20 противоречий и 20 согласованных |
| `analysis/run-stat.json` | Число утверждений, кандидатных пар и отметок по видам |
| `analysis/flagged.json` | 145 пар, отмеченных правилами на корпусе, с путями и строками |
| `analysis/history-edits.json` | 1 118 пар «прежняя и новая формулировка» из истории git |
| `analysis/hand.*.json`, `seeded.*.json`, `real.*.json` | Входы (`in`) и ответы NLI (`nli`) трёх наборов |
| `analysis/real.rows.json` | 726 кандидатных пар корпуса по убыванию вероятности NLI |
| `analysis/report.json` | Метрики по наборам и построчные результаты ручных и засеянных пар |
