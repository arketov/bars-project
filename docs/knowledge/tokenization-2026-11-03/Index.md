# Данные опытов токенизации

Метод, выводы и рекомендация — [tokenization.md](../tokenization.md). Здесь — скрипты и метрики без текстов закрытых проектов (tmc-opovechenie, firetech): в `exp*.json` только номера запросов, ранги и агрегаты. Запросы и эталоны читаются из `%USERPROFILE%\.bars\bench\` (вне репозитория), нужен `node` 24; ничего не собирается. Пакеты `snowball-stemmers`, `az`, `tinyld`, `franc-min`, `@node-rs/jieba` ставятся во временную папку, путь — переменная `TOK_NPM`.

| Файл | Что внутри |
|---|---|
| `scripts/lib.mjs` | загрузка копий индексов, эталон, метрики бенча, поимённые потери и приобретения |
| `scripts/analyzers.mjs` | токенизаторы: Snowball, правила, префикс, лемма `az`, формы идентификаторов, camelCase, Дамерау—Левенштейн, построитель FTS5-варианта |
| `scripts/exp1.mjs`, `exp1.json` | стемминг, правила, префикс, лемма, стоп-слова: 168 запросов |
| `scripts/exp2.mjs`, `exp2.json` | две колонки, поля, веса, trigram, множитель покрытия |
| `scripts/exp3.mjs`, `exp3.json`, `exp3.txt` | опечатки: настоящие и синтетические, словарь и триграммы |
| `scripts/exp4.mjs`, `exp4.json`, `exp4.txt` | сборка приёмов, таблицы по группам и проектам, списки потерянных и выигранных запросов |
| `scripts/lang.mjs`, `lang-detect.txt` | определение языка: письменность, tinyld, franc-min |
| `scripts/cjk.mjs`, `cjk.txt` | CJK на синтетическом корпусе: unicode61, trigram, биграммы, ICU, jieba |
| `scripts/size.mjs`, `size.txt` | размер и время построения FTS-индекса: база, четыре колонки, trigram |
