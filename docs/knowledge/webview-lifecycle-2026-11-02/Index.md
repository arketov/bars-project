# Данные исследования WebView2 3.6.1

| Файл | Когда читать |
|---|---|
| `metrics.ps1` | Счётчики дерева процессов и видимость нативного окна; проверка принадлежности перед показом/скрытием |
| `installed.ps1` | Три чередующихся серии рабочего экземпляра, восстановление исходной видимости, события отказов и версии Runtime |
| `measure.mjs` | Изолированный CDP-стенд: серии без обёрток, таймеры до загрузки UI, IPC, кадры, physics worker |
| `instrument.js` | Обёртки измерителя главного WebView; счётчики и стеки регистрации без содержимого документов |
| `summarize.mjs` | Пересчёт CPU по PID+времени старта, группировка серий, разности счётчиков таймеров и IPC |
| `installed.json` | Шесть серий рабочего bars: CPU/чтения/память по ролям и восстановление скрытой видимости |
| `isolated.json` | Двенадцать серий собственного WebView: исходные счётчики, IPC, таймеры, кадры, Runtime и проверка отказа |
| `metadata.json` | Машина, хеши исходников/сборки UI, пустые результаты Application/Crashpad и версии Runtime |
| `summary.json` | Пересчитанные результаты; создаётся `summarize.mjs` из двух файлов исходных серий |
| `cpu-visible.cpuprofile` | Отдельная 10-секундная выборка стека главного JS-потока видимого стенда |
| `cpu-hidden.cpuprofile` | Отдельная 10-секундная выборка стека главного JS-потока скрытого стенда |
| `fault.json` | Повтор только browser-crash: отдельная проверка каждого заранее сохранённого PID+времени старта независимо от родства |
| `fault-incomplete.json` | Незавершённый промежуточный повтор: после browser-crash helper не нашёл native PID; не доказательство причины выхода |
