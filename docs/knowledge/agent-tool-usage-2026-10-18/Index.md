## Воспроизведение анализа

Из корня репозитория: `node docs/knowledge/agent-tool-usage-2026-10-18/analyze.cjs`. Node 24.16.0; вход по умолчанию — `USERPROFILE`, альтернативный корень — первый аргумент. Читаются только `.codex/sessions`, `.codex/archived_sessions`, `.claude/projects`. Запись — только соседний `evidence.json`; логи и настройки клиентов не изменяются.

Повтор на дописываемых логах меняет размеры и хэши префиксов. Числа событий до границы должны совпасть, пока клиент не переписал историю. Первичный evidence содержит агрегаты и метаданные без запросов и документов; ручной разбор добавляет выбранные аргументы и оценки, текущие пробы — короткие выдержки выдачи. Полные логи, документы и ответы не копируются.

Ручные оценки не генерируются анализатором: для проверки читать строки задачи/вызова/следующего действия из chain-review. Пробы воспроизводятся по записанным args; текущая документация меняется, поэтому новая выдача может отличаться. Совпадение updated_at до/после окончательного триплета зафиксировано; исторический индекс не восстанавливался.
