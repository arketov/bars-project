# Данные замера выбора модулей агентом 24-10-2026

| Файл | Когда читать |
|---|---|
| `summary-test.json` | Сводка проверочной части: сравнения B−A, C−A, D−A по обоим проектам и вместе, режимы с rerank (K15) и без него (K0), решение по порогу |
| `summary-tune.json` | Та же сводка для подбора; по ней проверялся конвейер, решение по ней не принималось |
| `per-question.json` | Hit@3 и MRR@10 каждого вопроса по вариантам A–D в обоих режимах, модули эталонов вопроса |
| `configs.json` | Контрольные суммы наборов вопросов, манифестов снимков и сборки бенча для каждого из 16 запусков |
