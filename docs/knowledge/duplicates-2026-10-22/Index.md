# Сырые данные независимой разметки дублей get_duplicates

Снимок 22-10-2026. Выводы — [duplicates.md](../duplicates.md), раздел «Независимая разметка на настоящих корпусах». Воспроизведение — `scripts/duplicates-labeling.mjs`: `pairs` считает метрики кандидатов по копии индекса, `sample` строит слепую выборку, `agree` — согласие разметчиков, `score` — точность, оценку полноты и пороговые кривые. Тексты разделов в репозиторий не входят: в файлах только пути, строки, метрики и метки.

| Файл | Когда читать |
|---|---|
| `sample-key.json` | Ключ выборки из 120 пар: корпус, страта, размер страты, вид пары по правилам продукта, пути, строки и метрики (c5, j5, c3, cos) |
| `labels-A.json` | Метки первого слепого разметчика: verdict, form, coverage |
| `labels-B.json` | Метки второго слепого разметчика, он читал файлы в обратном порядке |
| `labels-final.json` | Итоговые метки: согласованные и разобранные основной сессией при расхождении (`source`) |
| `score.json` | Метрики по стратам и видам, оценка полноты по весам страт, перебор порогов |
