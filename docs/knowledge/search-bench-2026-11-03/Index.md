# Данные бенча настоящих запросов

Метод, состав, базовые числа и правило приёмки — раздел «Бенч настоящих запросов» в [search-quality.md](../search-quality.md). Здесь — только данные и скрипты, без отрывков закрытых проектов.

| Файл | Что внутри |
|---|---|
| `queries.json` | 168 запросов: идентификатор, проект, группа, текст, число эталонов, часть (`tune` — нечётные номера, `test` — чётные) |
| `summary.json` | метрики четырёх вариантов (полный конвейер `bars-cli`, FTS как сейчас, FTS с весом заголовка 5, FTS `AND`) по группам и проектам; ранг первого правильного места для каждого запроса и варианта |
| `spec/bars-project.mjs` | эталон bars-project: запрос, группа, дословная опора. Эталоны остальных проектов с отрывками лежат вне репозитория |
| `scripts/build.mjs` | проверка опор по копии индекса, сборка `queries.json` с эталоном |
| `scripts/run-cli.mjs` | прогон через установленный `bars-cli --json search`, строго по одному запросу |
| `scripts/fts.mjs`, `scripts/stem.mjs` | полнотекстовые варианты на копии индекса: правило MATCH как в `hybrid.rs`, стемминг |
| `scripts/analyze.mjs` | расчёт метрик по группам и проектам |

Закрытые данные — в `%USERPROFILE%\.bars\bench\` (вне репозитория): копии индексов пяти проектов, эталоны с опорами, сырая выдача `bars-cli`. tmc-opovechenie и firetech-* — рабочие проекты Firetech, их тексты в репозиторий не кладутся.
