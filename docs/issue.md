# Известные проблемы bars

Баги, найденные автором при использовании. Отметка `[x]` ставится, когда проблема исправлена; рядом пишется коммит.

## ISS-01: Загрузка моделей зависает и дублируется

- [ ] Исправлено
- Источник: автор, 16-10-2026

Нажимаешь «Загрузить» — примерно через минуту модель показана как загруженная, но при первом вопросе окно зависает, а в терминале снова идёт загрузка. Кнопка и реальная загрузка расходятся (ср. `is_downloaded`).

## ISS-02: Без rerank результаты идут не по убыванию шкалы релевантности

- [ ] Исправлено
- Источник: автор, 16-10-2026

Если rerank не используется, образцы выдаются в порядке, не совпадающем со шкалой процентов («71% частично»): порядок выглядит случайным.

## ISS-03: Rerank на другой машине даёт оценки меньше 0.1%

- [ ] Исправлено
- Источник: автор, 16-10-2026

На другой машине скачаны rerank и embed. Только с embed всё хорошо, с rerank оценки на шкале меньше 0.1%. На основной машине всё работает. Вероятен баг (веса, кэш, устройство или нормализация оценки); нужно воспроизвести.

## ISS-04: Иконка приложения не вшита в exe

- [ ] Исправлено
- Источник: автор, 16-10-2026

Иконка приложения придумана, но на exe-файл не поставлена.

## ISS-05: Enter в поле поиска меняет строку вместо отправки запроса

- [ ] Исправлено
- Источник: автор, 16-10-2026

При нажатии Enter в строке поиска вставляется перенос каретки, а должен отправляться запрос. Перенос строки заблокировать.
