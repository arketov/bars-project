# Известные проблемы bars

Баги, найденные автором при использовании. Отметка `[x]` ставится, когда проблема исправлена; рядом пишется коммит.

## ISS-01: Загрузка моделей зависает и дублируется

- [x] Исправлено
- Источник: автор, 16-10-2026

Нажимаешь «Загрузить» — примерно через минуту модель показана как загруженная, но при первом вопросе окно зависает, а в терминале снова идёт загрузка. Кнопка и реальная загрузка расходятся (ср. `is_downloaded`).

## ISS-02: Без rerank результаты идут не по убыванию шкалы релевантности

- [ ] Исправлено
- Источник: автор, 16-10-2026

Если rerank не используется, образцы выдаются в порядке, не совпадающем со шкалой процентов («71% частично»): порядок выглядит случайным.

Замер 16-10-2026 (24 вопроса по docs/): у каждого запроса 2–6 пар соседей, где оценка растёт вниз по списку. Порядок задаёт слияние RRF, а показывается косинус, поэтому шкала с порядком не согласована.

## ISS-03: Rerank на другой машине даёт оценки меньше 0.1%

- [ ] Исправлено
- Источник: автор, 16-10-2026

На другой машине скачаны rerank и embed. Только с embed всё хорошо, с rerank оценки на шкале меньше 0.1%. На основной машине всё работает. Вероятен баг (веса, кэш, устройство или нормализация оценки); нужно воспроизвести.

Замер 16-10-2026 на основной машине: оценки rerank на процессоре и на видеокарте (DirectML) почти совпадают, расхождение лидера не больше 0.0017. Значит, на основной машине числа не расходятся; причину искать на другой машине (видеокарта, драйвер, другие веса).

Диагностика добавлена 16-10-2026: воркер пишет в stderr устройство rerank, файлы модели и сырые логиты (`features/models/local-models.md`). Нужен лог с той машины.

## ISS-05: Enter в поле поиска меняет строку вместо отправки запроса

- [x] Исправлено
- Источник: автор, 16-10-2026

При нажатии Enter в строке поиска вставляется перенос каретки, а должен отправляться запрос. Перенос строки заблокировать.

## ISS-06: Автообновление не подхватывает изменения документов

- [x] Исправлено
- Источник: автор, 16-10-2026

Документы меняются на диске, но в bars изменений не видно: индекс не обновляется сам. Нужно воспроизвести: слежение за корнем документации, очередь проверки (Т-10), время обновления индекса в `bars_status`.

Причина (OQ-70): `notify` на Windows теряет события при переполнении буфера, а на неизвестной ошибке слежение снимается молча. Исправлено 16-10-2026: проверка целиком через 5 секунд после пачки событий, полная проверка по `Rescan` и по событию без путей, перезапуск слежения, которое молчит при находках периодической проверки; периодическая проверка — раз в 15 минут. Описание — `features/indexing/updates.md`. Проверено тестами на сотнях файлов; на реальном `overdrive-bots` не проверялось.

## ISS-07: Правый клик показывает меню webview

- [x] Исправлено
- Источник: автор, 16-10-2026

В окне по правому клику открывается стандартное меню webview. Его нужно убрать или заменить своим.

## ISS-08: Claude Code игнорирует bars и serena

- [ ] Исправлено
- Источник: автор, 16-10-2026

Codex с bars интегрировался отлично, а Claude Code по сути не замечает существования bars и serena: не вызывает их инструменты. Нужно разобраться, что в инструкции, хуке и описании инструментов подталкивает Codex и не подталкивает Claude Code.

## ISS-09: Проверить, что индексация не мешает запросам RAG

- [x] Исправлено
- Источник: автор, 16-10-2026

Исправлено 16-10-2026: запрос ждал модель до 22,8 с, теперь не дольше одной пачки (до 3 с); замер и причина — `knowledge/search-during-indexing.md`.

Индексация должна идти параллельно запросам RAG и не мешать им. Нужно убедиться на деле: запустить индексацию и в это время слать поисковые запросы, замерить задержку и найти блокировки (индекс SQLite, одна общая модель embed, очередь воркера).

## ISS-10: Строка состояния индекса обрезана и нечитаема

- [x] Исправлено
- Источник: автор, 16-10-2026

В нижней панели окна текст «Индекс актуален · обновлён 1…» обрезается многоточием и почти всегда не читается. Нужно вывести его в две строки: состояние индекса и время обновления.
