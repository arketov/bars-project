# Фичи bars

Что bars умеет с точки зрения пользователя и агента. Общее устройство, на которое опираются фичи, — `architecture/`.

| Папка | Когда читать |
|---|---|
| `indexing/` | Индексация: нарезка документов и обновление индекса |
| `search/` | Гибридный поиск от запроса до выдачи |
| `knowledge-base/` | База знаний: редактор, ссылки, `index.md` папки, файлы, аудиты; требования Т-29…Т-42 зафиксированы, реализации нет |
| `new-topics/` | Проект фичи «Новые темы»: сбор вопросов без материалов, дедупликация, список, повторная проверка и макет; реализации нет |
| `graphrag/` | GraphRAG: граф знаний, новые инструменты, поиск со связями и графический просмотр; реализован частично, приёмка S1–S8 открыта |
| `models/` | Встроенные и внешние модели embed и rerank, устройства, память |
| `settings/` | Настройки пользователя и проекта |
| `projects/` | Реестр проектов: регистрация, пропавшие и перенесённые проекты, удаление; подпроекты и список проектов с фильтром; git worktree как вид проекта (последние два — проекты, реализации нет) |
| `agent-tools/` | MCP-инструменты и команды `bars-cli` |
| `clients/` | Установка в Claude Code, Codex и другие MCP-клиенты, автообновление интеграций |
| `window/` | Окно и трей: экраны, уведомления, статистика MCP, меню, HTML-мокапы |
| `distribution/` | Поставка: установщик Windows с обновлением на месте, автозапуск при входе в систему |
| `docs-convention/` | Соглашение о документации: раскладка `docs/`, журнал сессий, стартовая инструкция и skills |
