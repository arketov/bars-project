# Индексация

Как документы проекта попадают в индекс и как индекс остаётся актуальным.

| Файл | Когда читать |
|---|---|
| `chunking.md` | Разбор Markdown, дерево разделов, нарезка, склейка, текст для эмбеддинга |
| `updates.md` | Часовая проверка, активность MCP и окон, очередь обновления, исключения и полная переиндексация |
| `document-queue.md` | Очередь документов: состояния, пауза перед embed, приоритеты, страница индексации; реализовано в 3.2.1 |
