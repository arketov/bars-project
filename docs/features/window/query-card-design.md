## Карточка запроса

На виду однострочное поле, полная подпись области и «Найти». Под ними компактное раскрытие «Параметры». Область переносится по словам, длинное имя — внутри слова; не сокращается до «Искать во всём пр…». При узкой панели кнопка переносится, горизонтальная прокрутка карточки не появляется. Enter в запросе и фильтре пути запускает поиск; составление текста IME его не запускает.

«Параметры» содержит режим, число результатов с прежним умолчанием и пределом, связанные источники для «Со связями», регистр, регулярное выражение и путь. Заголовок группы текстовых параметров явно говорит «Только в тексте»; они не фильтруют смысловые результаты. Для связей сохраняется пометка эксперимента без обещания лучшего ранжирования. Размещение действует в главном и глобальном поиске через один компонент.

Свёрнутая строка сообщает об активных отличиях словами: режим, изменённое число результатов, регистр, выражение, фильтр пути. Полный фильтр остаётся доступен при раскрытии. Это параметры следующего запуска; фактически применённые значения остаются у завершённой выдачи. Раскрытие и изменение параметров сами поиск не запускают и результатов не стирают. Возврат числа «по умолчанию» не сбрасывает область и запрос.

Временная область из графа и «Вернуть прежнюю область» остаются над карточкой; область не прячется в параметрах. Предупреждение о переиндексации не заменяет название области: текстовый поиск продолжает работать. Ошибки сохранения остаются над обеими выдачами.

## Пустой раздел в тексте

Только успешный полный ответ без вхождений, пропусков файлов и ошибки становится строкой «В тексте: вхождений не найдено» под смысловой выдачей (включая связанные источники или её пустое состояние). До первого ответа такой строки нет. Ожидание, ошибка, усечение и непрочитанные файлы сохраняют самостоятельный раздел над смысловой выдачей; неполнота не выдаётся за отсутствие совпадений.

Непустые текстовые результаты сохраняют прежние карточки и «Показать ещё». Ответы двух поисков независимы. Ошибка модели не скрывает ни текстовые совпадения, ни достоверный пустой итог. Новая выдача не использует пустое состояние предыдущего запроса.

## Подпись отрывка в редакторе

Над первой найденной строкой — «строки N–M · найдено», для одной строки — «строка N · найдено». Слева у диапазона полоса акцента, фон — прежний. Для точного вхождения сохраняется выделение символов, включая нулевую длину; подпись относится к строке. Это оформление CodeMirror, не вставка в Markdown: копирование, сохранение, нумерация и история отмены не получают служебный текст.

Повторный переход обновляет диапазон. Первая правка снимает подпись и подсветку вместе, как существующая модель найденного отрывка; новое внешнее содержимое также не сохраняет старую подпись. Переключение исходника и рендера сохраняет контракт Т-29. Открытие из дерева без диапазона не показывает «найдено».

## Стенд представления и границы проверки

Из `ui`: `npx vite --config vite.query-card.config.ts`; адрес `http://127.0.0.1:4187/query-card-design.html`. Стенд показывает продуктовые компоненты и подменяет только текстовые ответы. В обычных `npm run dev` и сборке продукта действует то же представление, ответы стенда в них не подключаются. Проверка подмены сообщает об изменении mock-ответа вместо молчаливой потери сценариев.

Без параметра адреса текстовый ответ пуст; `?text=hits`, `?text=zero`, `?text=error`, `?text=skipped`, `?text=limited` показывают соответственно вхождение, нулевое совпадение, ошибку выражения, пропуск файла и усечение. После открытия сцены ввести запрос и нажать «Найти». Эти ответы фиксированы для проверки оформления, не вычисляются по введённому запросу.

При параллельных правках удобнее зафиксировать просмотр: `npx vite build --config vite.query-card.config.ts`, затем `npx vite preview --config vite.query-card.config.ts --port 4188`. Адрес — `http://127.0.0.1:4188/query-card-design.html`; этот просмотр не перезагружается от чужого редактирования исходников. Выход сборки `ui/query-card-design-dist/` не коммитится.

Для следующей разрешённой проверки: обе темы; широкое окно и поиск рядом с документом; узкая панель; раскрытие с клавиатуры; длинная область; активные скрытые параметры; обычный поиск и глобальный слой; пустой и непустой текстовый результат, ошибка выражения и пропуски; открытие отрывка, повторный переход и снятие подсветки после правки, включая замену символа им же. Подготовлен `crates/bars-app/examples/query_card_probe.js` для изолированного `workspace_probe` с настоящим IPC и поиском; сценарий пока не запускался. Фикстуры стенда и компонентные тесты не заменяют приёмку установленного приложения.
