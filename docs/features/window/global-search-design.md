## Композиция и область поиска

Лупа в общей шапке доступна над любым содержимым: документом, графом, настройками, индексацией. Открывает модальный слой в текущем окне. Заголовок — имя текущего проекта; справа крестик. Фон затемнён и недоступен для ввода. Фокус сразу в запросе. Escape и крестик возвращают фокус вызвавшему элементу; щелчок по фону окно не закрывает.

Слой продолжает существующее окно: фон — настоящая рабочая область Dockview, без новой шапки экранов и выдуманных неподвижных панелей. В слое используется существующая карточка запроса и существующие карточки результата без изменения шрифтов, значков, оценки и отступов. Максимум ширины поиска — 640 px. Новых строк «Запрос…», «Параметры изменены…» и итогов сверх существующего компонента не добавляется. Пустой поиск по центру; завершённая выдача сверху. Выдача прокручивается отдельно.

В слой временно переносится настоящее дерево Sidebar с фильтром, галочками и текущим проектом. Узлы не заменяются плоским списком фикстур. Область и частичный выбор вычисляют существующие TreeRow/tree. На узком окне дерево раскрывается кнопкой «Область». Закрытие возвращает те же DOM-узлы на места; проект, раскрытие папок, выбор, фильтр и раскладка сохраняются.

## Общая сессия и режимы

Главный поиск и слой используют один запрос, проект, область, режим, число результатов, признак связанных источников и завершённую выдачу. Открытие/закрытие слоя не запускает поиск, не очищает раскрытые карточки и не меняет раскладку. Изменения видны при возврате к главному поиску. Один DOM-компонент поиска перемещается между двумя входами.

Сохраняются нынешние подписи: «Обычный» (`hybrid`), «Со связями» (`mix`), «Отношения и пути» (`graph`). В `mix` — галочка «Добавлять связанные источники». В `graph` показаны отношения с источниками; оценки rerank у ребра нет. Запрошенный и применённый режим различаются при fallback; причина видна рядом с итогом. При неполном графе — предупреждение, найденные документы остаются доступны. Это не выбор устройства физического графа блока 2.

«Результатов», кнопки −/+, возврат «по умолчанию», Enter/«Найти», обработка вставки — существующий SearchPane. Сессия и результаты принадлежат app.svelte.ts. Защита поздних ответов и смена проекта проверены компонентными регрессиями; отдельной поисковой логики в слое нет.

Разделы «В тексте / По смыслу», регулярные выражения и фильтр пути — Т-39 и отдельный этап 3.6. Последнее указание автора убрало текстовые вхождения из макета каркаса: этот дизайн их обратно не добавляет и не подменяет ими режимы GraphRAG. Новое сочетание вызова здесь не утверждается: действие регистрируется в этапе 1.3; в демонстрации вызов лупой.

## Выдача и переходы

Карточки — существующий ResultCard, не копия его разметки. Действия документа, найденные строки, глаз, структура и вкладки — существующий WorkspaceDocument. Кнопка выбора результата в графе отсутствует до реализации контракта блока 2. Новая служебная строка выдачи не вводится.

«Открыть документ» закрывает слой, активирует вкладку документа справа и прокручивает к подсвеченным строкам. Запрос, область и раскрытие карточек сохраняются. При узком окне документ занимает доступную рабочую зону. Фокус передаётся заголовку документа, при недоступном файле — сообщению с путём и возможностью вернуться к поиску; успешное открытие не имитируется.

Целевой переход «Показать в графе» закрывает слой, активирует панель графа, выбирает результат завершённого запроса; фокус — выбранному узлу/его инспектору. Видны запрос и источник выбора. При отсутствии объекта действие недоступно с причиной, документ остаётся доступным. Физика, бюджеты и построение графа от запроса относятся к блоку 2; этот переход ещё не реализован.

## Состояния и проверка

| Состояние | Вид и действие |
|---|---|
| Пустой запрос | Поле по центру, «Найти» недоступно |
| Ожидание | «Ищем…», повторный запуск недоступен; Escape закрывает слой без нового вызова |
| Результаты / нет результатов | Поле сверху; явный итог, прежняя выдача не выдаётся за новую |
| Ошибка воркера | Текст причины, «Повторить»; автоматический повтор и выдуманное model_loading не добавляются |
| Нужна переиндексация | Поиск недоступен; отдельный переход к согласию Т-25, переиндексация сама не запускается |
| Идёт индексация | Поиск остаётся доступен по готовому индексу; предупреждение об отставании правок |
| Неполные связи / fallback | Явные ограничения и применённый режим; доступные документы остаются |

Отдельная нижняя демонстрационная панель удалена вместе с отвергнутым интерфейсом. Ошибки и индексация — штатные сцены mock.ts. Проверка: обе темы; 1440/1024/760 px; открытие из служебных панелей; Tab внутри слоя, Escape и возврат фокуса; настоящее дерево/частичные галочки/сброс; режимы и количество; существующие карточки и документ; закрытие и повторное открытие. Результаты новой проверки — в [передаче сессии](../../chats/2026-10-20-global-search-design/handoff.md).

## Реализация 1.2.2

Поручение автора 20-10-2026 — реализовать 1.2.2 по переработанному макету. Поиск и дерево постоянно принадлежат Workspace: панели и модальный слой принимают те же узлы; закрытие панели не создаёт вторую сессию. Открытие слоя не добавляет панели и не меняет сохранённую раскладку. При смене проекта слой закрывается до восстановления панелей. Состояния воркера используются из главного поиска, без отдельной обработки в модальном окне.

Снимок завершённого поиска включает проект, запрос, область, режим и параметры. Начало нового поиска убирает прежнюю выдачу; поздний ответ не заменяет новый. Документ закрывает слой после получения результата чтения, включая сообщение об отсутствующем файле. До ответа чтения слой остаётся доступен. Фокус переходит заголовку документа. Escape и крестик возвращают фокус инициатору. Клавиша вызова — этап 1.3. Кнопка выбора в графе не переносится из демонстрации до контракта блока 2.

Проверки и границы — в [передаче сессии 1.2.2](../../chats/2026-10-20-global-search-implementation/handoff.md); установленное приложение требует отдельного разрешения OQ-106/OQ-113.
