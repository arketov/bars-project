# Диалог согласия на переиндексацию

Что видит пользователь, когда embed-модель в настройках не совпадает с моделью, которой построены индексы (Т-25, OQ-21). Мокап — [mockups/reindex-consent.html](mockups/reindex-consent.html), три сцены.

## Когда открывается диалог согласия

- Сразу после «Сохранить» на вкладке «Модели», если выбранная модель отличается от модели индекса хотя бы у одного проекта. Предупреждение под блоком модели ([settings-window.md](settings-window.md)) остаётся как заранее данная подсказка.
- По кнопке «Переиндексировать…» в баннере проекта и в пункте списка проектов с жёлтой точкой.
- Воркер при смене отпечатка только переводит проект в `reindex_required` ([architecture/worker.md](../../architecture/worker.md)); диалог — единственный путь согласия в окне. Остальные пути — `bars-cli reindex --accept-model-change` и ничего больше: агент через MCP согласие дать не может ([architecture/protocol.md](../../architecture/protocol.md)).

## Что показывает диалог согласия

- **Модели.** Слева «Индекс построен» (модель, источник, размерность), справа «В настройках сейчас» — выделена цветом акцента.
- **Таблица проектов** в состоянии `reindex_required`: галочка, имя, число документов, число чанков, оценка времени. Все отмечены; итог по выбранным — внизу таблицы. Согласие даётся по проектам: можно переиндексировать один сейчас, остальные позже (решение агента, OQ-56).
- **Что произойдёт.** Индекс строится заново в отдельном файле, старый заменяется в конце; пока идёт переиндексация, поиск по проекту не работает; временно нужно место под второй индекс.
- **Скачивание модели.** Для встроенной нескачанной модели — размер, он входит в ход индексации.
- **Удалённый провайдер.** Предупреждение красным значком и текстом: текст всех чанков уйдёт провайдеру; время и стоимость определяет он; вместо времени — «зависит от провайдера» (OQ-58).

Кнопки:

| Кнопка | Действие |
|---|---|
| «Переиндексировать (N)» | согласие по отмеченным проектам: окно вызывает `reindex` с `accept_model_change`; кнопка недоступна, если ничего не отмечено |
| «Позже» | закрывает диалог; настройки уже сохранены, проекты остаются в `reindex_required`, поиск по ним не работает (Т-25) |
| «Вернуть прежнюю модель» | возвращает в настройках модель индекса: отпечатки снова совпадают, переиндексация не нужна (решение агента, OQ-56) |

Согласие не снимается закрытием окна: состояние хранит воркер, а не окно.

## Окно после «Позже»

Проекты в `reindex_required` показаны жёлтой точкой и подписью «нужна переиндексация». У выбранного проекта дерево документов видно (оно читается с диска, от модели не зависит), поле запроса недоступно и подписано, над ним — баннер с причиной и кнопкой «Переиндексировать…», которая снова открывает диалог. Поиск по остальным проектам работает. Баннер говорит и о том, что агенты получают ошибку «нужна переиндексация» и сами её не запустят. Полный экран этого состояния — в [error-states.md](error-states.md).

## Оценка времени переиндексации

Оценка — число чанков, умноженное на скорость модели. Для bge-m3 — около 0,5 с на чанк ([features/models/local-models.md](../models/local-models.md)); для моделей без замера время показывается после первых пачек (решение агента, OQ-58). Скорость считается по фактическим пачкам и обновляется в ходе индексации ([indexing-progress.md](indexing-progress.md)).
