# Дизайн окна bars

Как выглядит окно bars: описание экранов и HTML-мокапы. Мокапы не индексируются — bars берёт только `.md`. Язык интерфейса и сообщений поиска — по НФТ-4: все пользовательские подписи по-русски, язык инструкций агентам на него не влияет.

| Файл | Когда читать |
|---|---|
| `keyboard-design.md` | Каталог и реализация клавиатуры: команды, умолчания, контексты, переназначение, профиль и границы приёмки |
| `global-search-design.md` | Глобальный поиск 1.2.2: общий поиск и дерево в модальном слое, состояния, переход в документ; границы графа и приёмки |
| `workspace-decisions.md` | Направление автора: перемещаемые панели, глобальный поиск, клавиши, физический граф; что ещё не согласовано |
| `requirements.md` | Рамка рабочей области раунда 17: зоны, панели, отдельные окна документов, общий поиск, клавиатура и граф; инженерные предложения для следующих шагов |
| `workspace-design.md` | Пункт 1.1.3: предлагаемый каркас панелей, обе темы, узкое окно и интерактивный макет; ожидает согласования OQ-112 |
| `workspace-plan.md` | Каркас и проект 3.2.3: жизненный цикл зон, превью, миграция раскладок и проверки; статус согласования |
| Исследование docking (`knowledge/window-docking.md`) | Прямой адаптер Svelte, размеры кандидатов, WebView2 и отдельное окно над общим воркером; ADR-0003 (`adr/0003-window-docking.md`) принят в реализации 1.1.4 |
| `main-window.md` | Главный экран и таблица мест открытия: документы, служебные вкладки, ручной перенос и пустой центр |
| `settings-window.md` | Вкладки настроек, запуск, оформление и экран анализа вызовов MCP |
| `implementation.md` | Как устроено окно: команда Tauri поверх обработчиков воркера, трей, один экземпляр, интерфейс на Svelte, что сделано сверх мокапов |
| `palette.md` | Палитра «Малина»: цвета светлой и тёмной темы |
| `reindex-consent.md` | Диалог согласия на переиндексацию после смены модели (Т-25) |
| `indexing-progress.md` | Ход индексации: очередь, прогресс, ошибка файла, трей |
| `empty-states.md` | Пустые экраны: нет проектов, нет документации, нет результатов |
| `error-states.md` | Ошибки: воркер, модель, провайдер, пропавший проект, переиндексация |
| `labels.md` | Словарь подписей: правило «идентификатор только в подсказке и в отчёте», опись внутренних слов окна, модуль подписей (проект 3.4.3, ISS-59) |
| `notifications.md` | Центр уведомлений: операции, достоверные итоги, доставка, внимание, сценарии N-01…16 |
| `mcp-statistics.md` | Отдельные вызовы MCP: данные, хранение, API фильтров и курсора, сценарии M-01…07 |
| `document-actions.md` | Меню файлов и папок: цели, три действия, сценарии F-01…11, границы нативной проверки; модель меню окна — группы, порядок, недоступные пункты, таблица меню объектов |
| `project-menu.md` | Меню проекта, проверка индекса и граница полного удаления |
| `logs.md` | Файловый журнал, уровни, ротация и просмотр в настройках |
| `refinement-design.md` | Композиция и состояния уведомлений, анализа MCP и меню папок; интерактивные макеты |
| `refinement-plan.md` | Оставшаяся нативная приёмка уведомлений, истории MCP и меню папок (ISS-13…15) |
| `mockups/` | HTML-макеты всех экранов с общей темой; открываются двойным кликом, внешних загрузок нет |

Смежное: Новые темы (`features/new-topics/Index.md`) — первая строка дерева и экран очереди вопросов (реализованы, приёмка в настоящем окне не проведена); полное удаление проекта (`features/projects/deletion.md`) — подтверждение и сохранение документации.
