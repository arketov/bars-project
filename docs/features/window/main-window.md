# Главный экран окна bars

Экран, который открывается из трея. Слева — проект и дерево его документов, в центре — запрос и выдача, справа по требованию — открытый документ. Мокап — [mockups/main.html](mockups/main.html). Раскладка взята из образца `rag_explorer`, цвета — [palette.md](palette.md).

## Выбор проекта в окне bars

Кнопка вверху боковой панели показывает текущий проект: имя, путь к корню документации и точку состояния индекса. По клику открывается список всех зарегистрированных проектов (Т-6) с состоянием каждого:

| Точка | Состояние |
|---|---|
| зелёная | индекс актуален, число документов |
| цвет акцента, мигает | идёт индексация: процент и сколько документов ждёт (Т-19) |
| жёлтая | нужна переиндексация: сменилась embed-модель (Т-25) |
| серая | папка проекта не найдена ([features/projects/projects.md](../projects/projects.md)) |

Последний пункт списка — «Добавить проект…»: регистрация проекта из окна (Т-6).

## Дерево документов с галочками

Дерево «модуль → папки → файлы» (Т-14). Модули — подпапки первого уровня корня документации, файлы в самом корне — модуль «(корень)». У каждого узла справа число чанков.

Имена в дереве показаны для людей: без `.md`, дефисы и подчёркивания заменены пробелами, первая буква заглавная — `hybrid-search.md` показан как «Hybrid search», `agent-tools` — как «Agent tools». Настоящий путь — во всплывающей подсказке. Фильтр ищет и по показанному имени, и по пути.

- Галочка на модуле или папке отмечает всё внутри; частичный выбор показан чертой.
- Нажатие на имя файла открывает целый документ справа без поискового запроса и без изменения галочек. [Документ и меню](document-actions.md).
- Снять галочку с файла внутри отмеченного модуля — значит отметить остальных его соседей.
- Ничего не отмечено — поиск по всему проекту. Внизу панели: «Отмечено модулей: N из M» и «Сбросить».
- Поле «Фильтр модулей и файлов» скрывает узлы, не совпадающие по имени, и раскрывает совпавшие.

Под деревом — строка состояния индекса текущего проекта в две строки (состояние; время обновления или ход индексации), кнопка смены светлой и тёмной темы и кнопка настроек.

## Запрос и выдача

Поле запроса вверху, поиск — кнопкой «Найти» или клавишей `Enter`. Запрос однострочный: перенос строки не вставляется, а при вставке текста переносы заменяются пробелами. Под полем строка «Искать в: …» повторяет выбор в дереве.

Рядом — «Результатов» с кнопками «−» и «+»: сколько результатов вернуть на этот запрос. Начальное значение — из настроек (с реранком или без, Т-18), верхний предел — `max_results`. Если число изменено, рядом появляется «по умолчанию» для возврата.

Над карточками — применённые параметры: число результатов, rerank-модель или «без реранка», порог и время поиска.

## Карточка результата поиска

Каждая карточка — один чанк (Т-13, Т-23):

- номер места; у первого он выделен цветом акцента;
- заголовок — последний заголовок цепочки;
- путь с номером строки начала (`features/search/hybrid-search.md:26`) и цепочка заголовков; путь показан как есть, его копируют агенту;
- метки: модуль (именем для людей) и `title` документа (Т-11);
- оценка справа: процент и полоска; подпись `Cosine similarity` без rerank либо `Rerank score` с ним. Число — оценка модели × 100, не вероятность правильного ответа.

Без rerank цвет полоски — акцент палитры: оценка не делится на неподтверждённые категории «хорошо/частично/слабо». С rerank цвет показывает диапазон числовой оценки, без словесного обещания правильности. Ниже порога результатов в выдаче нет (Т-24). Над карточками явно указан порядок: гибридный либо по оценке rerank. Для гибридного порядка видно пояснение, что косинусная близость может возрастать вниз: место учитывает также слова и точные идентификаторы (OQ-77).

Клик по карточке раскрывает текст чанка. Внизу раскрытой карточки:

- «Открыть документ» — открывает документ в панели просмотра внутри окна;
- «Копировать путь:строку» — для передачи агенту или в редактор;
- строки начала и конца и вид оценки (`rerank` или `cosine`).

Первая карточка раскрыта сразу.

## Просмотр документа внутри окна

«Открыть документ» в выдаче и имя файла в дереве открывают справа третью колонку — документ целиком, отрисованный из Markdown. Выдача остаётся видна слева; при открытии результата его карточка обведена цветом акцента. Из дерева документ открывается с начала, без подсветки найденного раздела.

- В шапке — `title` документа, путь от корня проекта, «В редакторе» (открыть файл в программе, связанной с `.md`) и «Закрыть».
- Раздел, из которого взят чанк, подсвечен фоном и полосой акцента с подписью «строки N–M · найдено»; документ прокручен к нему.
- Открытие другого результата заменяет документ в той же колонке.
- Пока колонка открыта, подсказка `Enter` под полем запроса скрыта, чтобы строка помещалась.

## Контекстное меню окна

Стандартное меню webview выключено (OQ-68): по правому клику открывается короткое меню bars.

- В поле ввода (запрос, фильтр, поля настроек) — «Копировать» (если есть выделение), «Вставить», «Выделить всё». В поле только для чтения — «Копировать» и «Выделить всё».
- На выделенном тексте вне полей — «Копировать».
- На файле дерева и карточке результата — [меню документа](document-actions.md#меню-документа), при выделенном тексте к нему добавляется «Копировать».
- В остальных местах меню нет, правый клик ничего не делает.
- «Вставить» читает буфер обмена через webview; в поле запроса переносы строк при вставке заменяются пробелами. Если webview не дал прочитать буфер, показывается уведомление, а вставить можно клавишами `Ctrl+V`.
- Меню закрывается по `Esc`, клику вне него, прокрутке и потере фокуса окна. Меню открывается рядом с курсором и не выходит за границы окна.
- Пункты документа (IDEA-09) и редактирования текста используют один компонент меню.
