# Пустые экраны окна bars

Что окно показывает, когда показывать нечего. Мокап — [mockups/empty.html](mockups/empty.html), четыре сцены. Пустой экран всегда объясняет причину и предлагает действие.

## Пустой экран «нет проектов»

Окно открыто, а реестр пуст (Т-6). По центру: значок папки, «Добавьте первый проект», одна строка о том, что bars ищет по Markdown-документации, кнопка «Добавить проект…». Ниже — второй путь: проект появится сам, когда сессия Claude Code или Codex начнётся в папке с документацией, если bars установлен в клиент; ссылка «Установить bars в клиенты» ведёт на вкладку «Клиенты» ([settings-window.md](settings-window.md)). Дерево, поле запроса и фильтр скрыты: им не на чем работать.

## Проект без документации

Проект зарегистрирован, но в корне документации (`docs_root`, по умолчанию `docs`, [features/settings/settings.md](../settings/settings.md)) нет ни одного `.md` или самой папки. Проект остаётся в списке, слежение включено: как только файлы появятся, проект проиндексируется. Экран называет проект и корень, который bars искал; кнопки:

- «Выбрать другую папку документации…» — меняет `docs_root` в `.bars/config.toml` проекта; полная проверка запустится сама. Корень проекта `.` допустим;
- «Открыть папку проекта»;
- «Убрать из bars» — снимает регистрацию, файлы и `.bars/` остаются ([features/projects/projects.md](../projects/projects.md)).

Точка проекта — жёлтая с подписью «документации не найдено».

## Индекс ещё пуст

Проект индексируется впервые. Дерево документов видно, поле запроса работает, но выдача будет пустой, пока индекс не наполнится. Экран показывает прогресс, оценку времени и кнопку «Ход индексации» ([indexing-progress.md](indexing-progress.md)). Если модель ещё не скачана — первой стадией идёт скачивание ([error-states.md](error-states.md)).

## Нет результатов поиска

Запрос выполнен, но ни один чанк не набрал порог (Т-24): ниже порога результатов в выдаче нет. Экран:

- называет причину и числа: порог и лучшую оценку («лучший кандидат получил 0,18»), чтобы пользователь видел, что документы нашлись, но слабо подходят;
- перечисляет, что можно сделать: снять галочки модулей, если искали по части проекта; переформулировать запрос термином из документов; понизить порог для этого запроса;
- кнопки: «Искать по всему проекту» (если дерево сужено) и «Порог N для этого запроса» (понижение только на один запрос, в пределах `min_score_*` из настроек; слабые результаты придут с пометкой «слабо»);
- строку применённых параметров: число результатов, порог, реранк, время.

Если проект просто пуст, а не запрос неудачный, показывается экран «Индекс ещё пуст», а не этот.
