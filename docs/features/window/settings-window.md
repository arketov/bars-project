# Экран настроек bars — модели, поиск, клиенты и статистика MCP

Отдельный экран, открывается шестерёнкой в главном. Слева — «К поиску» и семь вкладок, справа — содержимое вкладки. Внизу вкладок моделей, поиска и нарезки — полоса «Отменить / Сохранить»: настройки пишутся в `~/.bars/settings.toml` только по «Сохранить». Мокап — [mockups/settings.html](mockups/settings.html). Вкладка [«Логи»](logs.md) читает журнал воркера и не требует сохранения настроек.

## Вкладка «Модели» в настройках

**Embed-модель** (Т-16, Т-17). Переключатель способа подключения: «Встроенная», «Удалённый провайдер», «Локальный адрес».

- **Встроенная** — список моделей из [features/models/local-models.md](../models/local-models.md) с размерностью и бэкендом. У нескачанной модели кнопка «Скачать», у скачанной — метка.
- **Удалённый провайдер** — адрес API, модель, ключ и переменная окружения. Ключ задаётся кнопкой и уходит в хранилище ОС; в поле видно только имя записи ([architecture/secrets.md](../../architecture/secrets.md)).
- **Локальный адрес** — адрес OpenAI-совместимого сервера и модель.

Если выбрана модель, отличная от той, которой построены индексы, под блоком появляется предупреждение: после сохранения проектам понадобится переиндексация, она начнётся только после согласия, а до него поиск по такому проекту не работает (Т-25).

**Rerank** — выключатель в заголовке блока и тот же выбор способа и модели. Выключенный блок приглушён.

**Устройства моделей** — независимые «GPU, если доступен» / «Только CPU» для embed и rerank, применяются кнопкой «Сохранить». Candle показывает «Только CPU», внешний провайдер — неизвестное устройство сервера. Отдельно выводятся модель текущей конфигурации, состояние загрузки, устройство сессии и причина CPU-fallback. Состояния модели отображаются русскими подписями, а не кодами протокола (НФТ-4). Чтение состояния модель не загружает. Изменение устройства не требует переиндексации; действующее задание завершает работу на прежнем устройстве. Мокап — [device-settings.html](mockups/device-settings.html).

**Выгрузка из памяти** — два числовых поля «Embed» и «Rerank»: минуты простоя до выгрузки встроенной модели, `0` — не выгружать ([settings.md](../settings/settings.md)). Целое от 0 до 10 080; иначе ошибка под полем и «Сохранить» недоступна. Применяются кнопкой «Сохранить» без перезагрузки модели. Под полями подсказка: `0` держит модель в памяти постоянно. Отдельного мокапа нет: блок повторяет поля вкладки «Поиск».

## Вкладка «Поиск» в настройках

Значения по умолчанию для всех проектов; подпись напоминает, что проект переопределяет их в `.bars/config.toml`, а агент — в вызове ([architecture/files.md](../../architecture/files.md)).

- Число результатов с реранком и без, кандидатов на реранк, пределы агента `max_results` и `max_candidates` (Т-18).
- Порог релевантности отдельно для оценки реранка и для косинуса — ползунок с полем — и общие пределы, в которых агент задаёт свой порог, «от … до …» (Т-24, [features/search/hybrid-search.md](../search/hybrid-search.md)).

Имена ключей и заводские значения — [features/settings/settings.md](../settings/settings.md).

## Вкладка «Нарезка» в настройках

Минимальный и максимальный размер чанка в знаках (Т-18, Т-23).

## Вкладка «Клиенты» в настройках

Установка bars в агентские клиенты из окна (Т-21, [features/clients/clients.md](../clients/clients.md)). По строке на клиента:

- **Claude Code** и **Codex** — состояние («установлено», «не установлено», «хук ждёт одобрения»), файлы, которые bars правит, и кнопки «Установить» или «Переустановить» и «Удалить».
- Для Codex с неодобренным хуком — предупреждение выполнить `/hooks` в Codex.
- **Другой MCP-клиент** — «Копировать конфиг» для ручного подключения без хука.

Ниже — блок «Инструкция для агента» с текстом установки и кнопкой «Копировать».

Число в метке вкладки «Клиенты» — сколько клиентов требуют действия пользователя.

## Вкладка «Запуск» в настройках

Галочка «Запускать при входе в систему», по умолчанию снята (OQ-16). Применяется сразу, без «Сохранить», как тема: это запись в ОС, а не ключ `settings.toml`; состояние читает и пишет воркер ([features/distribution/autostart.md](../distribution/autostart.md)). Если запись указывает на другое расположение bars, под галочкой предупреждение; на ОС без автозапуска вместо галочки — пояснение. Вкладки в мокапе [mockups/settings.html](mockups/settings.html) нет: решение агента (OQ-64).

## Вкладка «Статистика MCP» в настройках

Экран анализа показывает сводку всей выборки за период (до семи дней, OQ-89), список отдельных попыток по пять серверных фильтров (период, проект, сессия, инструмент, исход) и подробности: исходный вход, фактически применённые параметры, итог и безопасную ошибку. Страницы по 50 записей; старые записи без деталей показываются отдельно; хранением управляют с подтверждением, есть диагностика. Источник — история этапа 29; старые агрегаты не прибавляются. Соединение MCP не называется чатом клиента. Композиция — [дизайн](refinement-design.md#анализ-mcp-список-фильтры-и-подробности), данные и API — [mcp-statistics.md](mcp-statistics.md). Нативная приёмка ISS-14 открыта ([приёмка](refinement-plan.md)).

## Вкладка «Оформление» в настройках

Тема окна: «Как в системе», «Светлая», «Тёмная» — три плитки с превью, применяется сразу, без «Сохранить». Быстрое переключение светлой и тёмной — кнопкой под деревом на главном экране. Цвета обеих тем — [palette.md](palette.md).
