Статус 18-10-2026: дизайн этапа 27 по ISS-13…15 выполнен; инженерные решения агента, не утверждение автора. Интерактивные макеты используют вымышленные данные. ## Общая система и навигация макетов

Палитра «Малина», шрифт Segoe UI, основной текст 14 px, подписи 12–13 px, заголовок страницы 22 px. Боковая панель 260 px, карточки с радиусом 12 px, кнопки 9 px, интервалы 8/12/16/24 px. Для текста статусов в светлой теме зелёный/жёлтый затемнены до контраста не менее 4,5:1 без изменения цветового смысла. Источник базовых цветов — неизменённые `mockups/theme.css` и `theme.js`; общие компоненты этих трёх экранов — `mockups/refinement.css` и `refinement.js`. Значки линейные SVG; статус всегда имеет текст. Фокус — видимый контур; цвет не единственный носитель смысла.

Панель демонстрации отделена от продукта: ссылки на три макета, сцена, тема и ширина. Действия ОС, очереди и маршрутизация показывают явно подписанный результат демонстрации, без настоящих побочных эффектов. При ширине 760 px боковая панель сужается до 210 px; фильтры переносятся, длинные имена и пути переносятся внутри подробностей. MCP-подробности занимают место списка с кнопкой возврата; в широком окне стоят справа. Панель уведомлений ограничена шириной окна и высотой рабочей области. Уменьшение анимации учитывается.

## Панель уведомлений: содержание и состояния

[Макет уведомлений](mockups/notifications.html). Колокольчик постоянно доступен внизу панели поиска и настроек; счётчик показывает непрочитанные события, не число процентов. Видимые карточки читаются при пересечении области списка; «Прочитать все» отдельно отмечает скрытые. Панель 440 px, привязана к колокольчику, заголовок и действия неподвижны, список прокручивается. Закрытие — кнопка, Escape или внешний клик; фокус возвращается к колокольчику, Tab остаётся внутри открытой панели. При открытии видимые события считаются прочитанными; появление нового итога снова требует внимания. Активные операции выше истории, внутри групп новые выше старых. Очистка удаляет только завершённые карточки, никогда активные и неизвестные исходы.

Иерархия карточки: операция → полный проект или модель → стадия/измеримый результат → время → действие. Длинное `ai-mutiplayer-bots` видно без обрезания. Прогресс содержит единицу, например «38 из 92 документов»; 100 % файлов отделено от подготовки модели. Доступное действие одно основное, повтор — только после завершённой ошибки/отмены; повтор создаёт новую попытку, исходная карточка остаётся в истории.

| Сценарий | Текст и действие | Нужные данные для реализации |
|---|---|---|
| Очередь | «Ожидает · перед ним 1 задание», «Ход индексации» | ID, проект, очередь |
| Работа/пауза | Документы и прогресс; при паузе явная подпись | Стадия, счётчики, пауза |
| Скачивание/подготовка | Байты и процент; затем «Файлы 100 % · подготовка модели» | Байты и отдельная стадия готовности |
| Успех, в том числе короткая операция | «Индекс обновлён · 92 документа, 4 изменены» | Явный итог и счётчики, доступные между опросами |
| Отмена | «Отменено · обработано 18 из 92», «Повторить» | Отдельный итог отмены |
| Ошибка/частичный итог | «Не обработаны 2 документа», причина, «Подробнее», «Повторить» | Безопасная ошибка, результат по файлам |
| Потеря связи | Общий баннер; «Исход пока неизвестен», последнее состояние, «Проверить связь» | Время последнего наблюдения, восстановленный итог |
| Пустая история | «Уведомлений пока нет», объяснение будущих событий | Нет активных и завершённых |
| Очистка/переход | История исчезает, активные остаются; переход фиксирует исходный проект | ID операции и неизменяемый проект |

Этап 28: панель реализована в Svelte по этой компоновке. Карточка показывает канонический путь проекта; время и действия стоят в одной строке для плотности. Точные байты провайдер не сообщает — показывается только процент файлов. Подробности сохраняют счётчики и до 20 путей ошибок своей попытки; длительность измеряется с постановки в очередь. Нативная приёмка остаётся этапу 32.

## Анализ MCP: список, фильтры и подробности

Этап 30 реализован в Svelte. Актуальный исполняемый макет — `ui/preview/mcp-history.html` через Vite (`npm --prefix ui run dev`, `/preview/mcp-history.html`), с вымышленными сценами и отдельной обезличенной записью настоящего IPC-теста. Он монтирует продуктовый компонент и не читает установленный профиль. HTML этапа 27 ниже сохраняет исходное проектирование.

Уточнения реализации: сводка стоит после фильтров, включает все четыре исхода и знаменатель среднего; поля проекта/сессии объединяют точный фильтр с подсказками по части пути/ID всей истории периода (до 200 совпадений, требуется уточнение при ограничении). «Без проекта» — отдельная галочка. «Ещё 50» продолжает серверный курсор, сохраняя открытый вызов; закрытие подробностей служит возвратом к списку. В настройках только этой вкладке доступна ширина до 1400 px; до 900 px содержимого подробности занимают место списка. Подтверждение очистки — встроенный блок с начальным фокусом на отмене. Проверки и снимки (`chats/2026-10-18-mcp-analysis-30`); нативная приёмка — этап 32.

[Макет MCP](mockups/mcp-statistics.html). Настройки → «Статистика MCP». Заголовок, время обновления и «Обновить»; сводка по текущей выборке: вызовы, ошибки, средняя длительность с единицей. Далее пять совместных фильтров: период, проект, сессия соединения, инструмент, исход. По умолчанию последние 24 часа, выбор «Сегодня» или последние 7 дней. Период задаёт окно по времени начала; даты в локальном часовом поясе с явной подписью. Смена проекта сохраняет совместимую сессию; несовместимую сбрасывает с объяснением. Для длинного ID есть поиск сессии. Сброс возвращает все фильтры. Обновление сохраняет выбор; при отказе старые данные не выдаются за свежие.

Список по убыванию времени начала: время, инструмент и проект, исход с текстом, результат с единицей, длительность. Вызов выбирается кнопкой строки, Enter/Space. Выбранная строка выделена; подробности открываются справа, фокус переходит на заголовок. Escape/«Закрыть подробности» возвращают фокус строке. Пагинация по 50; фильтрация до пагинации, итог сводки относится ко всей выборке. Большая сцена содержит 240 вызовов. Пустой фильтр предлагает сброс, первая пустая история объясняет источник данных; загрузка, ошибка чтения с повтором и старая агрегатная история — отдельные сцены.

Подробности: ID, инструмент, проект, сессия соединения, начало и окончание, длительность и граница измерения; результат; «Запрошено / Применено / Причина» в читаемых строках. Поиск показывает query, область, limit, candidates, min_score и rerank. Для read — путь и строки, outline — путь и число заголовков, projects — число проектов, status — состояние проекта, reindex — только принятие задания; количество для status/reindex не применяется. Неизвестное значение — «Не записано», неприменимое — «Не применяется», скрытый текст — «Не сохранён». JSON — вторичное раскрытие; полные документы в макет не попадают.

| Исход | Отображение |
|---|---|
| Успех с данными | «Успешно · 5 фрагментов», длительность |
| Успех с нулём | «Пустой ответ · 0 фрагментов», без красного статуса |
| Принято | «В очереди · количество не применяется», пояснение, что индексация ещё не завершена |
| Ошибка | «Ошибка · результат не получен», безопасный код и причина |
| Обрыв/незавершённый | «Исход неизвестен», нет выдуманного количества или времени окончания |
| Старые агрегаты | Отдельный блок сумм; открыть отдельный вызов нельзя |
| Неполный охват | Постоянное пояснение об учёте обработчика worker; диагностическое предупреждение о потерянных записях |

По OQ-89 панель хранения показывает максимум 7 × 24 часа, локальные запросы и пути, до 10 000 попыток / 32 МиБ данных. «Сохранять подробную историю MCP» включено по умолчанию; отключение оставляет прежние записи, прекращая новые. Очистка требует диалог с областью удаления, включая старые агрегаты, и пояснением независимости исполнения. Сцены скрытых и усечённых полей показывают неполноту конкретной записи, а не альтернативную политику. Для выполняющегося вызова нет выдуманного конца; успех с fallback имеет предупреждение и фактическую шкалу.

## Меню корня, модуля и папки

[Макет дерева и меню](mockups/document-menu.html). Виртуальная группа «Корневые документы» (`.`), модуль первого уровня, вложенная папка и файл представлены разными строками; отдельной строки «Корень документации» нет (убрана автором 19-10-2026). Группа `.` относится только к корневым файлам, её меню адресует docs_root. Правый клик, ContextMenu и Shift+F10 открывают меню для сфокусированной строки без смены проекта, галочек или открытого документа. По уточнению автора 20-10-2026 верхняя шапка с типом цели и путём удалена. Меню компактное: 12 px, пункты с отступами 4×8 px; цель фиксируется при открытии, путь доступен через «Скопировать путь». Корень `.` обозначается явно, вложенный `docs_root` разрешается от корня проекта.

Папка/модуль/корень: «Открыть в Проводнике» (Finder на macOS), «Скопировать путь», «Проверить проект». Пояснение прямо в меню: «Сверит документы с поиском и обновит изменившиеся»; проверяется весь проект; выборочная индексация папки не обещается. Удаления и подменю редакторов у папки нет. Файл сохраняет открытие, подменю редакторов, выделение в Проводнике, копирование пути и проверку по существующему контракту. Пункт проверки недоступен при недоступном проекте или необходимости согласия на смену модели; причина видна текстом рядом, а не только tooltip.

Меню ограничено краями рабочей области; при нехватке места открывается влево/вверх, внутри доступна прокрутка. Up/Down, Home/End перемещают фокус, Right/Left открывают/закрывают подменю файла, Enter выполняет, Escape возвращает фокус исходной строке. Закрытие также по внешнему клику, прокрутке и потере фокуса. Путь копируется только после подтверждения буфера; запуск ОС означает передачу запроса, не доказательство открытия окна. Проверка подтверждает очередь, не завершение. Ошибка пути/буфера/запуска остаётся в сообщении; пропавшая папка допускает копирование последнего пути и проверку проекта, но не открытие ОС.
