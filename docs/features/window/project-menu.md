## Поведение меню проекта

Правый клик по выбранному проекту наверху боковой панели, по проекту в выпадающем переключателе или в списке пустого состояния открывает общее контекстное меню bars. Проект не переключается, дерево, галочки и поиск сохраняются. Контекст определяется абсолютным путём строки, а не текущим выбранным проектом; одинаковые названия не смешиваются.

Порядок пунктов по [модели меню](document-actions.md) для проекта ещё не подключён: сначала «Проверить проект», последним «Удалить проект…». В шаге 3.3.4 переведено только дерево; проект остаётся шагу 3.3.7. Сейчас реализован обратный порядок. Первый пункт — «Удалить проект»: открывает диалог, фиксирующий название и путь нажатого проекта; до явного подтверждения ничего не удаляется. Снятие регистрации `unregister` не заменяет полное удаление. Второй — «Проверить проект»: существующий `reindex` без `full` и без `accept_model_change`, с явным путём проекта. Это сверка файлов, а не принудительная полная переиндексация. Ответ подтверждает постановку проверки в очередь, ошибка показывается уведомлением. Согласие Т-25 не обходится.

## Устройство меню проекта

«Переименовать…» открывает диалог имени нажатого проекта без переключения текущего. Enter сохраняет, «Отмена» и Escape закрывают без записи; во время сохранения повторная отправка и закрытие блокируются. Ошибка остаётся в диалоге вместе с введённым именем. Хранение имени и выбор проекта инструментами описаны в разделе «Что хранит реестр проектов» документа «Реестр проектов bars».

Строки проекта размечены `data-project-path`; единый `ContextMenu` определяет ближайший проект и фиксирует его путь при открытии. Меню файла и поля ввода сохраняют существующие действия. Проверка использует существующий `reindex`; полное удаление — window-only `project_delete` после подтверждения.

Меню закрывается при смене текущего проекта, исчезновении целевого проекта, Escape/Tab, внешнем клике, прокрутке, потере фокуса и изменении размера окна. Общий рендерер обходит стрелками/Home/End все показанные пункты, включая недоступные; их выполнение подавляется. Shift+F10 и клавиша контекстного меню открывают меню у сфокусированной строки.

## Ручная приёмка меню проекта

- В обеих темах открыть меню выбранного проекта и другого проекта в переключателе; исходный проект и поиск неизменны.
- Открыть меню пропавшего проекта в списке, проверить Escape, внешний клик, края окна и Shift+F10.
- Поставить проверку другого проекта: в очереди именно он; при ошибке нет сообщения об успехе. Смена модели требует отдельного согласия.
- Удаление проверять только после реализации этапа 24, на временном профиле и с подтверждением; настоящую документацию не затрагивать.
