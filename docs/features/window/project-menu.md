# Контекстное меню проекта

Статус 18-10-2026: этап 23 реализован в рабочей копии; UI 85/85, check/build и просмотр в браузере на фикстурах пройдены. Установленный Tauri не обновлялся, настоящий IPC и macOS не проверялись. Полное удаление — отдельный этап 24, границы операции ожидают ответа OQ-83; недоступный пункт принят автором в OQ-84. Основание: Т-14, Т-17, OQ-63; [реестр проектов](../projects/projects.md), [меню документов](document-actions.md). [Мокап](mockups/project-menu.html).

## Поведение меню проекта

Правый клик по выбранному проекту наверху боковой панели, по проекту в выпадающем переключателе или в списке пустого состояния открывает общее контекстное меню bars. Проект не переключается, дерево, галочки и поиск сохраняются. Контекст определяется абсолютным путём строки, а не текущим выбранным проектом; одинаковые названия не смешиваются.

Первый пункт — «Удалить проект», недоступный с видимым пояснением «Этап 24» (ответ автора OQ-84, 18-10-2026). Снятие регистрации `unregister` не заменяет полное удаление. Второй — «Проверить индекс»: существующий `reindex` без `full` и без `accept_model_change`, с явным путём проекта. Это сверка файлов, а не принудительная полная переиндексация. Ответ подтверждает постановку проверки в очередь, ошибка показывается уведомлением. Согласие Т-25 не обходится.

## Устройство меню проекта

Строки проекта размечены `data-project-path`; единый `ContextMenu` определяет ближайший проект и фиксирует его путь при открытии. Меню файла и поля ввода сохраняют существующие действия. Новый backend-метод не требуется: окно вызывает существующий `reindex`.

Меню закрывается при смене текущего проекта, исчезновении целевого проекта, Escape/Tab, внешнем клике, прокрутке, потере фокуса и изменении размера окна. Стрелки/Home/End обходят доступные пункты; Shift+F10 и клавиша контекстного меню открывают его у сфокусированной строки.

Браузерная фикстура: тёмная тема — меню текущего проекта; светлая — меню другого проекта в переключателе без смены текущего. [Снимок](../../chats/2026-10-18-project-context-menu/project-menu.png). Это проверка отображения и открытия меню, не настоящей очереди воркера; правильный вызов/параметры и ошибки проверены компонентными тестами. Установка приложения и настоящие профили не менялись.

## Ручная приёмка меню проекта

- В обеих темах открыть меню выбранного проекта и другого проекта в переключателе; исходный проект и поиск неизменны.
- Открыть меню пропавшего проекта в списке, проверить Escape, внешний клик, края окна и Shift+F10.
- Поставить проверку другого проекта: в очереди именно он; при ошибке нет сообщения об успехе. Смена модели требует отдельного согласия.
- Удаление проверять только после реализации этапа 24, на временном профиле и с подтверждением; настоящую документацию не затрагивать.
