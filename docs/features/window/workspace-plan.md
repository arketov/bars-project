# Внедрение панелей рабочего окна

[← Окно bars](Index.md)

Статус: каркас 1.1.4 реализован в рабочей копии по поручению автора 20-10-2026; программный прогон настоящего WebView2 выполнен. Основа — [требования](requirements.md), [актуальный макет](workspace-design.md), [ADR-0003](../../adr/0003-window-docking.md). Открытый OQ-112 не выдаётся за физическую приёмку. Установленная сборка ещё не проверена.

## Устройство переноса

Левая колонка — обычная разметка вне Dockview (OQ-117): дерево, под ним мини-граф, внизу статус индекса, уведомления, тема и настройки. Разделитель между деревом и мини-графом и разделитель ширины колонки управляются мышью и стрелками; минимальная ширина 220 px. Колонка не закрывается и не перетаскивается. Мини-граф — та же физическая панель, что во вкладке «Граф», в компактном виде; показ «Открыть связи и основания в графе» из выдачи открывает экран «Анализ связей» вкладки «Граф» (его действия переносятся этапом 2.3).

Dockview 8.6.1 с прямым lifecycle-адаптером Svelte держит только рабочую область: поиск и служебные экраны в центре, правая группа документов. Кнопка «Граф» открывает полный граф вкладкой центра. Правая группа есть в штатной раскладке; если опустевшая группа удалена, а групп осталось меньше двух, справа создаётся пустая группа. Документ из выдачи открывается в группе других документов, иначе в группе справа от поиска. Состояние смонтированного компонента сохраняется при переносе и переключении вкладки.

Перенос вкладок: `dndStrategy: "pointer"` — Dockview ведёт жест событиями указателя, а не HTML5 drag-and-drop, который в WebView2 перехватывает обработчик файлов Tauri (ISS-21). Окна bars и стенды создаются с `disable_drag_drop_handler()`; перетаскивание файлов в окно bars не используется.

По уточнениям автора: фильтр документов высотой 24 px, сброс области — иконкой рядом с ним; прежняя нижняя строка области удалена.

Раскладка хранится в localStorage с версией 2 и ключом проекта; раскладка версии 1 с панелями навигации и графа молча заменяется штатной. JSON содержит расположение рабочей области, ширину левой колонки, высоту мини-графа и ссылки на документы, без текста документов, ключей и настроек. При восстановлении документ читается заново через существующий read; поздний ответ прежнего проекта не попадает в новый. Повреждённый формат заменяется штатной композицией с сообщением. Команда сброса доступна в меню панелей. Настройки сохраняют собственные Сохранить/Отменить; перенос не перечитывает и не стирает черновик.

Перенос чтения документов не закрывает Т-29/Т-40: полноценный редактор, автосохранение, ревизии и отдельное окно остаются этапу 3.4. Вкладка сейчас показывает настоящий документ и исходник только для чтения; имитация записи недопустима. Физический граф реализован блоком 2 (пункт 2.1.5).

## Оставшиеся работы

- Физические жесты docking в настоящем окне и сверка с макетом автором (ISS-21); программные DOM-действия и синтетические PointerEvent стенда их не заменяют. Воспроизводимый прогон продуктового ui/dist — `scripts/probe-workspace.ps1`, временный профиль и FakeProvider; это не установленное приложение и не настоящая модель.
- Текущие доказательства сборки и программных проверок — [каркас](../../chats/2026-10-20-workspace-implementation/handoff.md), [постоянная навигация и перенос](../../chats/2026-10-21-workspace-sidebar/handoff.md).
- Установленная сборка: трей, меню проекта, Вставить, иконки, обычный установщик, другая папка, другой пользователь, настоящий вход в систему. Рабочее приложение не останавливать; установка только по согласованию OQ-106. Отсутствующие проверки записать точно, ISS-14 по фикстуре не закрывать.
