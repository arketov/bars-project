# Внедрение панелей рабочего окна

[← Окно bars](Index.md)

Статус: каркас 1.1.4 реализован в рабочей копии по поручению автора 20-10-2026; программный прогон настоящего WebView2 выполнен. Основа — [требования](requirements.md), [актуальный макет](workspace-design.md), [ADR-0003](../../adr/0003-window-docking.md). Открытый OQ-112 не выдаётся за физическую приёмку. Установленная сборка ещё не проверена.

## Устройство переноса

Dockview 8.6.1, прямой lifecycle-адаптер Svelte. Слева навигация и граф снизу; поиск в центре, документы из выдачи справа. Все нынешние экраны открываются как панели, вкладки можно переносить и разделять по горизонтали/вертикали. Состояние смонтированного компонента сохраняется при переносе и переключении вкладки.

По уточнениям автора: фильтр документов высотой 24 px, сброс области — иконкой рядом с ним; прежняя нижняя строка области удалена. Статус индекса, уведомления, тема и настройки находятся под графом; при закрытом графе — под навигацией. Геометрия строки обновляется после layout Dockview и изменения размеров окна.

Раскладка хранится в localStorage с версией 1 и ключом проекта. JSON содержит расположение и ссылки на документы, без текста документов, ключей и настроек. При восстановлении документ читается заново через существующий read; поздний ответ прежнего проекта не попадает в новый. Повреждённый формат заменяется штатной композицией с сообщением. Команда сброса доступна в меню панелей. Настройки сохраняют собственные Сохранить/Отменить; перенос не перечитывает и не стирает черновик.

Перенос чтения документов не закрывает Т-29/Т-40: полноценный редактор, автосохранение, ревизии и отдельное окно остаются этапу 3.4. Вкладка сейчас показывает настоящий документ и исходник только для чтения; имитация записи недопустима. Граф переносится существующий; физический граф остаётся блоку 2.

## Оставшиеся работы

- Физические жесты docking в настоящем окне и сверка с макетом автором; программные DOM-действия их не заменяют. Воспроизводимый прогон продуктового ui/dist — `scripts/probe-workspace.ps1`, временный профиль и FakeProvider; это не установленное приложение и не настоящая модель.
- Текущие доказательства сборки и программных проверок — [сессия](../../chats/2026-10-20-workspace-implementation/handoff.md).
- Установленная сборка: трей, меню проекта, Вставить, иконки, обычный установщик, другая папка, другой пользователь, настоящий вход в систему. Рабочее приложение не останавливать; установка только по согласованию OQ-106. Отсутствующие проверки записать точно, ISS-14 по фикстуре не закрывать.
