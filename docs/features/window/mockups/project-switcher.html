Переключатель проектов · шаг 6.1.1

Меню проекта — колонка из трёх частей: поле «Фильтр проектов» (закреплено вверху), список (прокручивается), «Добавить проект…» (закреплено внизу). Высота меню ограничена нижним краем окна; рамка сцены — «окно» высотой 440 px. Каждая сцена показана в обеих темах. Группировка подпроектов (шеврон, отступы, точка «ждёт первого обращения») — отдельный шаг 6.2.4: на сценах 2–3 показано место под неё, код шага 6.1.1 не группирует (дочерние строки появятся с данными parent).

1. Сорок проектов: список прокручивается, фильтр и «Добавить проект…» всегда видны; выбранный проект в видимой части

2. Фильтр «web»: совпавшие строки; предок без совпадения — приглушённая контекстная строка, выбираемая (слот 6.2.4)

3. Клавиатура: фокус на строке (видимый контур), стрелка вправо раскрывает проект с подпроектами; «Ничего не найдено» оставляет «Добавить проект…»

Клавиши: ↓/↑ — по видимым строкам и «Добавить проект…»; Home/End — первая/последняя; Enter/пробел — выбрать; из поля фильтра ↓ — в список; Enter в поле — первая выбираемая строка; Esc очищает поле, второй Esc закрывает меню и возвращает фокус на кнопку проекта; → раскрыть, ← свернуть или к родителю (6.2.4).
