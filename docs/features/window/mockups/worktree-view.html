Worktree в окне · шаг 6.3.6

Папка «worktree» в дереве проекта-владельца, вид worktree, изоляция выбора, вкладка и плашка результата, неактивные граф, аудиты и «Новые темы». Статический файл, обе темы; контракт — features/projects/worktrees.md, раздел «Окно». Данные демонстрационные.

1. Дерево владельца: папка «worktree» после модулей, у каждого worktree — ветка и состояние дельты

2. Раскрытый worktree: обычное дерево корня документации, галочки этого вида; выбор в другом виде снимает прежний

3. Редактор: вкладка с пометкой worktree, плашка worktree у результата поиска

4. Граф, аудиты и «Новые темы» у worktree неактивны
