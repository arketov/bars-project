Вход в граф · 2.3.4

Стенд существующей панели bars, записанные данные двух проектов. Запуск из корня: npm run graph-actions --prefix ui -- --host 127.0.0.1.

  • bars-project · страница графа с поиском в окне
  • overdrive-bots · страница графа с поиском в окне
  • bars-project · панель отдельно
  • overdrive-bots · панель отдельно

Поиск и выбор действия находятся на самой странице графа. В полосе макета переключаются корпус, тема и состояния. Действия документа — над картой и в инспекторе; на узкой панели — в меню «Действия». Инструменты остаются поверх обеих карт; общий список узлов удалён. «Настройки графа» → «Сведения» раскрывает технические данные.

Состояния задания имитируют ответы воркера. «Остановить движение» относится к карте; «Остановить построение» — к заданию. Данные overdrive-bots ограничены 53 документами фич: смысловой слой и близость не загружены. Согласование автора ожидается.
