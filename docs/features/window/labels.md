# Словарь подписей окна bars

Статус: реализация 3.4.6 по OQ-217 завершена 01-11-2026. Ревью Sol без замечаний, целевые тесты и изолированный WebView2 (5/5) прошли; полного зелёного гейта нет из-за параллельных правок, завершение с этим ограничением прямо разрешено автором. Источник — ISS-59 ([реестр проблем](../../backlog/issues.md)) и UX-3 [аудита клиента](../../audits/client-2026-10-23.md). Язык интерфейса — НФТ-4.

## Правило подписей окна

Пользователь видит слова, а не идентификаторы протокола. Идентификаторы допустимы в подсказке, раскрытых технических подробностях и копируемом отчёте об ошибке. Правила самих ошибок — в [экранах ошибок](error-states.md).

Неизвестное значение от более нового воркера получает нейтральную подпись своей группы: «состояние не определено», «причина ограничения не определена». Исходное значение остаётся в подсказке. Известная фраза воркера переводится целиком по таблице; неизвестная техническая фраза не обрезается регулярным выражением. Свободный русский текст сохраняется. Названия, пути, цитаты и текст документов не переводятся.

На основных экранах «чанк» называется «разделом», rerank — «оценкой модели», cosine — «оценкой по близости». В настройках и технических подробностях остаются исходные термины с пояснениями. Поисковые запросы, оценки, пороги, порядок результатов, протокол и ответы MCP/CLI словарь не меняет. Оценки разных видов не становятся одной шкалой.

## Места применения словаря

| Место | Подпись и пояснение |
|---|---|
| Режим поиска в графе | «Обычный», «Со связями», «Отношения и пути»; причина смены режима словами, код в подсказке; в выдаче поиска режимов нет |
| Карточки, граф запроса, похожие разделы | «Оценка модели» / «Оценка по близости»; процент и исходная шкала сохранены |
| Ошибка оценки моделью | «Оценка моделью не выполнена — выдача по близости», «Повторить оценку моделью» |
| Связанные источники | Число источников из справочника источников, ограничение полноты и причины усечения словами; размер ответа в подсказке |
| Граф | Общие подписи режимов, видов связей, состояний и движения; «Без движения (системная настройка)» |
| Сведения графа | «Версия графа — Получена»; исходный хеш в подсказке |
| Утверждения и контекст | Предикаты и роли из словаря; отрицание, условия и цитаты сохраняются |
| Меню проекта и папки, клавиши | «Проверить проект»; «Сверит документы с поиском и обновит изменившиеся» |
| Меню документа | «Проверить документ»; область действия не меняется, подробности — [действия документа](document-actions.md) |
| Анализ вызовов MCP | «Уточнение порядка не выполнено, использован запасной способ»; исходная запись доступна в JSON |
| Индексация и согласие | «Разделов обработано», «раздела/с», «Разделов»; при потере связи — «Показаны последние известные данные» |

Протокол не передаёт время построения графа, только непрозрачную версию. Окно не выводит выдуманную дату и не выдаёт время получения ответа за время построения. Старый экран анализа удаляется отдельным срезом 2.3.9; словарь не требует его восстановления.

## Устройство словаря

`ui/src/lib/labels.ts`: группы режимов поиска, оценок, состояния слоя, полноты и фонового обновления графа, видов связей и узлов, режима карты и движения, уровней, операций, ролей, предикатов, причин усечения и смены режима, действий проверки. `label(группа, идентификатор)` возвращает `{text, hint}`. Закрытые перечисления проверяются через `Record<Тип, Label>`, открытые строки получают запасную подпись группы. Унаследованные свойства объекта не принимаются за записи словаря.

Прежние таблицы `SEARCH_MODE`, `KIND_TITLE`, `STATE_TEXT`, `SCORE_LABEL`, `roleLabels` и таблицы причин в адаптере смысловых действий удалены без совместимых обёрток. Обращение к словарю синхронное: без IPC, загрузок моделей и обхода документов. Причины усечения объединяются без повторов; исходные причины остаются в подсказке.

## Проверка словаря

Тесты таблиц проверяют русские подписи, неизвестные значения и сохранение идентификатора в подсказке. Компонентные регрессии проверяют выдачу, связанные источники, действующую карту и меню проекта; коды не должны попадать в видимый текст. Проверки шкалы и порядка поиска сохранены. Применение к установленной сборке требует отдельной проверки после её обновления.
