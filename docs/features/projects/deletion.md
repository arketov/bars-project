# Полное удаление проекта из bars

Статус: реализовано и проверено 18-10-2026 в рабочей копии. Граница данных подтверждена автором в OQ-83. Связанные требования: Т-5, Т-6, Т-19. Существующее [снятие регистрации](projects.md) сохраняется для CLI и переноса проекта. Установленное приложение не обновлялось; нативная приёмка Tauri и macOS остаётся отдельно.

## Что удаляет полное удаление проекта

Удаляются регистрация в `projects.toml`, индекс и его SQLite sidecar-файлы, временный и старый индекс перестройки, локальный `config.toml` и временный файл записи настроек. Снимаются задания, слежение, отложенные проверки и состояние проекта в окне, включая выбранный путь, результаты, открытый документ и уведомления проекта.

В `.bars/` удаляются только известные рабочие файлы bars; пустая папка убирается. Неизвестные пользовательские файлы остаются. Markdown-документация и `BARS_INSTRUCTION.md` сохраняются побайтно. Общие модели, настройки приложения, ключи, интеграции и другие проекты не затрагиваются. В пользовательских настройках отдельного списка настроек проектов нет: локальные переопределения принадлежат `config.toml`.

Новая сессия агента может снова зарегистрировать папку по Т-6. Постоянный запрет регистрации не входит в удаление; повторное ручное добавление строит новый индекс с настройками по умолчанию.

## Подтверждение удаления в окне

Пункт «Удалить проект» в [контекстном меню проекта](../window/project-menu.md) доступен для выбранного проекта, проекта в переключателе и списке, включая пустой, индексируемый и пропавший. Нажатие правой кнопкой не переключает текущий проект. До реализации подготовлен [мокап](../window/mockups/delete-project.html).

Диалог показывает название и абсолютный путь, список удаляемого, сохранение документов и необратимость. Фокус по умолчанию на «Отмена». Escape и отмена не отправляют запрос. Enter на отмене не удаляет. После нажатия «Удалить проект» кнопки блокируются; показано ожидание остановки индексации. Ошибка остаётся в диалоге и допускает повтор. Цель фиксируется при открытии: смена выбранного проекта не меняет объект удаления.

Успех очищает данные удалённого проекта и выбирает другой проект; последний проект переводит окно в пустое состояние. Поздние ответы старых запросов не возвращают удалённые данные.

## Операция удаления и конкурентные запросы

Новый метод `project_delete` доступен только окну; обязательны точный путь проекта и `confirmed: true`. Без подтверждения никакой записи. MCP и CLI через канал метод не получают. Старое `unregister` не получает новой разрушительной семантики.

Удаление сериализуется с запросами к воркеру, отмечает проект удаляемым, останавливает слежение и снимает очередь. Текущее задание отменяется; операция дожидается его завершения и закрытия SQLite. Отложенные события и проверки не возрождают проект. Блокировка индекса дожидается читателей. Только затем удаляются рабочие файлы, регистрация и runtime. Внешний запрос может отключиться: начатая операция должна завершить очистку.

При недоступной папке удаляется только доступное состояние; на отключённом диске стереть файлы невозможно — диалог сообщает об этом заранее. При ошибке доступа к доступным рабочим файлам успех не возвращается, регистрация остаётся, допускается повтор. Многофайловая очистка не транзакционна: часть рабочих файлов уже может исчезнуть, восстановление из документов — новой индексацией. `.bars`, перенаправленная ссылкой/junction, и общая домашняя `.bars` защищены от очистки.

## Проверки удаления и оставшаяся приёмка

Worker: 168/168 lib-тестов, один отдельный тест настоящей модели намеренно исключён. Новые регрессии: сохранность документов, инструкции, общих настроек и другого проекта; очистка очереди и локальных файлов; текущая индексация на паузе; ожидание читателя; таймер и отложенное слежение; повторная регистрация; исчезнувшая папка; неизвестные пользовательские файлы; заблокированный Windows-файл с повтором; junction; защита пользовательской `.bars`; отключение вызывающей задачи. В обработчике проверены обязательное подтверждение и недоступность метода для MCP/CLI. Protocol: 52/52.

UI: 93/93, Svelte check без ошибок/предупреждений, production build. Проверены точный адресат при одинаковых именах и смене выбора, отмена/Escape, начальный фокус, двойная отправка, ошибка и повтор, последний проект, localStorage и поздние ответы поиска/списка. Проверка `cargo check -p bars-app --tests` пройдена. Clippy worker/protocol с `-D warnings` пройден. Вместо autoreview проведено ручное ревью: выявлено и исправлено завершение watcher под мьютексом при гонке запуска и удаления. Новых зависимостей нет.

Проверки Rust запускались с временным `BARS_USER_HOME`; библиотечные фикстуры отдельно задают временные папки воркера и проектов. Настоящие пользовательские проекты не удалялись. Во встроенном браузере проверены отображение диалога и Escape на заглушке — [снимок](../../chats/2026-10-18-project-deletion/dialog.png). Это не нативный Tauri invoke. Следующая ручная приёмка: удалить временный проект из собранного окна, проверить оставшиеся документы и пустое состояние, затем повторить на macOS.
