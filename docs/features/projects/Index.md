# Реестр проектов

Как папка становится проектом bars и что с ним происходит дальше (Т-5, Т-6, Т-15).

| Файл | Когда читать |
|---|---|
| `projects.md` | Корень при регистрации хуком, пропавшие и перенесённые проекты, снятие с регистрации, исключение вложенных проектов из внешнего (решение и устройство в коде) |
| `worktrees.md` | Git worktree как вид проекта: обнаружение, индекс-дельта, параметр `wt`, поиск и чтение по worktree (Т-48; обнаружение и разрешение цели написаны шагом 6.3.1 без проверки сборкой, остальное — проект) |
| `subprojects.md` | Подпроекты: автопоиск репозиториев с `docs/`, имя `главный/путь`, ленивый индекс, список проектов с прокруткой и фильтром, фильтр `bars_status` (Т-49, Т-50; автопоиск и ленивый индекс написаны без проверки сборкой, фильтр `bars_status` — проект) |
| `deletion.md` | Полное удаление данных проекта, подтверждение, конкурентные задания, проверка |
