# Функции MCP в окне bars

Статус на 10-11-2026: таблица переписана под четыре агентских инструмента шага 5.2.1 (`bars_search`, `bars_read`, `bars_status`, `bars_audit`); пункт 3.7.1 закрыт по прямому решению автора без нативной приёмки. Шесть графовых инструментов остаются отдельными и скрыты настройкой `[mcp] graph_tools` (OQ-162); их строки не изменились. Нативная приёмка и установленная сборка не проверены; это ограничение доказательств, а не открытый пункт реализации 3.7.1.

## Таблица функций пользователя

Основание — Т-37 в [требованиях проекта](../../MAIN_IDEA.md). Требуется действие пользователя, а не копия имени инструмента или всех его аргументов. Состав сверяется с реестром `crates/bars-mcp/src/`.

| Инструмент MCP | Действие пользователя | Где в окне |
|---|---|---|
| `bars_search` (вопрос) | Найти разделы по вопросу, выбрать область | Главный и глобальный поиск, один список; операторы в поле запроса |
| `bars_search` (`occurrences`) | Найти точную строку или регулярное выражение в сохранённых документах | В окне нет: раздел «В тексте» убран (03-11-2026), строку и регулярное выражение ищет только агент |
| `bars_search` (`like`) | Найти разделы, похожие на выбранный отрывок, и документы со ссылками на него | «Похожие разделы» в раскрытой карточке поиска; от найденного соседа можно продолжить поиск; панель ссылок даёт входящие |

| `bars_read` (`view=outline`) | Посмотреть заголовки документа и перейти к разделу | «Структура документа» в редакторе; использует текущий буфер, включая несохранённые правки |

| `bars_audit` (`kind=new_topics`) | Прочитать вопросы без найденных материалов, формулировки и проверки; проверить без увеличения спроса | «Новые темы», список и карточка; «Проверить знания» / «Проверить по всему проекту» |
| `bars_relations` | Посмотреть связи объекта и основания | Граф → «Ещё» → «Анализ связей» → «Связи» |
| `bars_paths` | Найти путь между двумя объектами | Граф → «Ещё» → «Анализ связей» → «Путь» |
| `bars_impact` | Найти затрагиваемые описания от выбранного объекта | Граф → «Ещё» → «Анализ связей» → «Влияние» |
| `bars_context` | Собрать источники для задачи | Граф → «Ещё» → «Анализ связей» → «Контекст», профиль задачи |
| `bars_explore` | Изучить темы, связность, пробелы и кандидаты конфликтов | Граф → «Ещё» → «Анализ связей» → «Обзор», вид анализа |

## Похожие разделы: поведение

Вход — раскрытая карточка обычного результата поиска с действующим ID чанка. Отдельное действие рядом с открытием документа показывает источник и соседей, не заменяя исходную выдачу. ID не вводится вручную. У старого воркера без ID действие недоступно с объяснением.

Используется существующий метод `similar` и [контракт похожих чанков](../search/maintenance-tools.md). По умолчанию — весь проект и лимит из настроек; отдельный выбор модулей относится только к соседям. Галочки файлов главного поиска не подменяются фильтром модулей. Пустой выбор модулей означает весь проект, что явно подписано. Можно задать лимит, применённое ограничение воркера видно пользователю.

Каждый сосед: путь и строки, цепочка заголовков, текст, косинус; действия «Открыть документ» с подсветкой диапазона и «Похожие» от этого соседа. Исходник показан отдельно и не считается соседом. Близость не доказывает дублирование или зависимость.

Порог главного поиска не переносится в `similar`. Дополнительный порог окна (0…1, исходно 0 — без отсечения) фильтрует уже полученных соседей; пользователь видит число оставшихся и применённый лимит. Универсальный ненулевой порог без размеченной выборки не устанавливается.

Загрузка, пустая выдача, пустота после фильтра, неполная индексация, ошибка и устаревший ID различаются. При `chunk_not_found` действие «Обновить поиск» запускает поиск с текущими полем и областью, без автоматической подмены источника. Смена проекта, источника, параметров и закрытие панели обесценивают поздний ответ. Панель не пишет Markdown и не запускает embed.

## Проверки 3.7.1

Проверить таблицу по реестру MCP и доступность каждого входа. Для похожих: точный проект/ID/модули/лимит в запросе, источник отдельно, открытие нужного диапазона, переход к соседу, ограничение лимита, порог, пустота, индексация, ошибка `chunk_not_found`, запоздалый ответ после смены источника/проекта и закрытия. Для структуры — переход к строке заголовка текущего буфера.

Задержку `similar` измерить через действующий воркер на готовых векторах настоящей модели. Время включает CLI и IPC; это не отдельный замер ядра. Исследование не считается нативной приёмкой окна.
