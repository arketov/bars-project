# Инструменты bars для агентов и терминала

Чем пользуются агенты и люди вне окна.

| Файл | Когда читать |
|---|---|
| `mcp-tools.md` | Четыре агентских инструмента (шаг 5.2.1): `bars_search` (вопрос / `like` / `occurrences`, область `in`), `bars_read` (текст, структура, ссылки, автоструктура длинных документов), `bars_status` (сводка по частям с версиями прокси и воркера), `bars_audit` (виды и действия, сводка находок); проект содержимого папки в `bars_read` — аналог ls (OQ-320); пределы узкого запроса, ссылки документа, графовые режимы и скрытые графовые инструменты, свежесть, ошибки и история |
| `search-staging.md` | Текстовый вид ответа поиска по вопросу: ступенчатая выдача, короткая шапка и хвост, слабые совпадения, предел `other headers`, оценка-опора без обрезки, параметр `detail` (ISS-114, ISS-115; шаги 5.1.1, 5.2.1) |
| `agent-layer-project.md` | Проект 10-11-2026: четыре инструмента вместо семнадцати, область `in`, ступенчатая выдача поиска, английские описания, гейт по счётчику (пока проект), порядок реализации; решения автора OQ-294…OQ-302 |
| `module-scope.md` | Проект и замер: модули проекта в инструкции и разбивка выдачи по модулям; с 5.2.1 модули подсказывают области `in`, а описания параметров их больше не дополняют |
| `cli.md` | Команды `bars-cli`, правила вывода и кодов выхода, хук начала сессии |
| `window-parity.md` | Таблица MCP → действие пользователя, похожие разделы в окне и проверки Т-37 |
