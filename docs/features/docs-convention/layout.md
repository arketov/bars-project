# Рекомендуемая раскладка docs

Совет bars для документации проекта (Т-8). Любая папка из списка может отсутствовать, рядом могут лежать свои папки и файлы проекта: общие требования, архитектура, руководства.

```text
docs/
  Index.md                     оглавление
  knowledge/                   база знаний
  adr/                         принятые решения
  features/<name>/             фича
    Index.md                   что это за фича, оглавление
    requirements.md            требования фичи, если есть
    plan.md                    план реализации, пока идёт работа
    <подфича>.md               любые документы фичи
    utils/                     скрипты фичи
  chats/<YYYY-MM-DD>-<тема>/   журнал одной сессии
    log.md
    handoff.md
```

## База знаний knowledge

Знание разработки, которое не описывает продукт напрямую: исследования, сравнения библиотек, замеры, соглашения по коду, найденные грабли. Пишется, когда находка пригодится дальше одной сессии.

## Решения adr

Одно решение — один файл `NNNN-<тема>.md` с четырёхзначным номером по порядку. Внутри: статус («принято» или «заменено ADR-NNNN»), дата, контекст, решение, последствия, отклонённые варианты. ADR — запись о том, почему выбрали так; в отличие от остальных документов он не переписывается под текущее состояние. Новое решение, которое отменяет старое, — новый ADR, а у старого меняется только статус.

## Фичи features

Фича — то, что продукт умеет с точки зрения пользователя: «поиск», «индексация», «окно». Это ТЗ проекта, как в Gramax. `Index.md` коротко объясняет фичу и ведёт на остальные файлы. Документы фичи описывают текущее состояние; `plan.md` живёт, пока фичу делают, и сокращается или удаляется, когда она готова.

Устройство, общее для многих фич (стек, процессы, схема данных), удобнее держать отдельной папкой рядом, например `architecture/`.

## Журнал сессий chats

Папка на каждую сессию агента: `log.md` по ходу работы и `handoff.md` в конце. Правила — [session-log.md](session-log.md). Журнал — история, а не описание продукта, поэтому агент включает модуль `chats` в поиск, только когда ищет, что и почему делали раньше.

## Оформление файлов

То же, что в `BARS_INSTRUCTION.md` ([bars-instruction.md](bars-instruction.md)): `title` во frontmatter, ATX-заголовки, разделы, понятные сами по себе. В каждой папке, кроме папок сессий в `chats/`, — `Index.md` с оглавлением.
