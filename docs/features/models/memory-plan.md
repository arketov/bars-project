# Память моделей bars — отложенная приёмка

Статус 23-10-2026: реализация 4.2.2 закрыта решением автора OQ-155 по выполненным разрешённым проверкам. Запрет OQ-106/OQ-113 на остановку и обновление рабочего bars сохранён; приёмка установленной версии явно отложена. Непройденные сценарии не объявляются пройденными.

Выбранная мера и действие окна описаны во [встроенных моделях](local-models.md), lifecycle — в [архитектуре воркера](../../architecture/worker.md). Замеры, протокол качества и ограничения — в [исследовании памяти](../../knowledge/memory.md). Установщик собран; само наличие установщика не доказывает перечисленные проверки.

## Отложенная приёмка установленной версии

После нового разрешения автора на установку:

1. Смена embed-модели: сохранение, «Позже», возврат прежней модели и согласие Т-25; до согласия нет эмбеддинга документов, после него новый индекс и поиск работают.
2. Скачивание Qwen из настоящего окна: ход, готовность и успешное первое использование; артефакт проверен штатным загрузчиком.
3. Первая загрузка bge-m3 с чистого изолированного кэша: скачивание, готовность, индексация и поиск.
4. Запуск при недоступном Vulkan: упакованный loader и лицензия, CPU fallback Qwen с причиной в runtime; установленная сборка действительно запускается.

Рабочий профиль, индексы, системную подкачку и чужие процессы ради приёмки не менять. `BARS_USER_HOME` разделяет Worker/IPC, но сам по себе не изолирует single-instance Tauri: второй штатный процесс не запускать как независимый стенд при работающем bars. Изолированные стенды используют отдельный identifier и собственный профиль.

## Границы принятой меры памяти

FP16 снижает измеренный активный расход, но не задаёт универсальный жёсткий лимит RAM. Для машин с 8/16/32 ГиБ, слабых GPU и Mac проверенных численных бюджетов нет. Полной атрибуции DML/драйверных выделений тоже нет; эти ограничения сохранены в исследовании и не подменяют принятое автором завершение реализации.

Дополнительный serial/overlap остаётся диагностическим инструментом. Глобальная сериализация в продукт не вводится; этот опыт не является обязательным условием уже принятого FP16-профиля. INT8 и сокращение длины входа/K ради памяти не выбраны.
