# База знаний bars

Новое направление bars: вести документацию в самом приложении, как в Obsidian, — редактор, ссылки между документами, файл папки `index.md`, создание файлов и папок, аудиты знаний и цвета. Требования Т-29…Т-42, НФТ-5 и НФТ-6 зафиксированы 19-10-2026 и живут в `MAIN_IDEA.md`. Проекты устройства написаны 22-10-2026 как предложения агента; реализован редактор (3.4.1, нативная приёмка не проведена) и выбор документа по `[[`. git отложен (IDEA-16).

| `editor-design.md` | Устройство редактора 3.4.1: команды чтения и записи, ревизия и конфликт, автосохранение, закрытие, CodeMirror 6, сценарии E-01…12 |
