# Поставка bars

Как bars попадает на машину пользователя и как обновляется (Т-4; решения автора по OQ-16, OQ-17, OQ-18 от 15-10-2026). Сделана Windows; macOS — когда появится Mac. Лицензии нет, репозиторий приватный: файла `LICENSE` нет.

| Файл | Когда читать |
|---|---|
| `installer.md` | Установщик: состав, папка, обновление поверх запущенной версии, понижение, удаление, как собрать и проверить |

Обоснование выбора формата, подводные камни шаблона и результаты ручной проверки — `knowledge/installer.md`.
