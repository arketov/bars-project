# GraphRAG в bars — техническое задание и внедрение

[← Фичи bars](../Index.md)

Статус: 18-10-2026 текущая частичная реализация остановлена по просьбе автора после проверок, актуализации документов и передачи дел. Используются существующие embeddings и явные связи, новая модель не добавлена; обновление автоматически и локально, один выбранный проект, исходники только читаются. Полная приёмка всех S1–S8 не завершена.

Реализован общий `bars-graph`, source maps/SQLite-публикация, автоматическое обновление, шесть операций, MCP/CLI, поиск hybrid/mix/graph и компонент окна с Cytoscape. [Макеты и renderer-проверки](../../knowledge/graph-renderer-2026-10-18/Index.md) отделены от настоящего окна. Полная приёмка открыта: real-corpus gold/holdout, качество extraction/цепочек/ролей/тем, native Tauri и ресурсный прогон. Наличие реализации и зелёных фикстур не закрывает S1–S8.
