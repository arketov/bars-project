# Новые темы — очередь пополнения документации

[← Фичи bars](../Index.md)

Статус: проект фичи IDEA-14, 18-10-2026. Потребность и расположение строки заданы автором; остальное — предложенный контракт. Сбор, хранилище, внутренний API и экран окна реализованы 19-10-2026; сквозная приёмка на настоящей модели и в собранном окне не проведена.

«Новые темы» собирает вопросы, для которых не нашлись материалы, объединяет повторный спрос и помогает пользователю дополнить документацию. Пункт выглядит как файл с отдельной иконкой и стоит первым в дереве, выше «(корень)». Сбор из окна и MCP идёт через worker; просмотр и управление — в пользовательском окне. «Общий чат» — это поиск окна и MCP (OQ-94, решено 19-10-2026); внешний чат не подключается.

20-10-2026 добавлено меню правой кнопки по теме: «Скопировать» исходный запрос, «Закрыть» с немедленным удалением темы и вариантов. Проверено компонентными тестами; установленная сборка не обновлялась. Контракт — [список и карточка](design.md#список-и-карточка-темы).

- [requirements.md](requirements.md) — исходная идея, границы, сценарии, требования NT-01…NT-12 и приёмка.
- [design.md](design.md) — UX, сбор, состояния, дедупликация, хранение и внутренние операции.
- [plan.md](plan.md) — последовательность реализации и необходимые проверки.
- [design/](design/Index.md) — макеты дизайна; [интерактивный макет](design/mockup.html): строка в дереве, список, проверка материалов, закрытие и удаление; данные демонстрационные.
