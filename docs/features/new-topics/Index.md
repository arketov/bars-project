# Новые темы — очередь пополнения документации

Статус: сбор, хранилище, внутренний API и экран реализованы. Основной сквозной сценарий проверен 23-10-2026 на настоящих bge-m3/rerank в release WebView2; расширенная матрица и установленная сборка остаются открытыми. Калибровка Qwen3 4B и явное объединение накопленных дублей реализованы 23-10-2026; проверки — в `requirements.md`, поведение и границы — в `design.md`.

«Новые темы» собирает вопросы, для которых не нашлись материалы, объединяет повторный спрос и помогает пользователю дополнить документацию. Пункт выглядит как файл с отдельной иконкой и стоит первым в дереве, выше «(корень)». Сбор из окна и MCP идёт через worker; просмотр и управление — в пользовательском окне. «Общий чат» — это поиск окна и MCP (OQ-94, решено 19-10-2026); внешний чат не подключается.

20-10-2026 добавлено меню правой кнопки по теме: «Скопировать» исходный запрос, «Закрыть» с немедленным удалением темы и вариантов. Проверено компонентными тестами; установленная сборка не обновлялась. Контракт — список и карточка (`features/new-topics/design.md`).

- `requirements.md` — исходная идея, границы, сценарии, требования NT-01…NT-12 и приёмка.
- `design.md` — UX, сбор, состояния, дедупликация, хранение и внутренние операции.
- `plan.md` — последовательность реализации и необходимые проверки.
- `design/` — макеты дизайна; интерактивный макет (`features/new-topics/design/mockup.html`): строка в дереве, список, проверка материалов, закрытие и удаление; данные демонстрационные.

Основания: поиск (`features/search/hybrid-search.md`), главное окно (`features/window/main-window.md`), история MCP (`features/window/mcp-statistics.md`), файлы bars (`architecture/files.md`). Исходная идея учтена в IDEA-14 (`backlog/ideas.md`). Новые требования всего проекта в MAIN_IDEA не добавляются, по OQ-67.
