## Подключение внешнего чата

Автор выбрал (OQ-94) поиск окна и MCP; отдельного адаптера в первом объёме нет. Если позже появится внешний чат — нужны конкретный адаптер, стабильный ID обращения, сигнал отсутствия ответа, определение наличия вектора и проверка доставки, и полный исходный сценарий S1…S8 проверяется также для этого источника до заявления о выполнении общего охвата. Чтение всего разговора не подразумевается MCP-подключением.
