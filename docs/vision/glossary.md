# Глоссарий

| Термин | Значение |
|---|---|
| **bars** | Рабочее название продукта, а также имя exe воркера с окном |
| **Воркер** | Единственный на машине процесс bars. Держит индексы всех проектов, следит за файлами, индексирует, ищет (Т-1) |
| **Окно** | Интерфейс воркера (Tauri), открывается из трея. Закрытие окна не останавливает воркер (Т-1) |
| **Прокси, bars-mcp** | Маленький stdio-MCP exe. Клиент агента запускает его на каждую сессию, прокси пересылает вызовы в воркер (Т-2) |
| **CLI** | Команды bars для терминала и хуков (Т-20) |
| **Проект** | Папка на диске, зарегистрированная в bars. Её настройки и индекс лежат в `<проект>/.bars/` (Т-5, Т-6) |
| **Корень документации** | Папка внутри проекта, которую индексирует bars. По умолчанию `docs/` (Т-7) |
| **Модуль** | Подпапка первого уровня под корнем документации. Всё, что глубже, принадлежит ей (Т-7) |
| **Документ** | Файл `**/*.md` под корнем документации. Заголовок берётся из frontmatter `title` (Т-11) |
| **Чанк** | Фрагмент документа — единица индекса и выдачи. Режется по заголовкам (Т-18) |
| **`embedded_text`** | Текст, который реально ушёл в эмбеддинг: документ + раздел + чанк. По нему векторы переиспользуются (НФТ-1) |
| **Гибридный поиск** | Полнотекстовый (FTS5) и векторный поиск, слитые в один список (Т-12) |
| **Реранк** | Необязательная переоценка кандидатов после слияния отдельной моделью (Т-12, Т-16) |
| **Хук начала сессии** | Команда, которую Claude Code или Codex запускает при старте сессии: регистрация проекта по cwd и проверка актуальности (Т-6, Т-10) |
| **`BARS_INSTRUCTION.md`** | Инструкция для моделей о том, как вести документы, чтобы их хорошо индексировать. bars кладёт её в корень документации при регистрации (Т-8) |
| **Образец** | `tz_rag_search`, `rag_query`, `rag_explorer` из Firetech — источник идей и уроков, не кода |
