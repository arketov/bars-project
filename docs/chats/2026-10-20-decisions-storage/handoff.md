# Передача — решения рабочей области и места хранения файлов

## Сделано

В [справке рабочей области](../../features/window/workspace-decisions.md) собраны направления панелей, поиска, клавиш и физического графа; несогласованные Т-43…Т-47 отделены от принятых Т-29/Т-40. Обновлены оглавления окна и графа. В [сборке](../../knowledge/build.md) — target, выход установщика, TEMP, BARS_USER_HOME, общий кэш моделей и уборка; добавлен переход из архитектуры файлов, убраны устаревшие утверждения про OneDrive и совпадение каталога установки с target.

## Не сделано

Согласование раунда 17, четвёртый тип связи и реализация интерфейса не входят в справочную задачу. Параллельные правки MAIN_IDEA.md сохранены отдельно.

## Сложности

bars-поиск не нашёл ответ о новых решениях; известные документы прочитаны напрямую. bars_impact отклонил change_description как неподдерживаемую возможность, вызов по files без roots тоже отклонён; зависимость этим не проверена. Пути сверены по скрипту установщика, тестам и существующим каталогам.

## Дальше

Использовать справку и разделы сборки для двух вопросов автора. Проверены относительные пути ссылок и frontmatter семи документов, git diff --check. Повтор обоих исходных вопросов через bars нашёл новые разделы (rerank 0,984–0,999). Сборка для изменения только документации не требуется.
