# Итог сессии — 5.2.1: четыре агентских инструмента MCP

Предыдущая сессия по теме: [аудит и проект агентского слоя](../2026-11-10-agent-layer-audit/handoff.md) (проект и решения OQ-294…OQ-302); ступенчатая выдача — сессия [2026-11-10-agent-search-staging](../2026-11-10-agent-search-staging/handoff.md) (шаг 5.1.1).

## Сделано

- Шаг 5.2.1 из PLAN.md: `bars_search`, `bars_read`, `bars_status`, `bars_audit` с английскими описаниями и английским `initialize`; семнадцать старых имён удалены без псевдонимов; `bars_reindex` из MCP ушёл (`refresh=true` у `bars_status`). Семь коммитов в `main`: протокол/ядро/воркер, прокси, тесты, правки по ревью (две волны), документация.
- Протокол (`bars-protocol`): область путей-префиксов `paths` у поиска/похожих/дискового поиска; `LikeParams/LikeOutput` и метод `like`; `AuditSummaryParams/Output` и метод `audit_summary`; `paths` в находках; `max_lines`/`headings` у чтения; `exclude_document` у похожих.
- Ядро (`bars-core`): префиксные области через готовый `path_prefixes`, исключение документа-источника у similar (ISS-26), разрешение «путь:строки» в ID чанка (`chunk_public_at_line`), `under` по концу цепочки с подсказкой ближайших заголовков (ISS-112), сводка находок аудита в `AuditStore`, общий `doc_path::like_escape`.
- Воркер (`bars-worker`): обработчики `like` и `audit_summary`, сводный статус перестаёт ронять ответ при ошибке графа (ISS-110), аудиты и новые темы принимают проект именем или путём (ISS-111), валидация `in=` у аудитов с подсказками, журнал истории MCP под новые имена и allowlist аргументов.
- Прокси (`bars-mcp`): модуль `tools/` с четырьмя инструментами; `bars_search` имеет три вида запроса и графовую форму при включённой настройке (надмножество, без `mode` ведёт себя как обычная); `bars_read` с `view` и автоструктурой длинных документов (400 строк); `bars_status` собирает части PROJECT/INDEX/VERSIONS/AUDITS/NEW TOPICS/GRAPH с кэшем версии воркера из `hello` (ISS-117); `bars_audit` с `kind×action` и текстовыми рендерами (ISS-113); `initialize` ≤ 2000 знаков с модулями проекта.
- Тесты: интеграционные `bars-mcp` переписаны под новый набор (`wait_status` ходит к воркеру напрямую); тесты воркера/протокола с новыми полями; Sol-ревью агента в трёх раундах — замечаний нет (особая пометка: производительность, логика, комплексность).
- Документация: [mcp-tools.md](../../features/agent-tools/mcp-tools.md) переписан; `window-parity`, `cli`, `search-staging`, `module-scope`, `Index`, статус проекта агентского слоя; ISS-110…113, ISS-117 закрыты; руководство (`agents`, `audits`, `new-topics`, `projects`).
- Шаг 5.2.2 выполнен коммитами `b4c1e1f` (в нём, помимо правок тестов, переписаны три skill в `crates/bars-worker/assets/skills/` и копия `crates/bars-core/assets/BARS_INSTRUCTION.md`), `4937642` (`docs/BARS_INSTRUCTION.md` под новый набор, next-подсказки графа, `bars-session-log` без `bars_outline`), `0c640b5` (правки по Sol-ревью: оговорка `new_topics` у `bars_audit`, описание BI в оглавлении); ISS-116 закрыт реестром, отметка в PLAN.md стоит.
