## Сложности

- В проекте физического графа не было правил для оценки поиска: пришлось развести rerank и cosine и описать `related`/`graph` без оценки, чтобы не подделывать силу.
- Проверка на случайных наборах не заменяет проверку настоящих запросов: реальные результаты сгруппированы по темам.
- Проверка «хаб без приоритета» слабая: хаб в тесте сам оказывается первым по взаимности/номеру; порядок соседей при этом верно не использует степень.
