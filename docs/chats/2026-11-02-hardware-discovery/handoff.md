# Определение железа — итог исследования 8.3.2

Предыдущая сессия: [подбор моделей в аналогах](../2026-11-01-model-hardware-presets/handoff.md).

## Сделано

- Завершено [исследование определения железа](../../knowledge/hardware-discovery-2026-11-02.md): Windows RAM/DXGI/DXCore/D3D12, GPU/NPU, драйвер и Toolkit; macOS Foundation/Metal/Core ML по первичным источникам. Предложения отделены от действующего продукта.
- Отдельный Rust-спайк `scripts/hardware-probe/` проверен на Windows 11 / RTX 3090; сохранены 20 запусков, независимая WMI/NVIDIA-сверка, SHA-256 и времена. WMI дал около 4 ГиБ вместо описания большой GPU; драйверный API CUDA 13.4 не равен установленным Toolkit 12.6/12.8. Медиана native-снимка — 246 мс; это не SLA.
- Обновлены границы в `features/models/local-models.md`, IDEA-19, исследование аналогов, каталог устройств и оглавления. 8.3.2 отмечен `[x]` по прямому поручению автора; продуктовые настройки и требования не менялись.
- Sol-ревью кода и выводов: замечаний по логике, производительности и сложности нет. Проверены title/H1 новых документов, локальные ссылки и соответствие хешей evidence. Полный check запущен после ревью; результат будет записан перед коммитом.

## Не сделано

Продуктовый детектор/показ — 8.3.7. Mac, iGPU/UMA, положительный NPU, гибридные адаптеры, старые ОС и отказы драйвера физически не проверены. Рабочий CUDA backend и численные резервы моделей не принимались. OQ-212…214 и IDEA-19 остаются открытыми.

## Сложности

Serena и графовые MCP-инструменты недоступны; источники собраны через bars read/search/similar/links, код — доступной навигацией. Общий Cargo-кэш занят параллельными проверками; чужие процессы и кэш не менялись. После начального чистого main появились чужие staged/unstaged изменения; собственный коммит выделяется отдельным индексом.

## Дальше

8.3.3 — память и скорость комплектов каталога. Для 8.3.5 использовать разделение физических пулов, бюджетов процесса и возможностей backend; для 8.3.7 — платформенные API и матрицу непроверенного железа из исследования.
