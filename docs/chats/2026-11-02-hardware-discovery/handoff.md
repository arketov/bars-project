# Определение железа — итог исследования 8.3.2

Предыдущая сессия: [подбор моделей в аналогах](../2026-11-01-model-hardware-presets/handoff.md).

## Сделано

- Завершено [исследование определения железа](../../knowledge/hardware-discovery-2026-11-02.md): Windows RAM/DXGI/DXCore/D3D12, GPU/NPU, драйвер и Toolkit; macOS Foundation/Metal/Core ML по первичным источникам. Предложения отделены от действующего продукта.
- Отдельный Rust-спайк `scripts/hardware-probe/` проверен на Windows 11 / RTX 3090; сохранены 20 запусков, независимая WMI/NVIDIA-сверка, SHA-256 и времена. WMI дал около 4 ГиБ вместо описания большой GPU; драйверный API CUDA 13.4 не равен установленным Toolkit 12.6/12.8. Медиана native-снимка — 246 мс; это не SLA.
- Обновлены границы в `features/models/local-models.md`, IDEA-19, исследование аналогов, каталог устройств и оглавления. 8.3.2 отмечен `[x]` по прямому поручению автора; продуктовые настройки и требования не менялись. Параллельная сессия уже включила этот результат в общий `67187df`, отправленный в main.
- Sol-ревью кода и выводов: замечаний по логике, производительности и сложности нет. Отдельный `cargo clippy --locked --offline --manifest-path scripts/hardware-probe/Cargo.toml -- -D warnings` прошёл. Проверены title/H1 новых документов, локальные ссылки и совпадение evidence-хешей с закоммиченными исходником/manifest/lock.
- После ревью запущен полный `scripts/check.ps1 -Jobs 2`: fmt, clippy и build прошли; компиляция `cargo test` остановилась на трёх E0277 `usize: FromSql` в параллельно изменяемом `crates/bars-core/src/graph/build/job.rs:140`. После форматирования те же вызовы находятся на строках 172/174/175. Тесты и UI-проверки не достигнуты; общий гейт не зелёный. Локальный лог — `.bars-832-full-check.log`, кэш `C:/bt/bars`; временные файлы тестов направлены внутрь проекта через собственный V:, отображение снято.

Чужие исходники, процессы и кэш не менялись; финальная запись содержит только документацию сессии.
