# Определение железа — находки исследования

WMI дал около 4 ГиБ для RTX 3090, DXGI — 64-битный объём. Driver API сообщил CUDA 13.4 при установленных Toolkit 12.6/12.8. Поэтому ёмкость, бюджет процесса и версии драйвера/Toolkit разделены; [метод, данные и ограничения](../../knowledge/hardware-discovery-2026-11-02.md).
