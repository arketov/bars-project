# План

План работы. Выполненные пункты сохраняются с отметкой `[x]` рядом с номером и кратким результатом. Как устроена реализация — в `docs/`, подробная история — в git и `docs/chats/`.

Обновлён: 20-10-2026

## Как читать

- **Этап** — фича или проблема. Под заголовком: цель и ссылка на документ с подробностями.
- **Шаг** — одно конкретное действие для одного агента. Нумерация шагов сквозная по всему документу. Типов три: исследование, проектирование (только если нужно), реализация. Тесты и правка документов — часть реализации.
- Выполненный шаг не удаляется: рядом с номером ставится `[x]`, указываются дата, результат и доказательства выполнения (уточнение автора 20-10-2026).
- Порядок этапов (OQ-66): баги, ломающие работу → приёмка окна → агенты → качество и скорость → новые возможности. Проблемы — [docs/backlog/issues.md](docs/backlog/issues.md), пожелания — [docs/backlog/ideas.md](docs/backlog/ideas.md).
