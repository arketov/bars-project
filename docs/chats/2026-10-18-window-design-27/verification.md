# Проверка интерактивных макетов этапа 27

Статус 18-10-2026: браузерная проверка дизайна на вымышленных данных завершена. Это не приёмка Rust/Svelte, сбора MCP, IPC, действий ОС или установленного Tauri. Макеты запускаются без внешних загрузок; для проверки использован локальный HTTP-сервер, встроенный браузер, viewport 1280 × 720 и рабочая область 760 px.

## Результаты проверки макетов

[64 успешные проверки](checks.json) — утверждения по отображаемому состоянию и геометрии при интерактивном обходе через браузер. Это запись выполненного обхода, не отдельный автоматически воспроизводимый тестовый набор. Синтаксис четырёх JS-файлов проверен `node --check`. Выполнен ручной обзор изменений и соответствия контрактам этапа 26; зависимости не добавлялись.

| Область | Проверено | Соответствие контракту |
|---|---|---|
| Уведомления | Активные/итоги, очередь, подготовка после 100 %, обход без total, запрос паузы/остановки, неполный rebuild, отмена, ошибка модели, готовность файлов и сессии, удалённая цель, короткая операция | N-01…13: состояния, результат и действие различимы; причина перехода не теряется |
| Действия уведомлений | Новая попытка при повторе, очистка сохраняет активные, восстановление связи даёт подтверждённый итог, скрытые карточки остаются непрочитанными, «Прочитать все», новое событие, Escape/Tab и возврат к колокольчику | N-14…16; доставка настоящих событий относится к этапу 28 |
| MCP | Все шесть инструментов, запрошено/применено, ошибка, ноль, очередь, неизвестный исход, выполняющийся вызов, предупреждение fallback; скрытый/усечённый ввод и раскрытие длинного запроса | M-01…03: четыре вопроса автора читаются без JSON |
| Список MCP | Совместные фильтры дают одну ошибку; нет совпадений; сброс; сохранение совместимой сессии и объяснение сброса несовместимой; 240 записей, страницы 1–50/51–100; возврат из подробностей | M-04…05; настоящая серверная пагинация ещё не реализована |

| Меню дерева | Корень без галочки, корневые документы `.`, модуль, папка, файл, пустой индекс, docs_root `.` и вложенный корень, пропавшая папка, недоступный проект, согласие на модель | F-01…11: нужные визуальные состояния; допуск путей требует этапа 31 |
| Действия/клавиатура меню | Правый клик по строке/галочке, неизменный выбор; Shift+F10, Home/End, стрелки подменю файла, Escape с возвратом фокуса; очередь проекта, ошибки буфера/запуска | Действия ОС явно обозначены демонстрацией |
| Темы/геометрия | Светлая/тёмная, рабочая область 760 px, длинные строки, прокрутка; меню 300 × 281 px целиком внутри узкой области; у MCP нет горизонтального переполнения | Отдельная колонка подробностей заменяется экраном с возвратом |

Найден и исправлен дефект самого макета: отложенная прокрутка к кнопке могла закрыть только что открытое меню у края. После исправления повторная проверка подтвердила `inside: true`; фокус не вызывает дополнительную прокрутку при открытии меню.

## Контраст текста макетов

Расчёт по sRGB для пар текст/фон панели: светлая тема — muted 5,99:1, акцент 6,11:1, успех 5,65:1, предупреждение 6,38:1, ошибка 5,46:1; тёмная — 5,65 / 7,19 / 8,16 / 9,01 / 6,33:1 соответственно. Семантический текст светлой темы использует затемнённые оттенки общей палитры. У отключённых действий есть текст причины; цвет не заменяет подпись. Это расчёт указанных пар и просмотр макетов, не полный автоматический аудит доступности приложения.

## Границы проверки этапа 27

Макеты задают композицию и состояния для этапов 28–31. Удержание/доставка событий, сохранение и срок MCP-истории, гонки очистки, реальная очередь, защита путей, буфер и запуск программ в Tauri не проверялись. ISS-13…15 остаются открытыми до реализации и соответствующей приёмки; macOS отдельно не проверена. Этап 32 сравнит собранное окно с этим дизайном. Новые отклонения реализации одновременно вносятся в описание и макеты.
