# Исправление группировки новых тем после смены модели

## Сделано

Причина подтверждена чтением настоящих БД: для Qwen3 4B порог отсутствовал; у реальной пары косинус 0,818915. Старые группы bge-m3 разделены первым представителем 0,655442 < 0,68; поздний вопрос подходит к обеим, но присоединяется к одной.

[Калибровка](../../knowledge/new-topics-threshold-2026-10-19.md): 224 текста, Vulkan, без fallback, порог 0,75 выбран на dev. 61/68 одинаковых пар после проверок, 4/12 552 обычных ложных слияния, ещё 9/37 ловушек; независимая проверка не подтвердила нулевую ошибку. Порог включён только для точного измеренного пространства Qwen3 4B. Реальная пара сохранена в регрессионной фикстуре.

[Поведение](../../features/new-topics/design.md): явное объединение накопленных тем сохраняет формулировки/области/векторы/обращения; обе ревизии и предел 50 защищены транзакцией. После объединения по каждой области остаётся свой семантический представитель. Метод доступен только окну.

Проверки: ядро 29, воркер 17, интерфейс 29 — проходят; svelte-check без ошибок/предупреждений. Доказательства — `core-tests.txt`, `worker-tests.txt`, `ui-tests.txt`, `ui-check.txt`, `analysis.json`, `qwen4.json.gz`. Код прошёл ручную проверку, локальный diff-check чист.

## Не сделано

Рабочий bars и пользовательские БД не изменены. Исправление не применено в установленном приложении; объединение накопленных тем в нём не выполнено. Автослияние всех формулировок одним низким порогом не обещается: замер показывает ложные слияния.

## Сложности

Serena недоступна. Для калибровочного стенда найден локальный libclang в MSVC BuildTools. Агент дополнительно собрал приложение без запроса автора; автор возразил. Дальнейшая сборка/установка не выполняется. Незапрошенный пункт планирования удалён по замечанию автора.
