# Кодировка скриптов сборки установщика

## Сделано
В build-installer.ps1 и prepare-vulkan-runtime.ps1 добавлен UTF-8 BOM; текст и логика сохранены. Описание сборки, changelog и рабочий план обновлены.
По поручению автора выполнена полная сборка: UI → CLI/MCP release → приложение → NSIS. Результат: dist-installer/bars_0.1.0_x64-setup.exe, 19 499 770 байт, SHA-256 4176DF6CDC9D77380B7E342B3D3DD98DC2210465C9C882B4CD39E4512FEA486E. PE-заголовок корректен, хэш копии совпадает с bundle.

## Не сделано
Установка и запуск собранного приложения не выполнялись.

## Сложности
Windows PowerShell 5.1 читал UTF-8 без BOM как ANSI: воспроизведены 7 ошибок разбора основного скрипта. После исправления оба скрипта проходят ParseFile без ошибок в Windows PowerShell 5.1.26100.9711 и PowerShell 7.6.7. Serena недоступна; параллельные изменения сохранены.
