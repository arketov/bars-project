# Журнал — обновление GraphRAG 4.1.3

- Автообновление выполнялось внутри индексации вне реестра graph_jobs: пользователь не мог остановить его graph_cancel. Перенесено в общий путь заданий; пауза сохраняется до явного build.
- Частичный граф требовал отдельного манифеста попытки: исключённый ошибочный файл остаётся в проверке ревизий и покрытии области, но не создаёт evidence.
- Общий прогон: тест исчезнувшей папки удалял её после готовности текста, пока новое отдельное задание графа держало SQLite. Теперь ждёт фактического окончания графа; это подготовка сценария исчезновения свободной папки. Независимый TEI roundtrip упал при параллельных изменениях настроек.
- Первый нативный стенд не передавал обязательный cwd в graph_status. Исправлен запрос стенда; продуктовый API не менялся.
