# Исследование памяти — находки сессии

20-10-2026: после намеренной очистки spikes владельцем большой стенд не восстанавливается: один TEMP-каталог, существующие веса через ссылки только для чтения, гарантированная уборка finally.
Полнопоточные попытки остановлены при смене протокола (137/277 МБ), их нельзя считать ни успешной cold-загрузкой, ни доказательством отсутствия передачи: размер открытого файла в каталоге запаздывал. Использован прежний проверяемый Range-протокол 4 МиБ с SHA256 и последующей нативной BLAKE3-проверкой.

Свежие индексы и 138 вопросов приняты; одна FP16-пара завершилась, повтор не стартовал по commit. Частичный статус сохранён честно; TEMP с весами удалён, общие каталоги целы. Выводы — в memory.md.
