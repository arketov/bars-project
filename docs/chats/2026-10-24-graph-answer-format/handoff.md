# Формат ответов графа для агента (4.3.1) — итог сессии

## Сделано

- Исследование [формата ответов графа](../../knowledge/graph-answer-format.md):
  - обзор GraphRAG, LightRAG, MCP memory, Graphiti, спецификации MCP, рекомендаций Anthropic и пределов Claude Code;
  - четыре черновых формата (J — текущий JSON, A — строка на факт, B — A плюс состояние и следующий шаг, C — компактный JSON) на 37 настоящих ответах замороженного корпуса 20-10;
  - прогон шестью агентами Sonnet по 13 задачам;
  - размер `tools/list`.
- Главное: текст в 8 раз короче JSON. На JSON агенты делают в 2,3 раза больше вызовов. B оценён легче всех, а без строки усечения агент объявил неполный список полным. Графовые схемы — 61 % списка инструментов (≈ 8–11 тыс. токенов); своя схема у каждой операции срезает их до 14 КБ.
- Сырые данные — `docs/knowledge/graph-answers-2026-10-24/`, строки в `knowledge/Index.md`.

## Не сделано

- Живой граф bars-project не проверен: он в состоянии `failed` («ссылка на объект устарела: editor-design.md»), графовые вызовы отвечают `graph_not_ready`.
- Токены — оценка `estimate-v1`, без токенизатора клиента; Codex не проверялся.

## Сложности

- В ответах графа лишь 4 из 25 нужных фрагментов эталона, поэтому прогон проверил честность и удобство формата, а не доставку правильного ответа.
- Черновики не рисуют `path` (mix) и имя темы — на T07/T12 текст проиграл JSON; это дефект черновика, а не вывод против текста.
- Транскрипты субагентов пустые, полные тексты ответов не сохранены.
