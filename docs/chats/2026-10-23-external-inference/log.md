# Другие серверы инференса — находки сессии

23-10-2026: прежние GGUF-замеры проверяли встроенный loader. У TEI обнаружен другой запрос и ответ rerank; нужен явный протокол, а не новые попытки совместимого запроса. [Отбор и причина](../../knowledge/external-inference.md).
23-10-2026: Docker daemon недоступен; готовые Qwen embed/rerank Q8_0 найдены на D:. Для ограниченной аппаратной проверки подготовлен отдельный llama-server b11669/Vulkan; профиль bars изолирован, установленные приложения не заменяются.
23-10-2026: регрессия TEI выявила пропуск обязательного model при совпадении с унаследованным builtin default: set_text сравнивал эффективные значения, а не наличие поля. Сохранение обеих внешних моделей исправлено без смены проверки требований.
23-10-2026: WebView2-стенд исправлен под отдельный экран настроек; проверены выбор TEI, save/readback и три ширины. Автоматическая проверка отклонила удаление собственного portable runtime: blocked by policy; серверы остановлены, каталог в TEMP оставлен.
23-10-2026: попытка поднять установленный Docker Desktop 4.61.0 для настоящего TEI завершилась ошибкой Inference Manager/сокета dockerInference; Docker сам завершился. Ремонт среды вне 5.3 не выполнялся; детали сохранены в docker-error.log.
23-10-2026: после замечания автора работа 5.3 продолжена до результата. Найдена готовая Ubuntu/WSL2 с доступной RTX 3090; TEI запускается отдельным официальным статическим бинарником без ремонта Docker. Release/NSIS собраны, установленный bars не меняется по OQ-113.
23-10-2026: WSL даёт доступ к RTX 3090. Выгрузка OCI-слоя оборвалась HTTP/2 PROTOCOL_ERROR; при новом старте Ubuntu очистился /tmp. Стенд перенесён в /root/Projects/oss/bars-tei-5-3, транспорт HTTP/1.1; OCI digest и SHA-256 неизменны.
23-10-2026: HTTP/1.1 передача того же OCI blob завершилась unexpected EOF на 408944640 байтах. Продолжение — стандартный HTTP Range по существующему файлу; полный SHA-256 обязателен до распаковки/запуска.

23-10-2026: настоящий TEI/CUDA в WSL2 прошёл полный поиск и 422 длинного входа; собственные серверы остановлены, веса сохранены. OQ-153: автор закрыл 5.3, сохранив запрет на установку; итог, контракт и отметка обновлены.
