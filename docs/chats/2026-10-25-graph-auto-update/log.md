# Автообновление графа — находки 2.2.4

- Отдельный scan без изменений не проходит через callback индексации; нужен собственный сигнал графу. Постоянная пауза и проверка `file_errors_total == 0` противоречат принятому проекту 2.2.3.
- Начальная проверка потребовала среды Developer PowerShell, Cargo в PATH и Vulkan SDK; повтор запущен в штатной среде, общий кэш сохранён.
- Первые общие прогоны: гонка статуса MCP, таймауты истории/отзывчивости при полной параллельности; тест корпуса поймал правку документа во время индексации. Полный прогон с `RUST_TEST_THREADS=2`, `-Jobs 2` зелёный без пропуска тестов.
- Тяжёлый тест гонки заменён точным барьером завершения на двух документах; добавлена поздняя отмена при появлении ошибки файла. Проверка сохранённого повтора выявила необходимость считать ожидание без замков отдельно от исполняемой работы.
- Нативный стенд: первоначальный запуск без штатного манифеста не прошёл загрузчик (`TaskDialogIndirect` отсутствует в Common Controls v5). В копию EXE внедрён существующий `graph_probe.manifest`; WebView2 прошёл 14 проверок, результат — `native-result.json`; рабочий bars не затрагивался.
- Финальный параллельный прогон с WebView2 дал отдельные красные проверки MCP history, аудита противоречий и 500-мс отзывчивости. Повтор без стенда идёт последовательно (`RUST_TEST_THREADS=1`), без изменения лимитов и пропуска тестов.
- Итог: 14 нативных проверок и полный последовательный `check.ps1` зелёные; 2.2.4 отмечен `[x]`, ISS-84/ISS-85 закрыты. Установленная версия не менялась (OQ-113).
