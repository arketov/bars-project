# Новые темы — несгруппированные обращения автора

## Сделано

Причина ISS-19 установлена по настоящим векторам: косинус 0,71045551 ниже прежних 0,79, другие условия проходят. По прямому поручению автора порог bge-m3 fp32/fp16 снижен до 0,68. Обновлены NT-04, дизайн, руководство, changelog, планы и ISS-19. `threshold-068.json`: исходная пара допускается; на старом наборе 66/68 одинаковых пар, 11/11 коротких и 20/12 552 обычных разных пар объединяются после проверок. `diagnosis.json` сохраняет исходную диагностику.

Проверено: 23 теста исходного модуля `new_topics` через изолированный Cargo harness, 1 нагрузочный тест ignored; граница ниже/ровно/выше 0,68 и косинус примера автора для fp32/fp16. Источники `store`, `guard`, `tests` подключены напрямую, объявление `ModelFingerprint` извлечено из настоящего файла. Воспроизведение: `pwsh -File docs/chats/2026-10-20-new-topics-grouping/test-isolated.ps1`; вывод — `tests-isolated.txt`. Выполнен ручной просмотр диффа кода; проверки формата и диффа пройдены.

## Не сделано

Сборка и установка приложения не выполнялись; пользовательская БД не менялась. Старые темы смена порога автоматически не объединяет. ISS-19 остаётся открытым до приёмки установленной сборки.

## Сложности

Полный `cargo test -p bars-core --lib new_topics::tests` сначала остановился без `VULKAN_SDK`, после подключения SDK/MSVC/Ninja — на ошибке записи `.fingerprint/candle-core` и вложенном CMake C1083/Invalid argument. Тесты модуля изолированы от inference-зависимостей. Параллельные изменения сохранены.
