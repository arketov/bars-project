# Находки сборки установщика

При попытке Tauri link в offline режиме не найдена локальная ONNX Runtime lib (`OrtGetApiBase`); повторные скачивания остановлены по уточнению автора. Перед продолжением проверить прежний локальный кэш или путь ORT.

Штатный build-installer.ps1 без искусственного CARGO_NET_OFFLINE успешно собрал приложение и NSIS. Предыдущий вывод о необходимости переустановки зависимостей не подтверждён; для сборки использовать существующий PS1.
