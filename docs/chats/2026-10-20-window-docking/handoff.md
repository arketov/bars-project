# Передача — исследование docking, пункт 1.1.2

## Сделано

Пункт 1.1.2 выполнен: [сравнение и метод](../../knowledge/window-docking.md), кандидат Dockview — [ADR-0003, proposed](../../adr/0003-window-docking.md). Инженерная рекомендация не выдана за согласованный дизайн. Обновлены проект окна, справка решений автора и оглавления.

Изолированные стенды: `ui/docking.html`, `ui/src/spikes/docking/`, `ui/scripts/docking-benchmark.mjs`, `crates/bars-app/examples/docking_probe.rs`, конфигурация `docking-probe/tauri.conf.json`, `scripts/probe-window-docking.ps1`. Основной App.svelte не подключает стенд; зависимости кандидата — только devDependencies.

Проверки: 195 тестов / 28 файлов; после последних изменений — 2 профильных теста и svelte-check без ошибок/предупреждений. Основной UI и прототип собраны; Rust example скомпилирован. [WebView2](webview2.json): 6 панелей, 5 исходных групп, перенос сохраняет DOM/ввод, split/JSON/localStorage/recovery, End между двумя вкладками, дочерний Viewer показывает настоящий временный документ, один PID/Shared/WorkerHandler, повторное чтение после закрытия дочернего. FakeProvider, без настоящих весов. [Размеры и ошибка альтернативы](bundles.json). Ручное ревью собственного кода выполнено; общий checkout содержит прежние параллельные изменения, коммит не создавался.

## Не сделано

Макет, продуктовый каркас, drag мышью/физические клавиши, визуальная проверка тем/узкой ширины, редактор/запись и согласованность правок, установленная сборка и macOS. Замечания автора к UX графа и ISS-13…15/17 не закрыты.

## Сложности

Serena недоступна; использованы bars и навигация по исходникам. Частичный граф context не дал полного набора ролей, impact вернул stale_ref; первичные документы прочитаны напрямую, similar проверен. Cargo example нуждается в отдельном manifest и канонической конфигурации в отдельной папке; подробности — исследование. Временный x64 libclang использован без установки в систему. Рабочий bars не останавливался. Уборка последнего прогона столкнулась с WebView2 lockfile; ожидание исправлено, синтаксис проверен, повтор удаления не выполнялся. Автоматическая проверка отклонила обе попытки удаления прежних собственных папок вне репозитория (`blocked by policy`, без детализации); [оставшиеся пути](cleanup-blocked.json). Это не отказ нативных функциональных проверок.

## Дальше

1.1.3: макет композиции автора, обе темы и узкое окно, с проверкой кандидата ADR-0003. Полный перенос экранов — 1.1.4; отдельный редактор и ревизии — работы базы знаний. При повторе начать с команд запуска из исследования, а не прежних неудачных запусков журнала.
