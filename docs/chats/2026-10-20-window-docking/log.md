# Находки исследования docking

20-10-2026: dockview-core 8.6.1 не содержит отдельного CSS; стили нужны из dockview той же версии. Прямой адаптер Svelte собирается; обе зависимости пока только для стенда.
20-10-2026: первый нативный build остановлен отсутствием LLVM по документированному пути. Найден libclang в установленном Android NDK; повтор использует его без установки инструментов и без остановки рабочего bars.
20-10-2026: у Cargo example нет Win32 manifest основного bars; без Common Controls v6 загрузчик не находит TaskDialogIndirect. Собственный manifest устраняет ошибку без изменений системных DLL. Проверяется async-создание дочернего WebView2: синхронная команда может блокировать UI-поток.
20-10-2026: generate_context в Tauri 2.12 читает каноническое имя конфигурации из родительской папки переданного пути. Альтернативное имя в той же папке молча брало основной UI. Стенд перенесён в отдельную папку с tauri.conf.json; выяснено по page-load и IPC trace.
20-10-2026: функциональный повтор WebView2 успешен, после выхода профиль кратко держал lockfile. Ожидание освобождения добавлено в runner. Отдельная уборка прежних собственных папок дважды отклонена автоматической проверкой (blocked by policy); удаление больше не повторялось, пути в cleanup-blocked.json.
