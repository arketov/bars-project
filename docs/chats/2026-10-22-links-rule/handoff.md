# Правило ссылок «ссылка — утверждение о связи» — итог 22-10-2026

## Сделано

Автор заметил, что агенты ставят ссылки слишком часто и беспорядочно, и на граф ссылок нельзя опереться. Причина — правило 21-10-2026 «каждое упоминание документа — ссылка». Замер до правки: 1571 ссылка в 330 документах; шум давали повторы одного документа, пучки по 6–8 ссылок в абзаце, перечни изменённых файлов в handoff, 33 ссылки на `QUESTIONS.md`, 55 крошек «← родитель», 76 ссылок из фич на сессии.

Новое правило — в [соглашении о BARS_INSTRUCTION.md](../../features/docs-convention/bars-instruction.md): ссылка только при названной связи, одна на документ в разделе, без пучков; не ссылаются на `Index.md`, сессии из документов текущего состояния и файлы вне docs. `Index.md` перечисляет файлы именем без ссылок (решение автора). Тот же текст — в `crates/bars-core/assets/BARS_INSTRUCTION.md` (и копии `docs/BARS_INSTRUCTION.md`), skills `bars-docs` и `bars-session-log` (исходники и установленные копии), `features/docs-convention/layout.md`, `manual/writing-docs.md`, `manual/graph.md`, строка об Index в `AGENTS.md` отсылает к skill.

Существующие документы почищены скриптом (механически): ссылки в Index → имена, крошки удалены, ссылки на файлы вне docs и на Index → текст, ссылки фич и архитектуры на сессии → текст с именем папки, повторные ссылки в разделе → текст. После: 1174 ссылки.

## Не сделано

- Не тронуты: `adr/`, папки сессий `chats/`, `MAIN_IDEA.md` и незакоммиченные файлы параллельной сессии редактора (`adr/Index.md`, `features/knowledge-base/Index.md`, `knowledge/Index.md`, `editor-design.md`, `editor-spike.md`) — их почистить после её коммита.
- Пучки ссылок в абзацах скрипт не разбирает: это решается при правке документа по новому правилу.
- Новые skills агенты получат только в новой сессии; проверки поведения агента не было.

## Дальше

Повторно прогнать чистку на файлах сессии редактора после её коммита; через несколько сессий пересчитать ссылки на раздел.
