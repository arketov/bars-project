# Журнал сессий bars

Папка на каждую сессию агента: `<YYYY-MM-DD>-<тема>/` с `log.md` (находки и смены курса по ходу работы) и `handoff.md` (передача дел в конце). Правила — `features/docs-convention/session-log.md`.

Папки сессий здесь не перечисляются: их имена начинаются с даты, последняя сессия — последняя папка по имени. У папок сессий нет своего `Index.md`.
