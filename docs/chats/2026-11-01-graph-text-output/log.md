# Текстовый вывод графа — находки сессии

Исходные интеграции клиентов сохранены в `main` и отправлены в origin до реализации по прямому указанию автора. Логи проверок оставлены локально. Serena и графовые операции bars недоступны; документация найдена через bars, точные вхождения и входящие ссылки. Контракт — [ответ графа](../../features/graphrag/tools.md).

Ревью sol нашло потерю хвоста большого элемента, источников темы и цитат при дедупликации. Исправлены целые единицы, сбор всех участников и предварительное объединение диапазонов. Непомещающаяся обязательная структура отклоняется явно, с советом JSON; скрытый хвост не считается показанным.

Native-сборка не увидела новые поля bars-protocol при их наличии в исходниках и зелёных целевых тестах. Причина не установлена; отрицательный лог сохранён локально. Обновлено время lib.rs для штатной пересборки зависимости, общий кэш не очищался.
