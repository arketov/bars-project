# Текстовый вывод графа — итог 4.3.4

Предыдущая сессия: [схемы графовых операций](../2026-10-28-graph-schemas/handoff.md).

Контракт и исключение для непомещающейся обязательной структуры — [инструменты GraphRAG](../../features/graphrag/tools.md).
- Список окна показывает роли, темы, аудит, фактические состояния и предупреждения; исходный индекс пакета согласован с картой. Обновлены описание CLI/MCP, протокол, руководство и changelog.

- Исходные интеграции Kimi/Ouroboros сохранены и отправлены в `main` до реализации (`f370ce8`, `fbe47b3`); логи оставлены локально.

Для штатной пересборки обновлено время файлов `bars-graph`/`bars-protocol`, кэш не очищался. Serena и графовые операции bars недоступны.
