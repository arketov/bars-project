# Выход воркера на границе документа — находки сессии

Начальный снимок интеграций отправлен в main параллельной сессией (f370ce8…b777200). Автор подтвердил коммит/push общего дерева при продолжающихся правках. Собственный начальный check ждёт общий замок C:/bt/bars. Serena и графовые инструменты bars недоступны; контекст найден поиском и входящими ссылками.

Общего cancel текущего задания недостаточно: оно может появиться после запроса выхода. Наблюдатель должен видеть общий stop. После последнего документа также нужна проверка перед завершающей уборкой/подменой, иначе перестройка успеет заменить старый индекс после остановки.

Ревью sol выявило ожидание pause под write gate и очистку старого last_error при Partial(Cancelled). Оба исправлены, добавлены регрессии; повторное ревью без замечаний. Первый полный check после ревью остановился на форматировании чужих правок; применён cargo fmt. Новый прогон ждёт общий кэш.

Focused-ревью подтвердило позднее начало prepare после stop: первая проверка была лишь перед документом. Добавлены ранний выход job::run и проверки перед lazy prepare в core; регрессии запрещают загрузку модели и создание индекса после выхода. Собственный устаревший check остановлен по проверенному PID; чужие процессы сохранены.
