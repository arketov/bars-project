# Журнал повторного счёта MCP 4.4.4

Неделя после доставки не подтверждается: initialize по-прежнему статический, 4.2.4/4.2.5 открыты. Считается доступный журнал до вызовов этой сессии; приёмочный критерий остаётся открытым. Графовые MCP-инструменты недоступны, опись документов собрана поиском, similar и входящими ссылками.
Живая история уже удалила две поисковые попытки после снятия снимка: прямой повтор SQL дал 1199 вместо 1201. Поэтому проверка и воспроизведение привязаны к сохранённой обезличенной проекции и её SHA-256, а не к повторному чтению обслуживаемой базы.
Полный check снимка прошёл fmt/clippy/build, но четыре теста старого воркера исчерпали ожидание при общем параллельном прогоне. Повторяется весь скрипт с RUST_TEST_THREADS=2 и Jobs=2; тесты, assertions и таймауты не меняются. Код исследования не участвует в упавших тестах.
