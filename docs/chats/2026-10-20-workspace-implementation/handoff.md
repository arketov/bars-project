# Передача реализации каркаса 1.1.4

## Сделано

Продуктовый каркас Dockview 8.6.1: перенос панелей, разделения, вкладки настоящих документов, рендер/исходник, подсветка и скрываемая структура; служебные экраны и сохранение раскладки по проектам. Контракт и оставшиеся работы — [workspace-plan.md](../../features/window/workspace-plan.md). По последним скриншотам автора: фильтр 24 px, сброс области иконкой, статус/уведомления/тема/настройки под графом, бренд в общей шапке сверху слева, единая панель иконок графа 116×26 px с кнопками 20×20 px; поле запроса без переноса и полосы прокрутки. [Снимок браузерной демонстрации](workspace.png).

Проверки: svelte-check без ошибок/предупреждений, 206 тестов, production build; [программный прогон WebView2](native-checks.json) с настоящим read воркера и FakeProvider, обе темы 1440/1024/760 px, компактный фильтр и геометрия статуса. Воспроизведение — `scripts/probe-workspace.ps1`. [Метаданные установщика](installer.json): время, размер, SHA256, MZ; сборка штатным `scripts/build-installer.ps1`. Изменения в рабочей копии, без push; параллельные правки сохранены.

## Не сделано

1.1.4 открыт: физические жесты и сверка автором, установленное приложение (трей, меню проекта, Вставить, иконки, обычная установка, другая папка/пользователь, настоящий вход Windows). OQ-106 запрещает останавливать рабочий bars без согласования; OQ-113 ожидает ответа. Полный редактор/запись/конфликты/отдельное окно — этап 3.4; физический граф — блок 2. ISS-14 по фикстуре не закрыт.

## Сложности

Serena, Chrome и нативное управление UI недоступны; программный WebView2 не выдан за физическую приёмку. Узкий граф наследовал `flex:none!important`/380 px, исправлено в адаптере. После разрешённого переноса target (OQ-115) исправлены 138 сгенерированных текстовых путей с резервными копиями, общий кэш не очищался; [сводка](cache-relocation.json). Vulkan теперь `C:/tools/VulkanSDK/1.4.363.0`. Общий cargo fmt имеет посторонние нарушения; собственный Rust-файл форматирован. Удаление остаточного временного профиля ~92 МБ отклонено автоматической проверкой («blocked by policy»), каталог оставлен, OQ-114.

## Дальше

Ответ OQ-113, затем проверка готового установщика с разрешённым штатным закрытием bars. Физическую и многопользовательскую приёмку фиксировать отдельно; до неё 1.1.4 не закрывать. Остаток временного профиля удалять только после ответа OQ-114.
