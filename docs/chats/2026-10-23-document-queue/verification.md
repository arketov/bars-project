# Проверка продолжения очереди документов 3.2.1

Дата: 23-10-2026. Проверяется [контракт очереди документов](../../features/indexing/document-queue.md), продолжение реализации 22-10-2026. Установленное приложение не обновлялось; приёмка установленного окна остаётся открытой по OQ-113.

## Что изменено и почему

Полные проходы индексатора обходили `DocQueue`; независимый `scan` не публиковал найденные документы до начала обновления. Теперь обнаружение, порядок и обработка документов передаются через `IndexObserver`. Очередь различает документ, ожидающий обработки внутри текущего прохода, и документ, ещё не переданный проходу. Соседнее событие не ставит уже взятые записи повторно.

Завершённые пути исключаются из набора текущего прохода: его итог не удаляет новую правку уже обработанного документа. Правка во время embed возвращается в ожидание и будит таймер после завершения документа. Ошибки остаются до новой правки или явного повтора, включая фоновые проходы после смены нарезки; новая нарезка не отмечается применённой при пропущенных документах.

В настройки добавлена пауза 0…3600 секунд с прежним переопределением проекта. В трее — число ждущих паузы, переход к проекту и сохранение внимания при ошибке документа. Подсчёт трея не сортирует список документов. Для наборов незавершённых путей используется `BTreeSet`, без удаления каждого пути линейным проходом всего списка.

## Ограничения и сборка

Повторный Cargo-прогон индексатора ожидал общий build lock; остановлена только собственная ожидающая команда. Вместо неё выполнены уже собранные актуальные тестовые бинарники, без вмешательства в чужие сборки. Результат Cargo, который лишь ждал, не назван успешным тестом.

Первый Rust-прогон остановился до тестов: C1083 на длинном пути вложенного пробного проекта генератора Vulkan в обычном `target/debug`. Сохранённая диагностика — `build-long-path.txt`. Проверка перенесена в существующий короткий `CARGO_TARGET_DIR=C:/bt/bars`, среда MSVC amd64, Ninja, установленный Vulkan SDK; рабочие процессы bars и чужие сборки не останавливались. Разбор причины добавлен в [руководство по сборке](../../knowledge/build.md).

Не проверены установленное окно, настоящее скачивание модели и отказ настоящего провайдера. Уведомления ISS-13 и переход ISS-17 проверены компонентными тестами, их нативная приёмка остаётся открытой. Замер умолчания паузы относится к 3.2.2.

## Ручная проверка изменений

Проверены переходы состояний, владение записями текущего прохода, новая правка после обработки, пробуждение таймера, отмена и устаревание scan, приоритеты, пропуск ошибок при смене нарезки, отсутствие изменения индекса при несовместимой модели без согласия Т-25, сохранение настроек и границы журналов. Подтверждённые ограничения перечислены отдельно; компонентные и модельные подделки не выданы за приёмку установленного приложения.
