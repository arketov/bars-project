# Смысловые действия графа — итог 2.3.8

## Сделано

- Подключены «Что затронет правка» (кнопка, инспектор, `I`), «Смысловой путь» в полосе пути по карте и меню «Анализ ▾» — «Контекст задачи», «Обзор тем», «Аудит связей»; «Собрать контекст» из полосы подграфа передаёт документы подграфа областью файлов. Правила и отличия от дизайна — [проект действий графа](../../features/graphrag/graph-actions-design.md), раздел «Состояние переноса: шаг 2.3.8»; руководство — [граф](../../manual/graph.md).
- Код: `ui/src/lib/graph/semantic.ts` (запросы `graph_query` v1 и разбор ответов в модели), `PhysicalGraph.svelte` (полосы, инспектор, наложение, клавиша `I`), `draw.ts` (пунктирное кольцо слабых узлов), `physical-api.ts`, `entry.ts` (все четыре действия подключены).
- Тесты: `semantic.test.ts` (на записанных ответах воркера), `PhysicalGraph.semantic.test.ts` (10 сценариев панели); весь `ui/src/lib/graph` — 123 passed, `svelte-check` — 0 ошибок. В браузерном макете пройдены вид влияния и обзор тем.
- Воркер проверен вызовами MCP на bars-project: корень-документ в `impact` даёт пустой ответ, сущности документа по его файлу возвращаются — на этом построено влияние.

## Не сделано

- Обзор тем не перекладывает карту в свёрнутые группы-круги: номера на документах и список. Контекстное меню узла (3.3.7), уровни «Чанки» и «Сущности», фильтры, поле «Задача или тема» на странице не перенесены.
- Шаг выполнен до этапа 4.3: ответ по документу скуден (смысловой слой bars-project почти без межфайловых зависимостей), смысловой путь между двумя документами по одним предикатам обычно пуст. Приведение документа к сущностям на стороне воркера — 4.3.5.
- Проверка в Tauri и на настоящем воркере через окно; Rust-шаги `scripts/check.ps1` не запускались — в рабочем дереве чужие правки Rust и мои изменения Rust не затрагивают. `npm run check` и тесты окна зелёные.

## Трудности

- Первый вариант запроса влияния по документу всегда возвращал бы пусто; выяснено только вызовом воркера, не по описанию контракта.
- Ключи `each` по тексту ответа воркера повторялись и роняли панель; списки ключуются индексом.
