# Передача сессии — этап 11 завершён

## Сделано

Исследование и FP16 rerank в продуктовом коде завершены 18-10-2026. Итог: [скорость и ограничения](../../knowledge/inference-speed.md), [доказательства](../../knowledge/inference-2026-10-18/Index.md), [контракт внедрения](stage11-plan.md). Полный поиск ускорился в 1,6–1,7× без обнаруженных потерь на 138 вопросах; worker private peak 7,36→6,00 ГиБ. Исследовательский IPC — 44 ответа; отдельная приёмка нового loader — 138 core + 22 IPC без потерь/fallback. FP16 DirectML, CPU FP32, tokenizer CPU, GPU batch16→4→1 только при allocation error; pinned weights/tokenizer, BLAKE3 и атомарный manifest кэша. INT8/усечение/MiniLM не приняты из-за потерь.

Финальные проверки: 197 core, 142 worker, реальный CPU FP32. Стенды release собраны. Полная/неизменённая/инкрементальная индексация четырёх вариантов завершена; чистые GPU 57,34→35,81 с. Полные тексты/SQLite другого проекта и веса остаются в ignored data/runs. Установленный bars не обновлялся, коммит/push этой работы не выполнялись; параллельные правки сохранены.

## Не сделано

Ноутбук/слабые GPU и ISS-03, естественный корпус5000/НФТ-2, полный retrieval FP16 embed и его fingerprint/fallback, другие EP. FP16 embed/INT8 CPU не включены. Дополнительные ABBA/binding/cache не нужны для принятого локального результата; полезные микрооптимизации автор разрешил.

## Сложности

Начальная нехватка commit и фоновые сборки исключены из чистого сравнения. Первая копия кэша без refs вызвала повторный download/lock error и CPU fallback; эти прогоны не приняты. Исправленная копия проверена. Serena Transport closed, использовалось прямое чтение; чужие процессы не завершались. Параллельная сессия меняла общий worker: доказательства содержат buildSources/sourceDrift, приёмка относится к испытанному бинарнику. Поздняя core-правка — только HRESULT OOM + два assert, точный diff проверен хешем и unit-тестом.

## Дальше

Применять результаты без повторения широкой сетки: аппаратная проверка ноутбука/малой GPU и отдельная приёмка embed. Lifecycle другой сессии не объявлять физически принятым по этим данным. Публикация/установка требуют отдельного действия; сохранять чужие изменения в общей main.
