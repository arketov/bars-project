# Навигация по графу — находки сессии 2.3.6

- Параллельные пути по взаимным ссылкам (a→b и b→a) давали «варианты» с одним и тем же маршрутом: алгоритм Йена банил одно ребро, а соседнее проходило. Варианты различаются теперь по узлам, запрет ставится на все рёбра пары.
- Наложения (путь, входящие) ложатся на текущую карту, а не заменяют локальный вид: отличие от строки дизайна «одновременно один вид», решено для сценария «Что рядом → Путь до…».
- Скриншот панели браузерного макета отстаёт на кадр (страница в фоне): состояние сверял через DOM.
