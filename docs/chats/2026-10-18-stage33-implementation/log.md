# Сессия внедрения GraphRAG — события

- OQ-85…87: автоматическое локальное обновление, только чтение/evidence, один проект. OQ-91: сначала существующие embeddings/явные связи; новую модель обсуждать после показанного недостатка. [Метод опыта](../../knowledge/graph-embedding-2026-10-18.md).
- Serena MCP отсутствует среди доступных инструментов; использованы bars и прямое чтение исходников. В checkout многочисленные параллельные изменения; не перезаписываются.
- Реальный корпус: 104 документа/579 chunks, parse ~120 мс, kNN ~292 мс. Правила v2 дали 2 отношения, одно с перепутанными участниками; исправлены сегментация и запрет неоднозначного местоименного субъекта (v3). Это development, не приёмка и не обоснование новой модели.
- Автор остановил search_corpus: длительный жёсткий CPU-прогон мешал работе. Не ошибка поиска. Тест сделан opt-in, DirectML без тихого CPU fallback, пачка 1/бюджет 60 с; тяжёлый прогон не повторён, проверка GraphRAG — готовые векторы.
- Development v4 заморожен отдельно: 99 документов/547 chunks, parse+kNN 418 мс без модели; revisions параллельно менялись, v3/v4 не сравнивать как качество. В quotes показаны потерянное условие и составной object; полная смысловая приёмка открыта.
- По просьбе автора срез остановлен: документы/база знаний актуализированы, handoff обновлён. Запрошенный bars_rag_search недоступен (Transport closed), устаревшие места найдены локальным rg; установленный bars ответил CLI status ready/pending=0/last_error=null, без перезапуска.
