# Передача сессии — реализация и открытая приёмка этапа 33

## Сделано

- Восстановлен полный состав этапа 33/P0–P8 и S1–S8; изучены ТЗ, инструменты, исследование, ошибки и прошлый handoff. Ответы OQ-85…87/91 записаны: автоматически после изменений, только локально, один проект, только чтение/evidence; сначала существующие embeddings/явные связи, дополнительную модель обсуждать после показанного недостатка.
- `bars-graph`: source maps исходного UTF-8/BOM/CRLF/CR, links/anchors, ObjectRef/revisions, типизированные явные отношения, SQLite-публикация/инвалидация, шесть bounded операций, цельные evidence paths, scopes/cursors, модульные/тематические группы и кандидаты аудита. Extractor `explicit-markdown-v4`, DTO/schema графа 1 независимо от embeddings schema 1. Семантика partial, не полная модель русского языка.
- Core: chunk spans без изменения текста embeddings, cosine kNN на сохранённых векторах, расширение кандидатов до rerank/top-K без снижения порогов; read-only SQLite, отбор контекста по ролям одной существующей resident query-моделью с переиспользованием query vector. Новые модели/внешние providers не вызываются. Профили implementation/investigation/decision, ранняя валидация до инференса; budget сначала сокращает дополнительные основания, сохраняя роли.
- Worker: автообновление после публикации индекса; explicit jobs/cancel, остановка/рестарт/retry, транзакционная защита source manifest, stale refs/snapshots. MCP/CLI и Tauri handler используют общий контракт. Старый SearchParams/SearchOutput сохранён; явные hybrid/mix/graph, include_related/related_budget, явный fallback. MCP только читает.
- UI: Cytoscape загружается при открытии GraphPage; пять видов, общий/локальный граф, шесть операций, inspector/quotes/переход к текущему файлу, ambiguity endpoints, pin/camera/bounded layout/destroy, scope/theme/узкое окно. Search показывает отдельные цепочки/отношения с основаниями и отключением related. Headless использует записанные Rust DTO, явно обозначенные фикстурами; не считать настоящим backend.
- Rust-драйвер `spikes/graph/knn.rs`, read-only export/analyze и тесты стенда `scripts/graph-embedding-probe*`. [Отчёт](../../knowledge/graph-embedding-2026-10-18.md): заморожены 104 документа/569 chunks/1024 dim; 8 настоящих MCP-вопросов и 9 графов. Все 160 hits совпали со snapshot. Наивное добавление соседей вытесняет часть исходников; необходимости новой модели это не доказывает.
- [Renderer/макет/компонент](../../knowledge/graph-renderer-2026-10-18/Index.md): одинаковые графы Cytoscape/Sigma, 39 проверок макета; компонент проверен отдельно, обе темы/1440/760. Frozen sources/quotes/24 assertions/измерения сохранены. Изменяющийся параллельный индекс не сравнивать между v1–v4 как качество.
