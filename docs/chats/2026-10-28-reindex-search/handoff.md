# Поиск при ожидании переиндексации — итог 3.4.2

## Сделано

- ISS-46: `app.search()` при `reindex_required` запускает только «В тексте», поиск по смыслу воркеру не отправляет и снимает прежнее уведомление «Ошибка поиска»; ответ `reindex_required` воркера (проект ещё не обновился в списке) уведомления не создаёт (`app.svelte.ts`).
- [Экраны ошибок](../../features/window/error-states.md), раздел «Нужна переиндексация», и [руководство по поиску](../../manual/search.md) описывают код: поле запроса доступно, баннер на месте выдачи по смыслу. Статус ISS-46 в `backlog/issues.md`.
- Тесты: два новых в `text-search.test.ts`; сброс уведомлений в `beforeEach`. Весь vitest — 634 теста зелёные, кроме `DocumentWindow.test.ts`.

## Не сделано

- `DocumentWindow.test.ts` не разбирается (чужая незавершённая правка в рабочей копии), поэтому `svelte-check` показывает 8 ошибок только в нём. `scripts/check.ps1` не запускался: Rust этим шагом не менялся.
- Проверка в браузере и в собранном окне не выполнена; заглушка `mock.ts` отвечает `reindex_required` на `search`, но сцены для неё нет (ISS-53).

## Сложности

- В рабочей копии параллельно правятся Rust-крейты, `Workspace.svelte`, `editors*`, `DocumentWindow*`; в коммит вошли только файлы этого шага. `app.svelte.ts` в HEAD со смешанными LF/CRLF: коммит собран патчем без правок окончаний строк.
