# Строки трея открывают свой проект — итог 3.5.4

## Сделано

- ISS-43: `tray.rs` запоминает проект строк индексации и внимания при каждом обновлении меню и передаёт его в `bars://navigate`; «Проекты» шлёт вид `projects`. Окно (`App.svelte`, `app.openProjectsMenu`, `Sidebar.svelte`) возвращается на главный экран и раскрывает список проектов, не меняя выбранный. Маршрут вынесен в чистую `route`.
- Строка меню теперь обновляется и при смене самих строк, а не только подсказки.
- Тесты: `tray::tests` (2), `project-menu.test.ts` (проверка «Проекты»). Описание — [ход индексации](../../features/window/indexing-progress.md), [устройство окна](../../features/window/implementation.md), статус — [ISS-43](../../backlog/issues.md).
