# Исправление ISS-17 — переход и итог индексации

## Сделано

- Воспроизведён `each_key_duplicate` в Svelte: running и queued одного проекта имели ключ `project`. Разделены ключи заданий; счётчик очереди считает задания.
- Переход из уведомления проверяет эпоху/цель, затем открывает страницу без ожидания tree/status. Общий экран ошибки связи больше не скрывает страницу; показан сохранённый снимок с предупреждением.
- «Последний проход» читает подтверждённые результаты из последних 1000 завершений worker, отдельно от карточек. Показывает состояние, время, счётчики, применение индекса, причину и пути ошибок. Без результата нет заявления об актуальности. Одновременные чтения объединены; история обновляется при завершении, смене эпохи или повторе после ошибки.
- Обновлены контракты окна, руководство, changelog; ISS-17 удалён из открытых проблем, пункт 2 отмечен выполненным.
- 13 новых регрессий: работа+очередь одного проекта, клик «Подробнее», переход из центра в полном App, занятые tree/status, завершение, success/partial/error/cancelled, ошибка связи, очистка карточек, недоступная цель, перезапуск worker. До исправления страницы 7 из первых 8 тестов падали, включая точное воспроизведение duplicate key. Итог: `npm test` — 188 passed; `npm run check` — 0 errors/warnings; `npm run build` успешен. Ручной просмотр диффа выполнен вместо отдельного autoreview.

## Не сделано

Нативные клики установленного Tauri-окна и настоящая индексация для этой регрессии не проверялись. Проверка UI — Svelte/jsdom с управляемыми ответами API, без настоящей модели. Установка, публикация и push не выполнялись. Общая приёмка окна (ISS-13…15) остаётся открытой.

## Сложности

Serena MCP отсутствует среди доступных инструментов; использованы локальное чтение и rg. Документы изучены через bars. Изменения MainNavigation и соседних сессий сохранены.
