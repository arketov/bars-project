# Проект CUDA 8.1.3 — находки

Начальный main чист; push и pull --ff-only без изменений. Позже появились параллельные правки других этапов; они сохраняются. Serena и графовые context/impact/relations/explore недоступны, карта документов собрана через поиск bars по модулям, точный текст, similar и входящие ссылки.

Исследование 8.1.2 не принимает скорость и обнаруживает пересечение порога rerank. Проект сохраняет консервативные ускорители и требует продуктовой численной матрицы. CUDA13/поставка DLL остаются решениями автора; Т-3 до согласования не меняется.

Сверка исходников ort rc.13 обнаружила CUDA12 в preload helper при автопакете CUDA13. Уточнена проверка драйвера: minor-version compatibility не позволяет сравнивать только номера Driver API и runtime. Выводы записаны в исходное исследование устройств.

Автор уточнил: «Нужна поддержка cuda 12 и 13». OQ-224 закрыт; проект переработан под две major, динамические ORT с DirectML/CPU и один выбранный комплект на процесс. Собственная комбинированная сборка обозначена риском первого шага 8.1.4; наличия готовых CUDA-архивов недостаточно для утверждения поддержки DirectML.

Автор принял переработанный проект и дополнение Т-3. OQ-225/241 закрыты; Т-3, критерий приёмки и журнал раундов обновлены, 8.1.3 отмечен выполненным. Это завершение проектирования, не реализация или аппаратная приёмка 8.1.4.
