# Полная близость чанков — итог 2.2.6

## Сделано

- Полный точный парный kNN без миллиона сравнений: квант 2 с, checkpoint, отдельный подготовленный набор и полное основание в SQLite, точный пересчёт правок/добавлений/удалений, запись рёбер через ID. Контракт — [реализация GraphRAG](../../features/graphrag/implementation.md), хранение и публикация — [архитектура графа](../../architecture/graph.md).
- Семь регрессий ядра/SQLite; release-сверка 2149/3510 чанков размерности 2560: результат, checkpoint и правка совпали с прежним точным оракулом. Ядро 5,3/14,6 с; отмена внутри ядра — 20 мс. Метод, альтернативы и ограничения — [исследование близости](../../knowledge/chunk-similarity.md); сырые результаты — `measurement.json`, `measure-release.log`.
- Изолированный Tauri/WebView2: 14 проверок (`result.json`); типы UI 0/0, весь UI — 501 тест в 64 файлах (`ui-check-final.log`, `ui-test-final.log`).
- Автор принял фиксацию с блокером общего check (OQ-192, 25-10-2026); 2.2.6 отмечен `[x]`, ISS-82 исправлен. Bars-end согласовал оставшиеся описания строк/пар и статус фичи, перенёс нюансы запуска проб в `build.md`. Руководство описывает продолжение и точную правку.

Это результат запуска, не утверждение о последующих чужих правках. Установочная приёмка отложена по OQ-106/OQ-113. Сквозные время/RAM/поиск на 50 тысячах чанков не измерены. Коммита и push нет; bars-end код и отметки плана не менял.

## Сложности

Serena недоступна. PowerShell требовал Rust PATH, MSVC/Vulkan и существующий x64 libclang. WebView2-примеру потребовались Common Controls manifest и локальные CRT/DirectML; mock read — revision, стенду — ожидание ready. Успешный запуск и границы его доказательств описаны в [сборке и пробах](../../knowledge/build.md). LNK1104/E0463 наблюдались при параллельных сборках, причина не доказана; отдельный прогон упал на истории MCP (2/3 записи) и 500-мс таймауте поиска. Пороги не ослаблялись. Тяжёлый debug-оракул остановлен по собственному PID и заменён лёгкой release-пробой production-модулей; precision f32-спайка не переносилась на продукт. Рабочий bars не останавливался.
