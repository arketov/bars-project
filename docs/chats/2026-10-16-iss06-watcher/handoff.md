# Передача сессии: ISS-06 и IDEA-07

## Сделано

- Слежение (`crates/bars-worker/src/worker/watcher.rs`, `mod.rs`): событие `Rescan` для флага потери и события без путей; полная проверка через 5 секунд после пачки событий (`arm_tail`), с повтором, пока проверка находит изменения при молчащем слежении; перезапуск слежения, если периодическая проверка нашла изменения без единого события; упавшее слежение поднимается этой же проверкой.
- Периодическая проверка — раз в 15 минут вместо часа.
- Кнопка «Проверить сейчас» на странице проекта (`ui/src/lib/IndexingPage.svelte`), шлёт `reindex` без `full`.
- Тесты: сотни файлов на уровне слежения и воркера, «оглохшее» слежение перезапускается. `cargo test -p bars-worker --lib` — 116 прошло.
- Документы: `features/indexing/updates.md`, `architecture/worker.md`, `issue.md` (ISS-06), `user_ideas.md` (IDEA-07).

## Не сделано

- Не проверено на реальном потоке файлов агента (`overdrive-bots`) и руками в окне; интерфейс не запускался.
- Интервал 15 минут выбран агентом без замера стоимости проверки на большом корпусе.
- Проверки «тест падает без исправления» не было.

## Сложности

- `notify` на Windows не даёт воспроизвести потерю событий стабильно: тесты проходят и без исправления, если буфер не переполнился. Защита проверена по логике и тестом «оглохшего» слежения.
