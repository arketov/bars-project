# Исследование 4.2.1 — находки

23-10-2026: прежние данные не закрывают повтор FP16 и 1/2/4 поиска; стенд продолжает [протокол памяти](../../features/models/memory-plan.md). В начале свободно около 6,3 ГиБ commit при резерве пары 8 ГиБ; рабочий bars PID 28748 сохранён, запуск моделей запрещён до достаточного запаса.
23-10-2026: pair-1 отклонён: загрузка rerank 26,3 с превысила TTL embed 20 с; release_idle делает blocking drop embed перед rerank, wait(15 с) истёк. Стенд теперь закрепляет embed до проверки rerank, затем снимает override; таймауты не увеличены. Данные неуспешного опыта сохранены, TEMP удалён.
23-10-2026: первый фикс стенда неполон: pin снимался перед вторым drop rerank, вновь допуская blocking drop embed первым. Reload уже прошёл с delta=0; проверка отключения rerank — timeout. Pin теперь снимается только после обеих проверок rerank; runner продолжает независимую IPC-матрицу после ошибки пары.
23-10-2026, продолжение по просьбе автора: свободный commit около 9 ГиБ. Порядок изменён: FP32-матрица первой, затем один FP16-артефакт, пара и FP16-матрица на том же снимке корпуса; предыдущие доказательства сохранены.
Продолжение: FP32 off/1 остановлен Monitor при system commit headroom <1 ГиБ; allocator-журнал сохранён. Собственная пересборка пары пересекалась с измерением — остановлена только её ветка cargo; перенос сборки на скачивание FP16. Следующая запланированная серия работает отдельно.
Продолжение: FP32 off/2 завершён, 100/100 стабильных выдач при indexing=true; полный rebuild 217,7 с, private peak 5042,9 МиБ. Последующие старты обнаружили ошибку прогрева стенда: unchanged-индекс не грузит embed. Исправлена явная prepare/readiness до единственного IPC-прогрева; копия исходного корпуса сохранена gzip с SHA-256 (0,84 МиБ) для точного повторения.

23-10-2026: OQ-151 — выделенного окна нет, все работают. Сохраняем общую нагрузку; дополнительные серии на 48 самых длинных документах замороженного снимка, полные тексты и прежние защитные границы. Полный FP32 off/2 остаётся отдельным результатом.

23-10-2026: фазовый разбор принятого FP32 off/2 — sampled peak повторной индексации выше предшествующего лишь на 1,17 МиБ, при удержании около 4,89 ГиБ до её запуска. Начальная индексация входит в предшествующий интервал; это не атрибуция allocator и не оценка её отдельной стоимости.

23-10-2026: два независимых FP16 lifecycle приняты под общей нагрузкой: DirectML/FP16, оба drop/reload/disable, 15 оценок совпали точно, shutdown. Lifetime private peak 4403,3 / 4432,9 МиБ; после shutdown 140,7 / 156,6 МиБ. Матрица продолжается, рабочий bars сохранён.

23-10-2026: на срезе 47 документов / 620 чанков приняты FP16 off/2, off/4 и on/1, по 100/100 ответов при индексации. On/1 peak private commit 5135,6 МиБ, выше fixture пары; вклад длинных входов и одновременного embed/rerank пока не разделён. Это ограничивает выводы о достаточности FP16 для 4.2.2.

23-10-2026: FP16-матрица завершена: 600/600 поисков корректны и пересекаются с индексацией; четыре процесса приняты целиком, off/1 и on/4 позже остановлены защитой по commit. TEMP удалён. Финальный snapshot bars: PID 38128 / 14:50:05 вместо исходного 28748; причина смены не устанавливалась, runner управлял только собственными стендами.

23-10-2026: исследование завершено, 4.2.1 отмечен [x]. Все 12 конфигураций дали 1200/1200 корректных ответов при индексации; 10 полных процессов, два защитных выхода после ответов сохраняются отрицательными результатами. Пять проверок анализатора проходят; оба финальных TEMP удалены. Продуктовая мера и ISS-18 остаются открытыми.
