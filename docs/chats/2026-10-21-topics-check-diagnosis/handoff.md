Параметры каждого варианта сохраняются в снимке, первые параметры обращения читаются из существующих observations. Экран показывает исходную и текущую оценку, нейтральные совпадения; полностью пустая проверка по одному индексу снимает прежнюю автоматическую находку, сохраняя решение пользователя и историю.

Проверки: 226 UI-тестов, финальные 24 профильных теста, svelte-check 0/0 и production UI build. Rust: 25 тестов core и 16 worker прошли, один прежний измерительный тест ignored — [журнал](rust-tests.log); настоящая SQLite/индексация/обработчик с FakeProvider, не проверка качества настоящих bge-m3/reranker. Новый SQL отдельно read-only проверен на исторической теме 5: возвращает исходные rerank/0,18.
