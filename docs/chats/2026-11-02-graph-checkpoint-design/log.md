# Разделение checkpoint графа — находки проектирования

2.2.8 — проектирование; кодовое исправление отдельно в 2.2.9. Обнаружены дополнительные границы: большой manifest тоже остаётся в метаданных, а Active проверяет собственную эпоху входов. В [проекте хранения](../../architecture/graph.md) изолированы оба счётчика, предусмотрены rowid-метаданные, сброс Active и проверка дискового checkpoint по полному ключу.

Ревью выявило неполноту дискового input_key и окно между публикацией/финализацией. Проект дополнен проверкой манифеста чанков и совместимого legacy resume; запись поколения, complete и очистка временных payload объединены одной транзакцией. Код текущей v1 не менялся.

Полный check после ревью: fmt зелёный, clippy E0425 — параллельный history.rs:315 вызывает отсутствующую bars_protocol::count_lines. Код этой задачи не менялся; результат не объявляется зелёным, коммит содержит только документацию 2.2.8.
