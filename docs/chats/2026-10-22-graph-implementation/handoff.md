# Передача — реализация физического графа 2.1.5

## Сделано

- Пункт 2.1.5 реализован: [проект и реализация](../../features/graphrag/physical-graph.md), [дизайн](../../features/graphrag/physical-graph-design.md), [проверка на настоящих данных](../../knowledge/graph-render.md). Макет 2.1.4 согласован ([OQ-118](../../../QUESTIONS.md) закрыт: окно модели 0,60–0,95, порог 0,82, яркость ссылок прежняя, настройки отдельно для мини- и полного графа).
- Rust: `crates/bars-graph/src/physical.rs` (проекция, пределы, срез), `crates/bars-core/src/graph/centroid.rs` (близость документов), метод `graph_physical` только для окна (`bars-protocol`, `bars-worker/src/handler/graph.rs`), кэш близости по снимку. Тесты: 7 проекции, 3 centroid, 1 на настоящем воркере (срез, раскрытие чанков, устаревший снимок, закрыт для MCP и CLI); `cargo test` bars-graph, bars-protocol, bars-core graph, bars-worker проходят.
- UI: `ui/src/lib/graph/` — одна панель `PhysicalGraph.svelte` для мини-графа и вкладки «Граф», физика d3-force в Web Worker с поколениями и запусками раскладки, Canvas2D, устойчивые индексы узлов при раскрытии и «Показать ещё», настройки по панелям. Прежний экран анализа сохранён кнопкой «Анализ связей» (ADR-0004: действия GR-05 переносятся в 2.3). 38 новых UI-тестов, всего 269; `svelte-check` без замечаний.
- Проверка в собранном приложении: `scripts/probe-graph.ps1` — WebView2, изолированный воркер, **копии** документации обоих проектов; [результат](webview2.json) успешен (worker под CSP, IPC, режимы, раскрытие, три размера окна). Замер по готовым индексам только для чтения — [real-index-probe.json](real-index-probe.json) (`physical_slice_probe`).
- Документы: протокол, архитектура графа, руководство, ADR-0004 («Где применяется»), Index графа, окно (требования, план панелей), CHANGELOG, план.

## Не сделано

- Физическая приёмка автором и установленная сборка (OQ-113): жесты, перенос и размер панелей в реальном окне, длительный idle, CPU и память, слабая GPU, macOS.
- Порог по умолчанию: centroid даёт вдвое больше пар при 0,82, чем kNN макета; автор выбрал 0,85 ([OQ-121](../../../QUESTIONS.md) закрыт), внесено в продукт и документы.
- Вид запроса (2.2.3) и перенос действий анализа в новую панель (2.3.2); проверка centroid на размеченном корпусе (3.8.2); kNN документов внутри области (сейчас область отбирает пары, слой помечается «частично»); близость чанков остаётся «частично» из-за прежнего предела построения в миллион сравнений.
- Стенд `ui/src/spikes/graph-design/` не менялся этой сессией; в рабочем дереве его правит параллельная сессия 2.2.2.

## Сложности

- Сборка bars-core в длинном пути `Рабочий стол\...` падает в генераторе Vulkan: помогает `CARGO_TARGET_DIR=C:/bars-build`, `CMAKE_GENERATOR=Ninja`, `CMAKE_BUILD_PARALLEL_LEVEL=1`.
- `cargo fmt -p` переформатировал чужие файлы (`bench_duplicates.rs`, `guard.rs`, `tests.rs`); возвращены `git checkout`, остальные правки не затронуты.
- Камера: первое вписывание срабатывало до конца раскладки, и плотный граф обрезался; теперь автовписывание плавно следует за ростом, пока пользователь не тронул камеру.
- Эффект на `app.project` пересоздавал модель при каждом перечитывании списка проектов; зависимость заменена производной по пути.
