# Передача — реализация сочетаний клавиш

## Сделано

Реализация 1.3.2 в рабочей копии: каталог/физические клавиши/конфликты (`keybindings.ts`), синхронизация профиля, маршрутизатор и адаптеры существующих экранов; список действий, перенос и изменение размеров без мыши, раздел настроек с черновиком/записью/заменой/сбросом. Будущие редактор, файловые операции и новый граф недоступны с причиной. Исправлены сброс раздела клавиатуры при открытии настроек, выбор первой вкладки вместо активной группы, конкурирующий Escape MCP и переполнение узкой панели. Текущий контракт — [keyboard-design.md](../../features/window/keyboard-design.md).

Воркер — единственный писатель `keybindings.json`: ревизии/CAS, временный файл и атомарная замена, сохранение второй платформы/неизвестных ID, защита повреждённого файла, событие окнам. Release WebView2 отключает browser accelerators; стенд использует тот же helper и читает настройку обратно.

Проверки: 224 UI-теста, svelte-check без замечаний, production UI; 3 изолированных теста самого Rust-модуля хранения через `rustc --test`. Программный WebView2 с настоящим IPC/FakeProvider: общий поиск, список действий, будущие команды, запись/переназначение/сохранение/подсказка, конфликт ревизии, обе темы на 1440/1024/760 px; readback browser accelerators — false. Сводка: [verification.json](verification.json). Доказательства: [webview.json](webview.json), [ui-tests.log](ui-tests.log), [ui-check.log](ui-check.log), [storage-tests.log](storage-tests.log). Установщик — штатный `build-installer.ps1 -SkipNpmCi`; итоговые артефакты — [artifacts.json](artifacts.json). Документы фичи, руководство, схема файлов и корневой план обновлены.

## Сложности

Полный `cargo test --release -p bars-worker --features test-support keybindings --lib` заблокирован сборкой `llama.cpp`: C1083 на длинном вложенном пути генератора Vulkan; уменьшение числа jobs не исправило. [Исходная ошибка](rust-tests.log). Приложение/стенд/NSIS собираются с готовым кэшем; изолированные тесты хранилища не заменяют полный набор worker. Serena не предоставлена; использованы bars и чтение исходников. Параллельные dirty-изменения сохранены; коммит и push не выполнялись.
