# Передача этапа 20 — уведомления

## Сделано

IDEA-04 реализована в рабочей копии: [описание и проверки](../../features/window/notifications.md), [мокап](../../features/window/mockups/notifications.html). Общий центр в поиске и настройках, модели с процентом, индексация и очередь, ошибки, непрочитанные, очистка; единый опрос моделей. Worker отдаёт процент и безопасную ошибку ручной загрузки; учитывает сохранённое устройство. Новых зависимостей нет.

79 UI + 154 worker + 51 protocol passed; UI check/build, app check и worker clippy прошли. Встроенный браузер: фикстуры, обе темы, настройки, переходы, очистка, пустой список, Escape. Снимки: [тёмная тема](notifications-dark.png), [светлая тема](notifications-light.png).

## Не сделано

Настоящее скачивание и приёмка в Tauri, установка приложения. Отдельный коммит не создавался: checkout содержит параллельную незакоммиченную реализацию моделей и логов; общие файлы сохранены. Реализация уведомлений использует новые API модели из этой рабочей копии.

## Сложности

Serena MCP не предоставлен. Cargo некоторое время ждал чужую сборку. Первые два падения UI-тестов относились к параллельному разделу логов; итоговый прогон зелёный. Невалидная remote-фикстура теста заменена полной конфигурацией; итоговый тест сохраняет CPU. `activity` не различает успех/отмену, поэтому исчезновение задания не объявляется успешной индексацией.

Проверить реальное скачивание и переключение экранов в новой сборке по списку в описании. История центра живёт в памяти окна; короткие операции между опросами могут быть пропущены. Общий интеграционный коммит — после сведения параллельных изменений.
