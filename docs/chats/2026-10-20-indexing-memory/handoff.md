# ISS-18 — поиск проверен, память остаётся открытой

## Сделано

- Штатный установщик собран и установлен. Полная индексация корпуса bars завершилась: 263 документа. MCP-поиск с rerank выполнен при идущей индексации без ложного `model_loading`; [лог](installed-before-worker.jsonl), [статус](installed-before-status.json), [45 снимков процессов](installed-before-memory.json).
- Пик наблюдений bars — 6015 МиБ private commit, потомки — 204 МиБ. Изолированная FP32 embed-сессия без индексатора держит около 4,8 ГиБ. Initializers и graph fusion не помогают; векторы совпали побитово. CPU arena/prepacking: незавершённые опыты, видимого выигрыша нет. DML arena: отвергнуто, guard остановил стенд на 10,9 ГиБ.
- Два воспроизводимых стенда: `crates/bars-core/examples/probe_embed_arena.rs`, `probe_dml_arena.rs`. Сырые `.jsonl` и `.vectors.json` рядом; [сводка](summary.json). CPU i7-11700KF, RTX 3090, 32 ГБ, Windows, Rust 1.99.0, fastembed 7.1.1 / ort rc.13. Время под фоновой нагрузкой не считается проверкой скорости.
- Регрессии готовности занятой модели и полной индексации с IPC/обработчиком окна — по одному тесту, проходят; MCP — 5 + 12 тестов. Хеши и mtimes Codex config / настроек bars сохранились. Канонические документы, ISS-18 и план обновлены. Продуктовый код памяти не менялся; пункт 3 не закрыт.

## Не сделано

Подтверждённое ограничение памяти; полный CPU-arena опыт; атрибуция рабочих выделений CPU/DirectML; нативные клики окна и установленная сборка с будущей оптимизацией.

## Сложности

Свободный commit к концу около 3,7 ГиБ, ниже резерва одиночного FP32-стенда. Отклонённые/прерванные процессы сохранены. До повторного запрета ошибочно выполнялись штатные `--quit` ради опытов; OQ-106: **рабочий bars не закрывать и не переустанавливать**, с ним работают. Подкачка и чужие процессы не менялись.

## Дальше

Продолжить с `knowledge/memory.md`: профиль выделений и парный CPU-arena опыт только при естественном запасе commit. Отвергнутые настройки в продукт не переносить; precision, модель, длину входа и профиль пользователя не менять. Есть параллельные чужие изменения, в том числе в документах памяти; не включать их в свой коммит.
