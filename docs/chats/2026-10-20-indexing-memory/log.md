# ISS-18 — находки и изменения подхода

- 20-10-2026: установленный bars держит 6,1 ГиБ private commit при 854 МиБ WS; это разные метрики. Проверяется CPU arena через поддерживаемый EP API; precision/длина/модель сохраняются.
- CPU arena и размещение initializers не дали существенного снижения; отключение DML arena превысило 10 ГиБ и остановлено guard. Для оставшихся парных опытов не хватает commit; OQ-106 о краткой штатной остановке bars.
- OQ-106: автор повторно запретил останавливать рабочий bars; остановки для стенда прекращены. До уточнения выполнялись штатные --quit; это нарушение ограничения, не допустимый способ освобождения памяти.
