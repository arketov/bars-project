## Сложности

Общий гейт сначала остановился на форматировании параллельного теста, после `cargo fmt` — прерван при ожидании clippy. Причина двух отказов отмены и исправленный способ проверки сохранены в разделе «Подавление ответа отмены в rmcp 3.5.1» базы знаний. Параллельные правки и чужой индекс Git сохранены; коммит задачи сформирован отдельно.
