# Функции MCP в окне — результат 3.7.1

- [Матрица всех 14 инструментов MCP и поведение окна](../../features/agent-tools/window-parity.md); тест сравнивает строки с реестром `bars-mcp`. Прочитаны Т-37, пожелание IDEA-12, контракт и прошлое исследование дублей. Структура документа уже реализована.

- `tests.txt`: 27/27 профильных UI-тестов (панель, карточка, GraphPage, Markdown); `parity-test.txt`: 1/1 Node-тест таблицы по настоящему реестру MCP. `check.txt`: 0 ошибок/предупреждений; production UI — `build.txt`. В браузере на production-фикстуре: вход, порог, переход в документ по возвращённому пути и строкам, продолжение от соседа и возврат; обе темы, 1280 и 760 px. Снимки `similar-window.png`, `similar-narrow-light.png`. Контракт, руководство, IDEA-12, CHANGELOG и выполненные части пункта 3.7.1 обновлены.
