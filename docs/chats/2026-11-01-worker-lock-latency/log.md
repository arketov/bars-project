# Задержки журнала и освобождения моделей — находки

ISS-79 затрагивает не только замену слота менеджером: последний Arc может отпустить действующий запрос. Передача только вытесненного Arc в spawn_blocking этого не гарантирует; освобождение самой сессии передаётся отдельному потоку из destructor слота. ISS-78 требует сохранить атомарность курсора при чтении прогресса вне журнала.

Ревью подтвердило риск нового пика памяти: constructor мог первым взять gate, пока старая сессия ждала в очереди очистки. Перед встроенными constructor и скачиванием добавлен FIFO-барьер освобождений; он ждёт вне load-gate, поэтому не мешает очистке. Регрессия запускает новую подготовку сразу после замены.

Общий main одновременно меняют другие сессии: затронуты в том числе worker/mod.rs и worker.md. В итоговый коммит включаются только участки 5.2.2. Два полных прогона остановились на форматировании новых чужих тестов; готовность проверяется собственным полным прогоном после ревью.

Бинарник bars-worker со свежим временем не содержал новых тестов 5.2.2; его запуск не принят как доказательство. Обновлены только mtime models.rs и tests/operations.rs для явной пересборки текущих исходников; в итоговом выводе проверяются имена всех пяти регрессий.
