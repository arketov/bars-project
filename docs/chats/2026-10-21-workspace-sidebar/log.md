# Журнал сессии — постоянная навигация и перенос вкладок

- ISS-21: окно Tauri без `disable_drag_drop_handler()` перехватывает HTML5 drag-and-drop WebView2; программные проверки 1.1.4 двигали вкладки через API и это пропустили. Dockview 8.6.1 умеет `dndStrategy: "pointer"` — выбран он плюс отключение перехвата.
- Удаление опустевшей группы (умолчание Dockview) схлопывало зоны: перенос последней вкладки центра вправо сдвигал всё влево. Перешли на `closeEmptyGroups:false` и структурное правило: зоны — дети корня сетки.
- Синтетический `left_click_drag` браузерной панели не давал края группы; разделение проверено PointerEvent с промежуточными движениями. `setPointerCapture` на синтетическом указателе бросает — обёрнут в try.
