# Передача — гейт чтения документации по счётчику (шаг 5.3.1, ISS-109)

Предыдущая сессия: [handoff](../2026-11-10-agent-layer-audit/handoff.md) — проект гейта по счётчику и решение автора OQ-295.

## Сделано

- Гейт `bars-cli hook pre-tool-use` в `crates/bars-cli/src/gate.rs` переписан: разовая разблокировка убрана. Поисковые обходы папки документации (Grep, Glob, `grep`, `rg`, `Select-String`, `findstr`) считаются подряд; каждый шестой получает отказ, тот же вызов, повторённый сразу, проходит. Широкая рекурсия по `*.md` (вся папка документации или от корня проекта) получает отказ с правом повтора независимо от счётчика. Любой вызов `mcp__bars__*` обнуляет счётчик.
- Журнал `chats/` считается наравне с остальными папками, папка без `.md` в shell теперь видна; чтение известного файла (Read, `cat`) и поиск в одном `.md` не считаются.
- Счётчик — файл `bars-gate-<session_id>.count` во временной папке (число и отпечаток отклонённого вызова); каждый обход дописывается строкой в `bars-gate.log` там же.
- Тесты в `gate.rs` переписаны под новое поведение: шестой обход и повтор, обнуление вызовом bars, другой вызов после отказа, широкая рекурсия, не считаемые вызовы, папки в shell и `chats/`, корень документации.
- Документы: `features/agent-tools/cli.md` (раздел хука), `features/clients/clients.md`, `features/agent-tools/agent-layer-project.md`, `features/docs-convention/bars-instruction.md` (П-18), `backlog/issues.md` (ISS-109), шаг отмечен в плане.

## Не сделано

- Сборка, `cargo`, тесты и `check.ps1` не запускались (правило проекта «без проверки сборкой»): код и тесты `gate.rs` не прогнаны.
- Установленная копия `bars-cli` не обновлялась: гейт заработает в клиентах после новой сборки и установки.
