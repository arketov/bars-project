# Handoff — полнотекстовые сигналы, шаг 2.3.3

Продолжает [handoff поворота к поиску](../2026-11-03-search-pivot/handoff.md).

## Сделано

- **Код `bars-core`, не собран и не запущен.** `storage/stem.rs` — новый разбор слов: Snowball ru/en, без стемминга ПРОПИСНЫЕ, слова короче четырёх знаков, с цифрой и с `іїєґ`; `ё→е`; точная форма с целыми формами идентификаторов; пары знаков для китайского и японского; `STEM_VERSION` = 2. `storage/index.rs` — `chunks_fts` из четырёх колонок (`name`, `heading_chain`, `body`, `exact`), `tokenchars '_'`, таблица `chunks_fts_vocab`; `rebuild_fts` пересоздаёт обе таблицы из `chunks` и `documents`. `search/fulltext.rs` (новый) — выражение FTS5 по колонкам, составной `bm25` 5/3/1/0,3, исправление опечаток по словарю, `f_signal` для шага 2.3.4. `search/hybrid.rs` — берёт запрос из `fulltext`, `Scope::text_scored`, ошибка `FtsRebuilding`, пока читатель видит старый разбор.
- **Тесты написаны, не запускались:** `search/fulltext/tests.rs` (11), `storage/stem.rs` (4 новых), `storage/index.rs` (миграция старой двухколоночной таблицы), `search/hybrid/tests.rs` (два теста выражения переписаны под колонки).
- **Документы:** новый [полнотекстовые сигналы](../../features/search/fulltext.md); правки `hybrid-search.md`, `architecture/schema.md`, `stack.md`, `worker.md`, `manual/search.md`, `manual/troubleshooting.md`, `features/search/Index.md`; вопрос OQ-277 в `QUESTIONS.md`.

## Не сделано

- Ни сборки, ни тестов, ни `check.ps1`: код не коммитился, первым делом `cargo fmt`, `clippy` и тесты `bars-core` у автора. Вероятные места первой правки: `stem.rs` (тест `bars向量` ожидает стем `bar`), `fulltext/tests.rs` (порядок `bm25` в тесте названия, `fts5vocab` с условием `term >= … AND term < …`).
- Метрики шага не пересчитаны на продукте: бенч, подбор весов и разбор 16 ухудшившихся запросов — шаг 2.3.4. Размер индекса и время запроса с `fts5vocab` на реальных проектах не измерены.
- `bars-cli`, `bench_quality` и `bench_search_cpu` не менялись: они зовут тот же `search`, но если вызывают `fts_query` или читают колонки напрямую, это видно только при сборке.

## Сложности

- Решение агента: пока `stem_version` устарел, читатель отвечает ошибкой «полнотекстовый индекс перестраивается» (новый вариант `SearchError::FtsRebuilding`, в воркере уходит как внутренняя ошибка с этим текстом), а не `reindex_required`: переиндексация и согласие по Т-25 не нужны, таблицу пересоздаёт первое задание обновления.
- Порог длины основы для исправления опечаток (7 и 8 знаков) применён к основе слова, а не к слову: исследование не уточняло, какая из длин имелась в виду.
- В рабочем дереве лежат чужие правки тех же файлов (`index.rs`, `hybrid.rs`, `hybrid/tests.rs`, `search/mod.rs`): не откатывались, мои правки наложены сверху.
