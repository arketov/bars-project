# Поддержка Ollama — состояние 5.1

## Сделано

Исследование и данные — [Ollama](../../knowledge/ollama.md), контракт — [внешние модели](../../features/models/external-models.md). Источник `ollama`, нативный embed без усечения, инструкция Qwen3, проверка ответа, независимый rerank; окно, руководство и changelog обновлены. Исследование, реализация и аппаратный сценарий отмечены `[x]` внутри открытого 5.1.

7 новых Rust-тестов; регрессии HTTP/settings/settings_io/внешнего воркера — 22/27/10/5. UI: 13 целевых тестов, `svelte-check` 0/0, production UI. Логи рядом. Общий UI-прогон имел 5 сбоев в других параллельно меняющихся модулях; общая зелёная регрессия не заявлена.

Ollama 0.40.9, Qwen3 0.6B Q8_0, RTX 3090/CUDA: индекс трёх документов, реальная запись/чтение настройки, два русскоязычных поиска с ожидаемым лидером — `worker-live.json`. Векторы 2×1024, VRAM/context/digest — `gpu.json`, версия/hash архива — `runtime.json`, оборудование — `server-hardware.log`, исходники/стенд — `source-hashes.json`. Три адреса rerank вернули 404. Профиль и индекс удалены через `shutdown`; модель выгружена, сервер остановлен (`after-unload.json`, `cleanup.json`). Веса сохранены только на D:.

## Не сделано

5.1 открыт: штатного rerank API Ollama нет, генеративная замена не согласована; нативное/установленное окно не проверено (Chrome через CUA недоступен). Сравнительное качество на корпусе не измерялось; прежний GGUF-бенч не заменяет его.

## Сложности

Serena отсутствует. C1083 длинного пути Vulkan устранён коротким target `C:/bt/bars`; ожидание сборки и загрузка архива заняли основное время. Параллельные изменения сохранены; общие файлы отбирались по собственным hunks, смешанные CRLF/LF `types.ts` сохранены. Автопроверка отклонила ускоренную загрузку (использован обычный curl) и удаление `%TEMP%/bars-ollama-5-1` (`blocked by policy`): portable-сборка осталась, сервер не работает.
