# Меню документа вне дерева — журнал сессии

- Находка: при `defaultRenderer: "always"` содержимое панели Dockview лежит вне `group.element`, поэтому поиск вкладки шапки и тела документа через `group.element.contains` ничего не находил, хотя тест с готовой вкладкой проходил; панель ищется по `panel.view.content.element`.
- Параллельно в том же checkout правят `Workspace.svelte`, `WorkspaceDocument.svelte`, `issues.md` и другие файлы (3.2.5, удаление документа, граф); свои правки в общих файлах держал маленькими и коммитил отдельными хунками.
- Решение: у «Переименовать…» и «Удалить…» вне дерева сочетаний нет, потому что F2 и Delete действуют только на строке дерева, а в редакторе Delete — правка текста.
