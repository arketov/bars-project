# Кэш графа и бюджет загрузки 2.2.7 — итог сессии

## Сделано

Репозиторий обновлён fast-forward до `c6e05eb`, ветка `main`. Изучены GR-09, проект жизненного цикла, ISS-77 и исследования загрузки/нагрузки. Общий кэш и дедлайн уже были реализованы предыдущей сессией; повторная реализация не потребовалась.

В `crates/bars-worker/src/handler/graph_cache.rs` исправлено вытеснение активного Slot: оно могло создавать вторую загрузку одного проекта. Добавлены регрессии LRU/лимитов и таймаута ожидающего читателя. [Контракт кэша](../../features/graphrag/implementation.md) и [архитектура](../../architecture/graph.md) уточнены; исходное исследование загрузки, resource-efficiency.md, реестр проблем и CHANGELOG.md согласованы с реализацией. Пункт 2.2.7 отмечен `[x]` по прямому поручению автора.

Проверки: `check-final.log` — полный `scripts/check.ps1 -Jobs 2`, `RUST_TEST_THREADS=1`, exit 0; пять тестов кэша, 300 тестов воркера, 514 UI-тестов, типы 0 ошибок/предупреждений. `ui-build.log` — сборка интерфейса, exit 0. `native-result.json` — свежий `graph_lifecycle_probe`, Tauri/WebView2, 14/14: новые поколения после правки, отклонение старого снимка, восстановление после stale, открытие карты. Стенд собран в `C:/bt/bars` со штатным manifest; профиль и фикстуры — `.bars/graph-cache-227-2026-10-26`, рабочий bars не перезапускался.

## Не сделано

Установка не выполнялась; прежние ограничения установочной приёмки сохранены. Нового ресурсного замера нет: использован опубликованный замер на 493 документах, без переноса его чисел на другие корпуса; общий профиль OQ-191 и причина нестабильных IPC-прогонов OQ-200 остаются открытыми. Коммит и push не запрашивались. Чужие параллельные правки сохранены.

Serena недоступна; использованы исходники и rg. Подготовка PATH, MSVC, Vulkan/libclang и ограничения одновременных IPC-прогонов сведены в [знание о сборке](../../knowledge/build.md). Первый полный прогон дал три отказа CLI и UnexpectedEof IPC-теста графа; причина не изолирована (OQ-200). После полного окружения и последовательного запуска check прошёл; отрицательные логи сохранены. Финальные документы дополнительно прошли три теста chunking_corpus. bars-end выполнен: статусы владельцев обновлены, код повторно не менялся.
