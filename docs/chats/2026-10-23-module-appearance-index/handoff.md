# Оформление модулей в Index.md — результат

## Сделано

По уточнению автора [контракт оформления](../../features/knowledge-base/colors-icons.md) перенесён для модулей в frontmatter их Index.md. Поля color/icon, регистр имени оглавления, перенос между проектами, миграция прежнего TOML без перезаписи заданного Index.md, сброс без возвращения старого значения. Документы и подпапки второго уровня остаются в TOML. Сохранение через document_io: ревизия, BOM, CRLF, сохранность остальных полей и тела.

Проверки: `cargo test --release -p bars-app appearance` — 15/15 (rust-tests.txt); `npm test --prefix ui -- appearance.test.ts` — 6/6; `npm run check --prefix ui` — 0 ошибок/предупреждений; production UI build прошёл (обычные предупреждения о размере чанка и смешанном импорте editors). Ручной обзор: путь через document_io, отказ при незакрытом/неподдерживаемом поле, перенос старых записей перед сбросом. Т-38, OQ-129, руководство, changelog и пункт 3.9.2 обновлены.

Установщик и проверка установленного окна. Независимые копии модулей автоматически не синхронизируются: оформление переносится вместе с файлами.
