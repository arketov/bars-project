# Граф запроса 2.4.1 — передача реализации

## Сделано

- [Граф запроса](../../features/graphrag/query-graph.md): Rust `QueryGraphSlice`, команда окна `graph_query_slice`, общий кэш документных представлений с физическим графом; точный cosine по всей области. Отбор окружения, узел запроса, сила рёбер, порядок, глубина, бюджеты и fingerprint — в Rust. Старый клиентский алгоритм изолирован в архивном стенде `spikes/graph-actions`.
- Окно принимает готовые списки режимов без IPC при переключении; защищено от поздних ответов и возврата к кэшированной глубине. Ошибка сохраняет прежний вид. Отметка 2.4.1, протокол, руководство и changelog обновлены.
- С разрешения автора исправлен OQ-205: [поиск](../../features/search/hybrid-search.md) читает один снимок SQLite и открывает индекс readonly. Управляемая публикация схемы воспроизводит `SchemaChanged (17)` без снимка и проходит с ним; две регрессии поиска прошли. ISS-68 закрыт только для поиска и mix.
- OQ-200: каналы CLI/MCP/worker Harness привязаны к уникальному временному профилю. Два одинаковых ярлыка раньше видели общий реестр; после исправления та же проверка проходит.
- Полный `scripts/check.ps1 -Jobs 1`, `RUST_TEST_THREADS=1` — зелёный (`check-alone.txt`): fmt, clippy, build, Rust, Svelte без замечаний, 68 файлов / 522 теста UI. Сводка — `verification.json`.
- `result.json`: 10/10 программных проверок собранного Tauri/WebView2 после исправления FTS; временный проект, три документа, FakeProvider. Ручное ревью выполнено; принятые находки исправлены и покрыты регрессиями.

## Не сделано

2.4.2: связанные источники, пути, ревизии и статусы изменённых/удалённых результатов, узлы-призраки, восстановление прежних мест/камеры/выбора. Проекция чанков и полная приёмка Т-47 на настоящих запросах обоих проектов открыты. Установленное приложение не обновлялось.

## Сложности

Общий кэш и тестовые exe заняты параллельными сессиями; их изменения сохранены. Отрицательные логи сохранены: FTS — OQ-205; коллизия каналов — OQ-200; потеря одной записи истории под нагрузкой — открытый OQ-207, тот же тест отдельно и в финальном полном прогоне прошёл. Причина исторической потери записи не объявляется исправленной. Serena MCP недоступна. Параллельные коммиты захватили часть ранней подготовки; итоговый коммит дополняет её до рабочего среза.
