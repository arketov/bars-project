# Модули проекта для агента — находки сессии

Исходные интеграции Kimi/Ouroboros сохранены параллельной сессией в `f370ce8`/`fbe47b3`, отправлены в main. Проверка ждёт общий Cargo-кэш. [Контракт модулей](../../features/agent-tools/module-scope.md) требует отдельного лёгкого запроса только проекта сессии: общий `projects` обходит все индексы. Графовые MCP-инструменты недоступны; использованы поиск, similar и входящие ссылки.

Sol-ревью нашло два P2: общий projects() читал чужие настройки; пустой primary в mode=graph давал ложный совет расширить поиск. Исправлены отдельным accessor и явным признаком primary-search, добавлена регрессия. Третий проход — без замечаний по производительности, логике и полноте. Полный check запущен после ревью.

Первый полный check: fmt и clippy зелёные, build встретил E0425 в параллельном graph_text (новые функции query отсутствовали в увиденном сборкой срезе). На диске обе функции уже есть. Без обходов запущен новый полный check на сохранённых исходниках.
