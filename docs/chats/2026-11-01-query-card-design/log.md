# Карточка запроса — события проектирования

3.4.7 оказался дизайном с согласованием, реализация выделена в 3.4.8. Прежний самостоятельный макет глобального поиска отклонён автором: выбран изолированный стенд поверх настоящих компонентов, без изменения продуктовой сборки.

Начальный check остановился без Cargo в PATH, затем без VULKAN_SDK. Повтор запущен с установленными MSVC/Vulkan и общим C:/bt/bars. Исходную интеграцию клиентов параллельная сессия уже отправила в main; последующие чужие правки не включаются в дизайн.

Chrome недоступен в инструментах; локальный стенд проверяется встроенным браузером без авторизации. Первый запуск обнаружил незавершённую чужую правку MOTION_TEXT в PhysicalGraph; её не подменяли. GraphRAG-инструменты bars отсутствуют, использованы поиск, точные вхождения, похожие разделы и входящие ссылки.

Ревью sol выявило ссылку на удалённый SEARCH_MODE после параллельной миграции подписей и потерю фона нулевого вхождения. Исправлены оба случая; повторное ревью без замечаний. Браузер подтвердил подпись диапазона и снятие после правки. Обычный mock всегда давал пустой текстовый ответ, поэтому добавлены отдельные фикстуры состояний стенда.

Автор принял макет (OQ-237) и разрешил завершить commit/push несмотря на соседние сбои общего check. Макет уже включён параллельной интеграцией в ac52757; push main подтверждён. bars-end закрепляет итог и ограничения проверок, без реализации следующего шага.
