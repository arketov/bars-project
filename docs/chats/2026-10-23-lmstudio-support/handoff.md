# Подключение LM Studio — итог и границы

## Сделано

[Исследование LM Studio](../../knowledge/lmstudio.md), [контракт подключения](../../features/models/external-models.md), руководство и changelog обновлены; завершённые части 5.2 отмечены `[x]`.

Источник `lmstudio`, выбор embed в настройках, необязательный ключ, инструкция Qwen3 только к запросу; встроенный или внешний rerank независим. Включённый LM Studio rerank отклоняется. OpenAI-ответы проверяются на индексы, пустые/неконечные векторы; LM Studio не выдаётся за сервер с гарантией отказа вместо усечения.

HTTP 24, настройки 28, запись настроек воркера 10, полный HTTP-поиск воркера 7, UI 15 тестов прошли; svelte-check 0/0, production UI собран. Результаты — `rust-*.log`, `worker-*.log`, `ui-*.log`. Финальный release WebView2 с IPC/FakeProvider: 13 проверок выбора/сохранения, независимости rerank и предупреждения, обе темы на 1440/1024/760 px — `result.json`, `native-build.log`. Аппаратный backend проверен отдельно.

Настоящий LM Studio 0.4.26+4/Qwen3 0.6B Q8_0 на RTX 3090: 2×1024, индекс трёх документов, `SettingsSave/Get`, два поиска с ожидаемым лидером (`worker-live.json`). GPU-размещение/освобождение — `gpu-memory-*.json`; веса — `weights.json`. Модель выгружена, HTTP-сервер остановлен, порт 1234 восстановлен, временный профиль/индекс удалены; рабочий bars сохранён.

## Не сделано

Установленная сборка и физические жесты; установка запрещена ранее автором OQ-113. Штатного rerank API нет (upstream #521 открыт; локально ошибки маршрутов, в том числе HTTP 200). Генеративная подмена и сравнительный бенчмарк не выполнялись. Общий 5.2 открыт.

Уборка двух временных native-runtime каталогов не завершена: WebView2 держал кэш при выходе, последующее удаление отклонено автопроверкой (`blocked by policy`). Точные пути/наличие — `native-cleanup.json`; обход отказа не предпринимался. Сам native-процесс завершён. Временный профиль реального worker smoke удалён отдельно штатным TempDir.

## Сложности

Длинный вход сервер обрезает до 8192 токенов без HTTP-ошибки даже при `truncate:false`; разные окончания дали одинаковые векторы, причина подтверждена журналом (`truncation.json`, `server-excerpts.log`). Ограничение явно показано пользователю.

Serena недоступна. Повторная bars-выдача вернула `reindex_required`; известные источники прочитаны с диска, индекс не менялся. Промежуточные GraphRAG-типы блокировали native-сборку; после появления типов проверка возобновлена. Исправления собственного стенда: include `appearance_index`, runtime DLL/manifest, селектор реального корня SettingsPage вместо отсутствующего wrapper панели. Первые ошибки сохранены отдельно. Параллельные правки, включая TEI, сохранены; общий checkout не коммитился.
