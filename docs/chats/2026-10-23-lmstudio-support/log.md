# Подключение LM Studio — находки

23-10-2026: LM Studio и Qwen3 Q8_0 уже установлены; `lms ls` автоматически разбудил сервис, исходно HTTP-сервер выключен и моделей в памяти нет. Проба — отдельный ID/порт, без загрузки новых весов; рабочий bars сохранён.
23-10-2026: штатный rerank API отсутствует в документации; upstream #521 открыт. Поддержка embed и независимый rerank проектируются отдельно, без генеративной подмены.
23-10-2026: подтверждено серверное усечение LM Studio (`truncate:false` игнорируется): разные окончания дали одинаковые векторы, журнал указал 24009/24010 → 8192 токена. Причина и границы — [исследование](../../knowledge/lmstudio.md).
23-10-2026: bars-поиск после смены индекса вернул reindex_required; переиндексация не запускалась, известные источники прочитаны с диска. Native-проверка ждёт занятый параллельными сборками общий target.
23-10-2026: первая native-сборка стенда выявила новую зависимость общего appearance.rs от appearance_index. Добавлен настоящий модуль в собственный стенд; продуктовый код оформления не менялся.
23-10-2026: повторная native-сборка заблокирована чужими незавершёнными GraphRAG-типами (`BuildLayer`, `Dataset.similarity_state`); native-build.log сохранён. Собственный стенд готов, проверка окна оставлена открытой, чужие модули не правились.
23-10-2026: заключительная сверка обнаружила появление BuildLayer и similarity_state в bars-graph. Native-проверка возобновлена на новом исходном состоянии; прежняя ошибка сохранена в native-build-graph-transition.log.
23-10-2026: native exe собран; прямой запуск вне Cargo не получил runtime DLL из release/. Стенд переведён на установленный в проекте способ: отдельная временная папка с Vulkan/MSVC DLL, manifest и контролируемый Start-Process; свой зависший процесс остановлен по проверенному пути.
23-10-2026: WebView2 открыл настоящий выбор LM Studio; стенд ошибочно искал wrapper панели, хотя меню открыло настройки поверх окна. Селектор привязан к корню SettingsPage (.app), индикатор записи — к фактической отдельной savebar; продуктовый UI не менялся.
23-10-2026: финальный release WebView2/IPC прошёл все 13 проверок, result.json success=true; обе темы и 1440/1024/760 px. Временный runtime удалён, готовые части 5.2 отмечены [x]; открыты установленная приёмка и недоступный штатный rerank.
23-10-2026: прежняя запись об удалении native runtime оказалась преждевременной: WebView2 держал кэш при выходе. Удаление точных собственных временных каталогов отклонено автопроверкой (`blocked by policy`); остатки перечислены в native-cleanup.json. Проверки окна прошли; ограниченное ожидание уборки добавлено в сценарий.
