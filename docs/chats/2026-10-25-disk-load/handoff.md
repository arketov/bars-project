# Дисковая нагрузка bars — итог исправления

## Сделано

- Исправлен случайный поиск каждого BLOB при полном переборе: последовательное чтение векторов, узкая область сохраняет предварительный отбор. Исправлены аналогичные запросы ключей графа. Причина и границы — [векторный поиск](../../architecture/vector-search.md).
- 3515 чанков: поиск 446 → 47,9 МиБ чтения; ключи графа 430 → 2,39 МиБ. Полное содержимое результатов совпало по SHA-256. Это файловое I/O, включая кэш ОС. [Измерения](sqlite-io-final.json); стенд — `scripts/probe-sqlite-io.ps1` и `.cjs`.
- Регрессия SQL и все 336 тестов ядра зелёные; проверка разреженной Windows-фикстуры прогресса загрузки прошла с прежними ожиданиями 50/99/100 %. Отдельно окно: Svelte 0 ошибок/предупреждений, 505 тестов.
- По OQ-193 исправлена обработка `Result` у `progress_handler`, убран лишний `mut` аудита, выполнено форматирование. Основной патч трёх файлов — `.bars/disk-load-fix.patch`; дополнительные изменения графа остаются в общей копии.

## Сложности

Повторные проверки ошибочно совмещались с другим Cargo: промежуточные API, занятый test exe и длительное ожидание кэша. Финальный прогон начат после завершения чужого Cargo; ошибки тестов зафиксированы без очередного цикла пересборок.
