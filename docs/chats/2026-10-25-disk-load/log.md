# Дисковая нагрузка bars — находки

25-10-2026: SQL полного поиска читает 442 МиБ ради 35,7 МБ векторов; последовательный проход — 47,6 МиБ. Причина и границы — в статье «Векторный поиск bars».
WPR отказал в доступе (0x80070005); вместо ETW использован отдельный read-only процесс SQLite и GetProcessIoCounters. Чужие процессы не останавливали.
Полный прогон с параллельностью Rust по умолчанию: красные история MCP (2/3), IPC-поиск (500 мс), массовый watcher (20 с); все три отдельно зелёные без правок. Повтор полного check с RUST_TEST_THREADS=2, без пропусков и изменения дедлайнов.
Windows-фикстура download_percent выделяла более 4 ГБ и упала с StorageFull; переведена на sparse без изменения размеров/ожиданий. C: затем заполнился при сборке bindgen; кэш не очищался. После восстановления свободного места полный check повторён с RUST_TEST_THREADS=1.
Повторные полные проверки ошибочно совмещались с другим Cargo: получены промежуточный API и занятый test exe. Автор OQ-194 выбрал общую копию. Финальный прогон начат после отсутствия других cargo/rustc/link; прежние отказы сохранены отдельно.
Финальный прогон после завершения другого Cargo: fmt/clippy/build зелёные, 336 тестов ядра зелёные; worker красный на partial-аудите и SQLite FTS конструктора локального endpoint. Новые циклы полных пересборок не запускались; установщик не собирался.
