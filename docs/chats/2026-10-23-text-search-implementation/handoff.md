# Поиск в тексте — реализация и проверки 23-10-2026

## Сделано

- Автор расширил 3.6.1 на реализацию 3.6.2 (OQ-148). [Контракт поиска](../../features/search/text-search.md), руководство, протокол и оглавление обновлены; выполненные части отмечены `[x]` в PLAN.md.
- `bars-protocol::TextSearch`, `bars-worker::text_search`, кооперативный обход: без индекса/модели/кэша, пределы, пропуски, область/путь, регистр/regex, отмена по окну, порции с ревизией. UI: независимая выдача, запись буферов перед запросом, точный UTF-16 диапазон редактора; текст выдачи не попадает в раскладку.

- [Замер реализации](../../knowledge/text-search-2026-10-22.md): настоящий dispatch, копия 393 документов / 3,08 МБ, остановленная индексация/FakeProvider, 4 режима × 40 отсчётов; p95 27–170 мс в тёплом кэше ОС. Сырые данные — рядом с исследованием, `worker-2026-10-23.json`.

- Длинный target/ дал C1083 генератора Vulkan; проверки прошли через существующий C:/bars-build без очистки. Первый общий UI-прогон страдал от числа процессов; далее maxWorkers=1. Раннее падение аудита исчезло после завершения параллельной правки; финальный общий прогон 480/480.

- Повтор проверок: `check-worker.ps1`, `benchmark.ps1`, `check-window.ps1 -Output <путь JSON>` в этой папке; собственный временный профиль, рабочий bars не останавливается. Продолжение — оставшиеся условия приёмки.
