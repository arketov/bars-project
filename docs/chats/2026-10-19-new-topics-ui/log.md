# Находки сессии: «Новые темы», экран окна (шаг 20, P4)

- Находка: `record_check` поднимал ревизию темы переходом в «Есть материалы», а проверка хранила ревизию старта, поэтому первая найденная проверка сразу выглядела устаревшей. Теперь проверка получает новую ревизию, если тему не меняли другие ([store.rs](../../../crates/bars-core/src/new_topics/store.rs)).
- Метка индекса для `conclusive` — `index_token` (секунды и наносекунды `SystemTime` обновления воркера), а не RFC 3339; после перезапуска воркера она восстанавливается из секундной метки.
