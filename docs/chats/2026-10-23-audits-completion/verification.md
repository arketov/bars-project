# Проверки — завершение аудитов 3.8.3

## Реализация и границы

Действующий контракт — [аудиты знаний](../../features/knowledge-base/audits.md). Добавлены числовые кандидаты по OQ-143, игнор/возврат с миграцией БД, центр уведомлений и защита поздних страниц. Дубли считают по собственному снимку после освобождения index gate; изменение поколения индекса даёт частичный итог. Удаление ждёт фактического окончания писателя. Отсутствующий корень проекта не воссоздаётся хранилищем. Markdown аудитами не меняется. Установка и рабочий профиль bars не затрагивались.

## Автоматические проверки 23-10-2026

- Release `bars-core --lib`: 320 прошли, 2 проигнорированы; `bars-protocol --lib`: 55 прошли. Данные исходного исследования числовых расхождений: 40/40 замен, 0/40 ложных на контролях. Также проверены диапазоны источника, отпечатки, история, отмена, миграция v1→v2, игнор после 25 запусков и переоткрытия БД, запрет воссоздания удалённого корня. Полный вывод — `rust-final.log`.
- Release профиль воркера аудитов: 11/11 (`worker-tests.log`); дубли: 14/14, включая независимый снимок после удаления файла индекса (`duplicates-tests.log`). В полном конечном прогоне воркера 279 прошли, 1 проигнорирован, 1 упал: `settings_io::tests::tei_settings_roundtrip_both_models`, пустое имя TEI embed-модели отвергнуто новой валидацией. Этот параллельный код не исправлялся; общий прогон не зелёный.
- Полный UI: 482/482, 62 набора (`ui-final.log`); `svelte-check`: 0 ошибок/предупреждений; production UI собран (`ui-build-final.log`). Числовой блок, источники, игнор/возврат, поздние страницы, уведомления и возврат находки того же запуска покрыты тестами.
- Отдельный cached-model тест ISS-19: bge-m3/DirectML, косинус 0,7104555, одна тема, два обращения и два варианта (`real-model.log`). Загрузка из сети запрещена preflight-проверкой кэша; БД изолирована.
- Clippy с `-D warnings` не зелёный: `large_enum_variant` в протокольном GraphQuery; `single_range_in_vec_init` в `indexing/chunking.rs:466`; `chunks_exact_to_as_chunks` в `new_topics/store.rs:296`. Подавления и несвязанные исправления не добавлялись. `clippy-core.log` содержит корректно настроенный запуск. Отдельная неудачная попытка без VS/Vulkan env не доказывает состояние кода.

## Настоящее окно и модели

`webview2-real-v5.json`: success=true, 15 проверок. Release WebView2 с production UI, настоящими командами Tauri и собственным IPC-воркером; embed — bge-m3 fp32 DirectML, rerank — CPU fp32. Три аудита запущены кнопками окна; проверены игнор/возврат, weekly, новая находка и переход из уведомления, обе темы на 1440/1024/760 px, открытие источника в редакторе.

Настоящие MCP и Window search объединяют исходные обращения ISS-19; диагностика не увеличивает спрос. Затем добавлен документ, полная индексация сохраняет тему, обязательный rerank работает при выключенном обычном rerank. Проверка показывает материалы; только пользователь закрывает тему. MCP получает отказ на внутренний список. Это изолированный нативный стенд, не приёмка установленного приложения и рабочего профиля.

Предыдущие JSON сохранены как неудачные/промежуточные попытки. Причины: отсутствие ожидания доступности кнопки после записи; неверное ожидание поля `topic` вместо serde(flatten); попытка включить rerank полем search, которого нет в DTO. Исправлялся стенд: штатная проверка знаний инициирует загрузку rerank, затем ожидается наблюдаемое состояние ready. Ранняя проверка коллектора с helper-дедлайном 30 с заменена более полным нативным сценарием: фактический первый ready занял 30,25 с. Продуктовые дедлайны не ослаблялись.

| A1–A2 | Тесты воркера: самостоятельность, повторы, диагностика. Нативно: два настоящих источника/варианта, диагностика исключена; закрытое окно отдельно не проверено |
| A3–A5 | Тесты воркера: ручная отметка непустой выдачи, область/расширение, пустой корпус; core: текст без вектора. Нативная ручная отметка непустой нерелевантной выдачи открыта |
| A6, ISS-19 | Настоящая модель на исходной паре, нативный сбор; калибровка/ложные слияния — в документах порога. Новая полная независимая оценка качества не проводилась |

## Замеры и воспроизводимость

- `scripts/probe-workspace.ps1 -Example audits_probe -RealModelsDir <готовый кэш> -Output <новый JSON>` — изолированный нативный стенд; без RealModelsDir используется FakeProvider (`webview2-diagnosis.json`). Чужие процессы и профили не используются.
- `snapshot.mjs` читает исходный SQLite через read-only connection, backup учитывает WAL. Снимки временные; исходные индексы не менялись.
- `cargo run --release -p bars-core --example audit_measure -- <копия индекса> <новый JSON>`: по три повтора на 1653/2402 чанках. Дубли полностью 359–729/552–1120 мс; числовые правила 201–217/201–203 мс. Снимок под gate 83–457/136–689 мс; это отдельный этап, не весь расчёт. Сырые точки и SHA256 входов — [данные замера](../../knowledge/duplicates-2026-10-23/Index.md). Параллельная нагрузка машины; выводов о cold-cache/p95/причинном ускорении нет.
- `cargo test --release -p bars-core --lib new_topics::tests::measure_limits -- --ignored --nocapture`: 2000 тем, медиана записи 12,13 мс, p95 21,98 мс, максимум 71,61 мс, список 16,9 мс, БД 9,3 МБ (`write-measure.log`). Это хранилище без задержки моделей/поиска.
- В сохранённых логах и JSON пользовательский префикс пути заменён на `<user>`, путь checkout — `<repo>`; результаты не менялись.
