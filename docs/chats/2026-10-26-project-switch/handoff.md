# Смена проекта и поиск без потери правок — итог шага 3.1.4

## Сделано

- Реализован контракт [смены проекта и несохранённого](../../features/knowledge-base/editor-design.md): запись буферов прежнего проекта до смены раскладки; отмена сохраняет вкладки и черновик, отказ разрешает переход, при конфликте доступна копия рядом. Ошибка копии удерживает диалог. Проверка действует перед исключением и удалением проекта из bars.
- Поиск продолжается после ошибки записи; предупреждение над обоими разделами ведёт непосредственно к черновику. Поиск и событие переноса учитывают свой проект. Отцепление отброшенного буфера не запускает запись повторно.
- Обновлены руководство поиска, ISS-40, К-06 аудита и статус матрицы сохранности. Исторические строки матрицы сохранены.
- Проверки: 521 тест окна; Svelte — 0 ошибок и предупреждений; продуктовый UI собран. Шесть сценариев `project-switch.test.ts`, один `move-flush.test.ts`; все девять программных проверок WebView2 с настоящим диском прошли (`native-result.json`). Сценарий — `crates/bars-app/examples/project_switch_probe.js`; изолированные профили и логи — `.bars/task-314/`.
- Ручной просмотр собственного диффа выполнен: переход до отцепления, адресная запись, судьба отброшенного буфера, ошибки копии и переход к недоступному документу.

- Полный `scripts/check.ps1 -Jobs 1` с `RUST_TEST_THREADS=1` прошёл: fmt, clippy, build, все Rust-тесты, Svelte и 521 тест окна. Шаг 3.1.4 отмечен `[x]` по поручению автора.

## Не сделано

- Установка и физическая клавиатура не проверялись; ограничение OQ-113 сохраняется. Прочие дефекты матрицы и третий выбор при закрытии вкладки/выходе остаются в 3.1.6.

## Трудности

- Serena недоступна. Подготовлены штатные Cargo/MSVC/Vulkan/LLVM; исходный прогон остановился на форматировании параллельного кода графа. После обновления этого кода fmt, clippy и build прошли; общий кэш задержал старт Rust-тестов. Первый полный прогон затем остановился на LNK1104 при открытии `bars_worker` exe; повтор — с одним заданием Cargo, без отключения проверок.
- Отрицательные пробы WebView2 исправлены в сценарии: ожидание активной кнопки, открытого диалога и события close перед контекстным меню; продуктовые условия не ослаблялись. Реальный дефект перекрытия диалога исправлен нативным модальным слоем. Два CLI-отказа общего прогона соответствуют наблюдениям OQ-200; полный повтор зелёный, причина не установлена.
