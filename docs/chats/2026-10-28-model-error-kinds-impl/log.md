# Журнал сессии 3.4.5 — виды ошибок модели в воркере и окне

fastembed скачивает файлы bge-m3 внутри `try_new`, и сеть там неотличима от сбоя ORT. Чтобы вид `network` работал и на поиске, `load_builtin_embedder` для ONNX сначала получает файлы через `download_onnx_artifacts` (типизированная ошибка), потом создаёт сессию.

В общей рабочей копии параллельно шла сессия 5.2.1 (`model_retry`, `retryModelSearch`): те же `methods.rs`, `SearchError.svelte`, `app.svelte.ts`. Перед записью файлов перечитывал их и подстраивался под чужие правки; коммит — только своими хунками.
