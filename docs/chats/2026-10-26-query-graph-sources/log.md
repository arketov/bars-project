# Граф запроса 2.4.2 — находки

- Старый снимок графа при совпавшем текущем файле не доказывает правку после поиска: несовпадение ревизий без проверки диска означает отсутствие связей для версии выдачи.
- Команда карточки могла выбрать общий узел до включения запроса; выбор ждёт готового среза. Регрессия воспроизвела потерю выбора и прошла после исправления.
- Параллельные сборки занимают общий `C:/bt/bars`; ранние проверки застали незавершённые чужие правки UI и настроек. Исходные логи сохранены; отдельные зелёные тесты не заменяют полный гейт.
- Полный `check-3.txt` остановился на запуске `search_corpus`: Windows `os error 32`, exe занят, тесты этого файла не выполнялись. Остальные выполненные наборы прошли; нужен новый полный зелёный гейт без пропусков.
- Следующий гейт остановился на LNK1104 при линковке тестового `bars_worker.exe`; параллельные Cargo-тесты продолжаются. Повтор — после освобождения exe, без остановки чужих процессов и очистки кэша.
- Исторические фильтры исчезнувшей области раньше отклонялись по новому снимку; сохранение области без расширения закреплено в [графе запроса](../../features/graphrag/query-graph.md) и проверке оконного обработчика.
- Нагрузочный тест отзывчивости однажды дал таймаут в общем наборе; отдельный повтор того же exe и следующий полный набор прошли без изменения кода и лимитов теста.

- Уточнение `$bars-end`: запись о «таймауте» нагрузочного теста ошибочна — исходный лог содержит AlreadyRunning на IPC bind; детали и отдельный повтор записаны в OQ-200 и в сборке/проверках.
- При сверке кэша повторного входа найдено расхождение с OQ-120; зарегистрирован ISS-99, код в документационном завершении не менялся.
