# Проверка этапа 31 — меню папок и ограничения приёмки

Статус 18-10-2026: реализация и автоматические проверки выполнены в рабочей копии. Открытие каталога в Проводнике, системный буфер и нативные клики не приняты; этап 31 и ISS-15 остаются открытыми. Автор запретил Computer Use, проверки ОС не обходились другими средствами.

## Реализованное поведение меню папок

По [контракту F-01…11](../../features/window/document-actions.md#контракт-этапа-26-цели-меню-дерева-документов) и [дизайну](../../features/window/refinement-design.md#меню-корня-модуля-и-папки): отдельная строка корня без галочки, группа «Корневые документы», модуль и вложенная папка. Три действия: открыть каталог, скопировать путь, проверить весь проект с ID принятой операции. Меню фиксирует исходную цель и не меняет поиск/раскрытие.

`folder_target` подтверждает узел по дереву; `folder_action` принимает только ID и действие. Сервер хранит одну текущую цель, проверяет поколение регистрации, ревизию docs_root и канонические границы. Два последних подтверждённых дерева сохраняют допуск только что удалённого узла при обновлении индекса; допуск другого проекта/поколения/корня не переносится. Проверка очереди использует `reindex_receipt(false, false)` — Full/Explicit, без rebuild и согласия на модель.

## Нативная попытка и оставшаяся приёмка

Собрана отдельная Tauri-сборка с идентификатором `io.github.arketov.bars.stage31`, временным `BARS_USER_HOME` и тремя документами в кириллическом пути с пробелами, docs_root `manual/docs`. Подготовка данных — отдельный opt-in тест `folder_native_fixture`; индекс создан FakeProvider, поэтому настоящая сборка показывает `reindex_required`, не загружает модель и не обходит Т-25.

Удалось увидеть дерево, отдельный корень и группу корневых документов. Сценарий меню/действий не завершён: ввод остановлен физическим Escape; затем автор явно запретил Computer Use. Открытие папки, значение системного буфера, обе темы, узкое нативное окно и полная матрица нативной клавиатуры остаются непроверенными. Попытка не доказывает ни исправление в установленной сборке, ни новый дефект меню.

Собственный временный процесс остановлен только после сверки сохранённого PID и полного пути exe. Установленный bars продолжил работу; его профиль/бинарники не обновлялись. Внешние модели, установленное приложение, macOS и публикация не входят в подтверждённый результат.

## Воспроизведение сборки

На этой машине Cargo/Vulkan SDK не были видны из обычного shell; длинный target ломал вложенный CMake shader generator. Успешные Rust-прогоны использовали Developer Shell MSVC 17.14, локальный Vulkan SDK, Ninja и существующий короткий target `C:/bg22`, согласно [соглашению сборки](../../knowledge/build.md). Первые неуспешные вызовы не учтены как проверки реализации.

Serena MCP среди доступных инструментов отсутствует; навигация выполнена поиском исходников. Ручной обзор дополнительно выявил и устранил гонки позднего закрепления цели и Tab; полноценная нативная приёмка остаётся отдельным незавершённым результатом.
