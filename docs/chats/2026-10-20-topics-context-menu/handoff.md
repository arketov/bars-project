# Передача — контекстное меню новых тем

## Сделано

По прямому решению автора 20-10-2026 добавлены два пункта меню строки: «Скопировать» (первая исходная формулировка целиком, не переименованный заголовок), «Закрыть» (удаление темы и вариантов без подтверждения). Использованы существующие ContextMenu, clipboard API и new_topics_delete с ревизией. Строку не нужно предварительно выбирать; Shift+F10, Escape и смена проекта обрабатываются общим меню. Позднее удаление из старого проекта не меняет выбор нового.

Обновлены требования и описание фичи, руководство, оглавление фичи, changelog. Ручной просмотр изменений выполнен: идентичность темы/проекта, исходный текст, обработка ошибок, клавиатура. npm run check — 0 ошибок/предупреждений; npm run build успешен; npm test — 193 теста в 27 файлах, включая пять новых проверок меню и позднего ответа. git diff --check пройден.

## Не сделано

Нативная приёмка Tauri, сборка EXE и установка не выполнялись; работающий bars не останавливался, настоящие темы не удалялись. Тесты используют подделку worker/clipboard.

## Сложности

Serena MCP отсутствует в доступных инструментах; навигация через Semble и прямое чтение. Параллельные изменения сохранены.

## Дальше

При отдельном поручении на обновление — собрать и установить, проверить два пункта в настоящем окне. До этого меню доступно в исходниках и собранном UI, но не обещается в запущенной установленной версии.
