# Handoff — сигнал связей в баллах поиска, шаг 2.3.5

Продолжает [handoff сложения баллов](../2026-11-05-scores-implementation/handoff.md).

## Сделано

- **Формула `l`** (подробно — раздел «Схема баллов: сигнал связей» в [гибридном поиске](../../features/search/hybrid-search.md)): после `S` без `l` якоря — документы трёх лучших разделов; `l = 1`, если документ куска связан ссылкой в любую сторону с якорем и это не он сам, иначе 0; `S' = S + w_l·l`. Порог от `l` не зависит. При `w_l = 0`, без источника ссылок или при его ошибке сигнал не считается (`signals.links` и `"links"` в `applied.signals` нет). Стартовый вес 0 (OQ-268).
- **Код, не собран и не запущен.** `link_index/store.rs`: `LinkIndex::linked_documents(якоря, документы)` — один проход по таблице ссылок на запрос. `search/hybrid.rs`: `search_with_links` с источником `LinkedDocuments` (`search_with_signals` вызывает его без источника), `load_documents` вынесена из `fold_sections`, `apply_links`; экспорт в `search/mod.rs`; комментарии `params.rs`. `examples/bench_quality.rs`: индекс ссылок снимка, вес из `BARS_BENCH_W_L` (входит в `config.json` прогона, при 0 — как прежде).
- **Протокол, MCP и CLI не менялись:** `HitSignals.links`, `ScoreWeights.links` и строки `signals:`/`weights:` уже были в протоколе и рендерерах.
- **Тесты, не запускались:** `link_index/tests.rs` (связи в обе стороны, якоря между собой, пустые наборы); `search/hybrid/tests.rs` (нулевой вес не вызывает источник, `l = 1` и добавка веса, один вызов с якорями трёх лучших разделов, ошибка источника не меняет выдачу).
- **Документы:** `hybrid-search.md` (раздел о `l`, таблицы, форма ответа), `search-scores.md` (что мерить в 2.3.7), `link-index.md`, оглавление `chats/`; вопрос OQ-279.

## Не сделано

- Ничего не собиралось и не запускалось (`cargo`, `check.ps1`, бенч); код не закоммичен, он лежит рядом с чужими правками.
- **Воркер сигнал не подключает:** веса — константы продукта (OQ-278), с `w_l = 0` вызов был бы напрасным; при включении вес надо передать и сверить индекс ссылок перед поиском (OQ-279).
- Замер пользы `l` — шаг 2.3.7.

## Сложности

- При правке `bench_quality.rs` скриптом файл на время задвоился; восстановлен, остальные чужие правки (`text: None`, парные запросы, `min_score`) сохранены. Стоит посмотреть `git diff` файла при сборке.
- Ожидаемые места первой правки при сборке: замыкание `linked` в бенче (заимствование `link_index`), параметры `search_with_links` в тестах.

Автор собирает и запускает `check.ps1` → правка по ошибкам → ответ на OQ-279 → в 2.3.7 один прогон с `BARS_BENCH_W_L` из сетки.
