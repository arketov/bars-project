# Ссылки и перемещение — итог 3.5.2 от 23-10-2026

## Сделано

- Контракт и границы — [индекс ссылок](../../features/knowledge-base/link-index.md); применение и согласование окон — [операции дерева](../../features/knowledge-base/tree-and-files.md). Исправлены устаревшие описания редактора и руководства, BARS_INSTRUCTION в обеих копиях, CHANGELOG и отметки готовых частей в PLAN.md.
- `bars_graph::links::moves`: чистый план, точечные замены Markdown/определений меток/вики-ссылок, проверка адресатов после правок, защита от перехвата одноимённого документа. Tauri `entry_plan_move`/`entry_move`: снимок, CAS, частичные неудачи без отката, оформление и очередь документов.
- Окно: предварительный список, постоянный отчёт об отказах; создание файла по ссылке в никуда; перенос буферов, вкладок, отдельных окон и сохранённой раскладки. Повторное использование старого имени не захватывает перемещённый вид. Общий JSON-набор Rust/окна; исправлены различение «е/ё» и UTF-8-проверка расширения.
- Проверки: `cargo test -p bars-app --bin bars` — 62; `cargo test -p bars-graph links --lib` — 17; `cargo test -p bars-core link_index --lib` — 8 (один замер ignored), `cargo test -p bars-core graph --lib` — 16. MSVC 17.14, Ninja, Vulkan SDK 1.4.363.0, `CARGO_TARGET_DIR=C:/bars-build`. Нативные файловые сценарии: readonly, sharing violation, устаревший снимок, папка, BOM/CRLF, оформление.
- UI: `entries`, `follow-link`, `link-fixtures`, `link-picker`, `editors`, `DocumentWindow`, `unsaved` — 70 тестов; `Workspace` — 22, `workspace-layout` — 5. Все прошли; `npm run check --prefix ui`, `npm run build --prefix ui` — успешно.

## Не сделано

Нативная приёмка WebView2: русский ввод/IME `[[`, создание по ссылке, предварительный план и список отказов в интерфейсе, два настоящих окна. Рабочий bars и установщик не обновлялись. По прямому решению автора 23-10-2026 «закрой 3.5.2!!!!!» пункт закрыт `[x]` без этой приёмки.

## Сложности

Serena не предоставлена; подключённого Chrome нет, управление нативными приложениями отключено. Rust-проверки ждали общие Cargo-замки параллельных сессий. Финальные профильные прогоны и весь Workspace зелёные. Рабочий bars старой сборки перезаписал генерируемый `docs/BARS_INSTRUCTION.md`; копия восстановлена из изменения, канонический источник — `crates/bars-core/assets/BARS_INSTRUCTION.md`. Доставка новой инструкции установленной сборкой не проверена. Общие файлы менялись параллельно; коммит не создавался.

## Дальше

Обязательных действий по 3.5.2 не осталось. Ограничения: внешние документы не правятся, создание требует существующей папки, непредставимое в вики-ссылке новое имя отклоняется до перемещения.
