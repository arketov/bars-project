# Глобальный поиск 1.2.2 — реализация и границы проверки

## Сделано

Лупа над любой панелью, HTML dialog, один поиск и одно дерево во владении Workspace; работают и при закрытых панелях. Сохраняются запрос/область/режимы/раскрытие карточек и папок. Крестик/Escape возвращают фокус; документ закрывает слой после read, получает фокус и подсветку. Контекстное меню внутри dialog; согласие на переиндексацию закрывает слой. Файлы: `GlobalSearch.svelte`, `SearchSurface.svelte`, `Workspace.svelte`, `WorkspacePanel.svelte`, `ContextMenu.svelte`.

`app.svelte.ts`: snapshot параметров, очистка старой выдачи, защита поздних ответов, диагностика исходного запроса. Раскладка без текста SearchHit. Стенд дизайна теперь показывает продуктовый App. Обновлены [контракт](../../features/window/global-search-design.md), [устройство](../../features/window/implementation.md#общий-поиск-и-модальный-слой), [руководство](../../manual/search.md#поиск-поверх-любого-экрана), changelog и отметки готовых частей.

Проверки: svelte-check — 0 ошибок/предупреждений; 214 тестов / 30 файлов; production UI; ручной review lifecycle/маршрутов/snapshot/сериализации. [WebView2](native.json): обе темы, 1440/1024/760, общий DOM, Tab, контекстное меню, неизменная раскладка, сохранённые карточки/область, IPC-поиск → документ с подсветкой/фокусом. Изолированный WorkerHandler/FakeProvider; программная интеграция, не физическая приёмка или оценка модели.

NSIS `dist-installer/bars_0.1.0_x64-setup.exe` собран штатным скриптом с `-SkipNpmCi`; [размер/timestamp/SHA-256/MZ/PE и хеш UI](artifacts.json). Сборка всей текущей рабочей копии, включая прежний каркас; версия не менялась.

## Сложности

Serena недоступна. Нативные прогоны нашли преждевременное закрытие слоя из настроек и текст SearchHit в JSON: причины исправлены с регрессиями, финальная проба успешна. npm ci — EPERM native binding; offline-восстановление — ENOTCACHED. npm install --ignore-scripts --prefer-offline восстановил пакеты с неизменным lockfile; -SkipNpmCi проверяет npm ls. Чужие процессы сохранены. Vite предупреждает о размере чанка. Commit/push отсутствуют: прежний каркас и затронутые файлы уже содержали параллельные изменения; отдельный коммит слоя был бы неполным.
