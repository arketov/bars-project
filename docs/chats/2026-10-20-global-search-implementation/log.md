# Глобальный поиск 1.2.2 — находки

- Панели Dockview можно закрывать: поиск и дерево вынесены во владение Workspace, иначе слой зависел бы от открытых панелей. Первый дизайн отклонён; используется переработанная композиция настоящих компонентов.
- Нативный dialog блокирует внешнее контекстное меню; меню помещается в активный dialog, согласие на переиндексацию закрывает слой. Serena недоступна; bars impact не поддержал выбранный вход, проверены первичные контракты.
- Первая нативная проба нашла потерю фокуса при открытии документа из поиска поверх настроек: мост app.view закрывал слой раньше получения документа. Переход перенесён на результат read; маршрутизация документа отделена от открытия панели поиска, добавлена регрессия.
- Поиск через IPC подтвердил переход к документу; проверка JSON нашла текст SearchHit в раскладке после открытия карточки. Сериализация ограничена DocumentReference; регрессия проверяет отсутствие текста фрагмента.
- Сборка установщика: npm ci получил EPERM на native binding, offline-восстановление — ENOTCACHED. npm install --ignore-scripts --prefer-offline восстановил пакеты с неизменным lockfile; добавлен -SkipNpmCi с npm ls вместо остановки чужого процесса.
