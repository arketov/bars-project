# Этап 21 — передача сессии статистики MCP

## Сделано

IDEA-05 реализована в текущем main; [контракт и приёмка](../../features/window/mcp-statistics.md), мокап, OQ-88, запись в changelog и отметки готовности обновлены. `bars-protocol/server.rs` передаёт локальный ID соединения, `handler/mod.rs` учитывает MCP; `bars-worker/mcp_statistics.rs` хранит дневные SQLite-агрегаты. Tauri-команда и `McpStatisticsPage.svelte` показывают фильтры, итоги и сессии. Запросы и документы в статистике не хранятся.

Проверки: worker 4, MCP 9, protocol 51; UI 93/93 с одним worker; UI check/build, app check, worker/protocol clippy, diff check. Браузер на фикстурах: обе темы, фильтр проекта, пустая вкладка настроек. Снимки в `target/stage21/`. Собственный Vite остановлен, временный HTML в ui удалён.

## Не сделано

Нативная приёмка Tauri и установленного exe; установка не запрашивалась. Отдельного коммита нет: общие файлы содержат многочисленные параллельные изменения, они сохранены и не включены в чужой коммит.

## Сложности

Serena отсутствует в инструментах; документация изучена через bars, навигация по исходникам — доступными средствами. Cargo найден в `.cargo/bin`. Неиспользуемый импорт в bars-core — предупреждение параллельной работы. Первые общие UI-проверки застали незавершённое меню/удаление; итоговый прогон зелёный.
