# ui

Статус: требования · Спека: нет

## Назначение

Окно для человека: проекты, дерево документов, поиск, настройки, состояние индекса. Открывается из трея.

## Требования

- Окно открывается из трея; закрытие окна не останавливает воркер — `[требование Т-1]`.
- Добавление проекта в окне — `[требование Т-6]`.
- Чтение и правка настроек проекта в `.bars/` — `[требование Т-5]`.
- Дерево «модуль → папки → файлы» с галочками; поиск только по отмеченному; пустой выбор — весь проект — `[требование Т-14]`.
- Настройки моделей и чисел — `[требование Т-16]`, `[требование Т-17]`, `[требование Т-18]`.
- Пункт «Установить» в клиенты — `[требование Т-21]`.

## Идеи из образца

rag_explorer: интерфейс встроен в exe, есть демо-режим `-mock`, плашка «Черновик».
