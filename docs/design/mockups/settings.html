Инструкция для агента

Передайте агенту — он подключит bars сам.

bars установлен на этой машине.
bars-mcp: C:\Program Files\bars\bars-mcp.exe
bars-cli: C:\Program Files\bars\bars-cli.exe
Подключи bars к своему клиенту:
  bars-cli install --client claude-code
Не передавай --accept-model-change: это согласие пользователя.
