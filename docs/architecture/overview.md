## Потоки

**Поиск агента.** Клиент запускает `bars-mcp` → прокси проверяет, жив ли воркер, и при необходимости запускает `bars` и ждёт готовности (Т-2) → вызов идёт в воркер → воркер выбирает проект по cwd или по параметру (Т-15) → FTS5 + векторы → слияние → реранк, если включён (Т-12) → фрагменты с путём, модулем, разделом и оценкой (Т-13).

**Начало сессии.** Хук Claude Code или Codex вызывает CLI: зарегистрировать проект по cwd и проверить актуальность (Т-6, Т-10). Если в проекте ещё нет `.bars/`, он создаётся, а в корень документации кладётся `BARS_INSTRUCTION.md` (Т-8).

**Обновление индекса.** Источники изменений: слежение за файлами, старт воркера, хук, проверка раз в час (Т-10). Изменившийся документ режется заново; эмбеддинг запрашивается только для чанков с новым `embedded_text` (НФТ-1).
