# Архитектура bars — оглавление

Общее устройство bars, на которое опираются фичи. Решения по нему автор делегировал агенту.

- `stack.md` — стек: библиотеки, версии, инструменты сборки и почему они выбраны.
- `components.md` — исполняемые файлы, Cargo-крейты (включая `bars-graph`), интерфейс окна.
- `ipc.md` — локальный канал клиентов к воркеру, протокол, запуск воркера по требованию.
- `protocol.md` — методы канала (включая `graph_*`), исходный MCP-контекст, доступ окна, коды ошибок и согласие на переиндексацию.
- `worker.md` — воркер: запуск, очередь индексации, модели, сбор истории MCP и завершение.
- `secrets.md` — где лежат ключи провайдеров и как bars с ними обращается.
- `files.md` — `.bars` проекта и пользователя, индекс, история MCP, модели и настройки.
- `schema.md` — таблицы SQLite-индекса проекта и версия схемы.
- `vector-search.md` — точный перебор вместо ANN и когда это пересмотреть.
- `graph.md` — граф документов: крейт `bars-graph`, таблицы SQLite, снимки и действующее обновление; проект жизненного цикла 2.2.3 — состояния, планировщик, checkpoint и кэш (OQ-190).
