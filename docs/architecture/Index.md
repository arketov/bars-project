# Архитектура bars — оглавление

[← Оглавление раздела](../Index.md)

Общее устройство bars, на которое опираются фичи. Решения по нему автор делегировал агенту.

- [stack.md](stack.md) — стек: библиотеки, версии, инструменты сборки и почему они выбраны.
- [components.md](components.md) — исполняемые файлы, Cargo-крейты (включая `bars-graph`), интерфейс окна.
- [ipc.md](ipc.md) — локальный канал клиентов к воркеру, протокол, запуск воркера по требованию.
- [protocol.md](protocol.md) — методы канала (включая `graph_*`), исходный MCP-контекст, доступ окна, коды ошибок и согласие на переиндексацию.
- [worker.md](worker.md) — воркер: запуск, очередь индексации, модели, сбор истории MCP и завершение.
- [secrets.md](secrets.md) — где лежат ключи провайдеров и как bars с ними обращается.
- [files.md](files.md) — `.bars` проекта и пользователя, индекс, история MCP, модели и настройки.
- [schema.md](schema.md) — таблицы SQLite-индекса проекта и версия схемы.
- [vector-search.md](vector-search.md) — точный перебор вместо ANN и когда это пересмотреть.
- [graph.md](graph.md) — граф документов: крейт `bars-graph`, таблицы графа в SQLite, идентичность и снимки, построение и обновление.
