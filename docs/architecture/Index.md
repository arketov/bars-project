# Архитектура bars — оглавление

Общее устройство bars, на которое опираются фичи. Решения по нему автор делегировал агенту.

| Файл | Когда читать |
|---|---|
| `stack.md` | Библиотеки, версии, инструменты сборки и причины выбора |
| `components.md` | Исполняемые файлы, Cargo-крейты и интерфейс окна |
| `ipc.md` | Локальный канал клиентов к воркеру и запуск по требованию |
| `protocol.md` | Методы канала, MCP-контекст, доступ окна, ошибки и согласие на переиндексацию |
| `worker.md` | Запуск, очередь индексации, модели, история MCP и завершение |
| `window-updates.md` | Общий снимок и подписка окон: ревизии, нативная видимость, восстановление и пределы ресурсов; OQ-232 |
| `secrets.md` | Хранение ключей провайдеров и обращение с ними |
| `files.md` | Файлы проекта и пользователя, индекс, история MCP, модели и настройки |
| `schema.md` | Таблицы SQLite-индекса проекта и версия схемы |
| `vector-search.md` | Точный перебор вместо ANN и условия пересмотра |
| `graph.md` | Слои графа, снимки, обновление, состояния, планировщик, checkpoint и кэш |
