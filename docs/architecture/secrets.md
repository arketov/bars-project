# Ключи провайдеров bars

Решение агента: автор делегировал его 14-10-2026 (OQ-07).

## Где лежат ключи провайдеров

Ключи удалённых провайдеров embed и rerank хранятся в хранилище ОС через крейт `keyring`:

- Windows — Credential Manager;
- macOS — Keychain.

В настройках приложения записано только имя записи (например, `bars/openrouter`), сам ключ — никогда. В `.bars/` проекта ключей нет: эта папка может попасть в git (Т-5).

## Переопределение ключа через окружение

У провайдера в настройках может быть поле `api_key_env` — имя переменной окружения. Если переменная задана, её значение используется вместо ключа из хранилища ОС. Так можно запускать bars в CI или на машине без хранилища.

## Что bars никогда не делает с ключами

- не пишет ключ в лог, в ответ MCP, в вывод CLI и в сообщения об ошибках;
- не вшивает ключ в exe при сборке (урок 12);
- не показывает ключ целиком в окне: поле ключа только записывается и показывает последние 4 символа.
