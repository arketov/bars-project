# Стек

Статус: черновик. Язык и основные библиотеки зафиксированы требованием Т-3. Остальное — `[предложение]` из раздела «Решение» MAIN_IDEA.md, версии не выбраны.

## Зафиксировано

| Что | Выбор | Основание |
|---|---|---|
| Язык | Rust | `[требование Т-3]`, В-15, В-18 |
| Окно и трей | Tauri 2 (`TrayIconBuilder`); WebView2 на Windows, WKWebView на macOS | `[требование Т-3]` |
| Встроенный инференс | fastembed-rs (`TextEmbedding`, `TextRerank`, ONNX Runtime через `ort`; Qwen3 — через candle) | `[требование Т-3]` |
| Платформы | Windows, macOS | `[требование Т-4]` |
| Python | не используется | В-15 |

## Предложено

| Что | Вариант | Открытый вопрос |
|---|---|---|
| Индекс | SQLite, файл в `<проект>/.bars/` | `[требование Т-5]`; раскладка — OQ-05 |
| Полнотекстовый поиск | FTS5 | — |
| Векторный поиск | sqlite-vec (MIT/Apache) | перебор или ANN — OQ-11 |
| Внешний embed | OpenAI-совместимый `/v1/embeddings` | — |
| Внешний rerank | формат Cohere `/rerank` (routerai, llama-server) | — |
| Канал прокси/CLI → воркер | именованный канал или localhost | OQ-03 |
| Хранение ключей | хранилище ОС или переменные окружения | OQ-07 |
| UI окна | не выбран | OQ-15 |
| Раскладка крейтов | не выбрана | OQ-02 |

## Проверить на прототипе

- НФТ-2: поиск без реранка меньше 1 с на 5 000 чанков на CPU. Опора из образца — pgvector, 70–76 мс на 3 897 векторах размерности 4096; для SQLite замеров нет.
- Сборка sqlite-vec вместе с `rusqlite` на Windows и macOS.
- Размер `bars-mcp` без тяжёлых зависимостей (НФТ-3).
