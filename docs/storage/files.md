# Файлы bars на диске

bars хранит данные в двух местах: в `.bars` проекта и в `.bars` домашней папки пользователя.

## Папка .bars проекта

`<проект>/.bars/` — локальные рабочие файлы, как `.serena` или `.claude`. Уходит ли она в git, решает пользователь; bars `.gitignore` проекта не трогает (Т-5).

| Файл | Что в нём |
|---|---|
| `config.toml` | настройки проекта: корень документации (по умолчанию `docs`), переопределения числовых параметров поиска и нарезки |
| `index.sqlite` | индекс проекта ([schema.md](schema.md)) |
| `index.sqlite.new` | временный файл полной переиндексации; после неё исчезает |

Ключей и личных данных в `.bars` проекта нет.

## Папка .bars пользователя

`<домашняя папка>/.bars/` — общие файлы bars на этой машине.

| Путь | Что в нём |
|---|---|
| `settings.toml` | настройки приложения: embed и rerank модели, включён ли rerank, числовые параметры по умолчанию, порог и его пределы (Т-16…Т-18, Т-24), провайдеры без ключей |
| `projects.toml` | реестр зарегистрированных проектов: путь и время регистрации |
| `models/` | скачанные встроенные модели (Т-17) |
| `logs/` | логи воркера, по файлу на день, хранятся 14 дней |
| `run/bars.sock` | Unix-сокет воркера на macOS ([architecture/ipc.md](../architecture/ipc.md)) |

## Порядок настроек bars

Значение параметра берётся по первому найденному: вызов агента (в пределах Т-24 для порога) → `config.toml` проекта → `settings.toml` пользователя → заводское значение (Т-18).

## Регистрация проекта

Проект регистрируется хуком, в окне или через CLI (Т-6). При регистрации bars создаёт `.bars/config.toml`, если его нет, кладёт `BARS_INSTRUCTION.md` в корень документации (Т-8) и добавляет проект в `projects.toml`. Если `.bars/` уже есть (проект скопирован вместе с ней), используются её настройки. Если индекс в ней построен другой моделью, срабатывает Т-25.
