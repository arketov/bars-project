# storage

Статус: требования · Спека: нет

## Назначение

Хранит настройки проекта и его индекс в `<проект>/.bars/`.

## Требования

- Настройки и индекс в `.bars/` в корне проекта; индекс — отдельный SQLite-файл; окно читает и пишет настройки там же; `.gitignore` проекта не трогается — `[требование Т-5]`.
- Проект с готовым `.bars/` подхватывается без настройки — `[требование Т-6]`.
- Корень документации задаётся в настройках, по умолчанию `docs/` — `[требование Т-7]`.

## Предложено

FTS5 для полнотекстового поиска, sqlite-vec для векторов — `[предложение]`.

## Вопросы

OQ-05 (что из `.bars/` для git), OQ-06 (метаданные модели), OQ-11 (перебор или ANN). Ещё нужно выбрать формат настроек (TOML или JSON), схему БД и правила миграций при обновлении bars.
