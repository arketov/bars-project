# cli

Статус: требования · Спека: нет

## Назначение

Команды для человека в терминале и для хуков начала сессии.

## Требования

- Команды: установка в клиенты (Claude Code, Codex) и удаление; регистрация проекта; переиндексация; состояние; поиск — `[требование Т-20]`.
- Регистрация проекта по cwd из хука и проверка актуальности — `[требование Т-6]`, `[требование Т-10]`.
- Подключение к клиентам командой CLI — `[требование Т-21]`.
- Каждая команда даёт тот же результат, что то же действие в окне — критерий приёмки Т-20.

## Границы

Входит: разбор аргументов, вывод для человека и машинный вывод для хуков, обращение к воркеру.

Не входит: логика команд — её выполняет воркер.

## Вопросы

OQ-04 (отдельный exe или режим), OQ-03 (канал). Ещё нужно решить, ждёт ли хук индексации или возвращается сразу: от этого зависит время старта сессии.
