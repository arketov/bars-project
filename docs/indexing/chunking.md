# Нарезка документа на чанки

Как bars превращает Markdown-файл в чанки по требованию Т-23. Размеры по умолчанию — из Т-18: минимум 250, максимум 6000 символов. Размер считается в символах Unicode, а не в байтах.

## Разбор документа перед нарезкой

1. Файл читается как UTF-8; BOM отбрасывается. Переводы строк `CRLF` и `CR` приводятся к `LF` до любого разбора (урок 1 образца). Номера строк при этом не меняются: одна строка остаётся одной строкой.
2. Frontmatter в начале файла (`---` … `---`) отрезается. Из него берётся `title` документа (Т-11). Номера строк считаются по исходному файлу, вместе с frontmatter.
3. Заголовки — только ATX: строки `#`…`######` с пробелом после решёток. Строки внутри огороженных блоков кода (```` ``` ```` и `~~~`) заголовками не считаются. Setext-заголовки (текст с подчёркиванием `===` или `---`) bars не распознаёт; `BARS_INSTRUCTION.md` просит их не использовать.

## Дерево разделов документа

Документ превращается в дерево разделов. Раздел — заголовок и текст до следующего заголовка любого уровня. Родитель раздела — ближайший заголовок выше с меньшим уровнем. Текст до первого заголовка — раздел-вступление; его цепочка заголовков — `title` документа или имя файла. Имя файла без `.md` заменяет `title` и везде, где показывается заголовок документа, если в frontmatter его нет (Т-11).

Цепочка заголовков раздела — заголовки от корня до него через `/`: `Заголовок 1/Заголовок 2/Заголовок 3.1`. Решётки в цепочку не входят.

## Один раздел — один чанк

Каждый раздел даёт свой чанк. Текст чанка — собственный текст раздела, без подразделов. Если у раздела есть подразделы, в конец чанка добавляется список их заголовков (только прямых детей), как в образце автора:

```text
Заголовок 1/Заголовок 2/
В этом разделе уточнение бла бла
other headers:
### Заголовок 3.1
### Заголовок 3.2
```

## Большой раздел: дорезка по абзацам

Раздел длиннее максимума режется на несколько чанков с одной и той же цепочкой заголовков. Граница ищется в таком порядке:

1. пустая строка между абзацами;
2. конец строки;
3. жёсткий разрез по максимуму — только если одна строка длиннее максимума.

Огороженный блок кода и таблица не разрезаются посередине, если помещаются в максимум целиком. Блок длиннее максимума режется по строкам.

## Маленький раздел: склейка

Раздел, у которого собственный текст короче минимума, склеивается со следующим разделом документа (Т-23, OQ-20). У склеенного чанка цепочка заголовков и номер строки — от первого раздела, а заголовок второго остаётся в тексте строкой с решётками. Склейка повторяется, пока чанк не дорастёт до минимума или не упрётся в максимум. Последний маленький раздел документа приклеивается к предыдущему.

## Текст чанка для эмбеддинга

В эмбеддинг идёт весь чанк, кроме номера строки (Т-23, OQ-19):

```text
path: docs/test/test_file.md
Заголовок 1/Заголовок 2/Заголовок 3.1
<текст чанка>
```

Префикс документа модели, если он есть, добавляется перед этим текстом ([models/local-models.md](../models/local-models.md)). Номер первой и последней строки чанка хранится рядом как метаданные и показывается в выдаче.

Из этого следует: правка внутри раздела меняет только его чанки; вставка строк выше сдвигает номера строк, но не текст для эмбеддинга, поэтому векторы переиспользуются (НФТ-1). Переименование файла меняет `path:` и требует нового эмбеддинга чанков этого файла.
