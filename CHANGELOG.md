# Изменения bars

## Unreleased

- Документы открываются из дерева без поиска; меню документа в дереве и выдаче позволяет выбрать редактор, показать файл в Проводнике, скопировать абсолютный путь и поставить проверку индекса файла (IDEA-02, IDEA-09).

- Embed и rerank независимо выбирают CPU или GPU с показом устройства; ошибки отдельных документов больше не прерывают всю индексацию, а неполный rebuild сохраняет старый индекс (IDEA-01, OQ-62, OQ-80).
- Инструкция и skills bars явно описывают размещение требований, фич, исследований, решений, багов, пожеланий и журналов; учитывают правила проекта. Реестры багов и идей bars перенесены в docs/backlog/ (IDEA-08).
- Тестовые воркеры больше не меняют пользовательские MCP, хуки и skills: доступ к профилю клиента включается явно приложением, тесты установки используют временные каталоги (ISS-12).
- bars автоматически обновляет MCP, хуки и skills в уже подключённых Claude Code и Codex; сохраняет чужие записи, не восстанавливает удалённую интеграцию и напоминает `/hooks` только при изменении хука Codex (IDEA-10).
