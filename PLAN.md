# План

Блок → этап (одна фича) → шаги. Шаг — одна строка: вид, что сделать, куда результат. Выполненный шаг удаляется из плана; итог и доказательства — в handoff сессии в `docs/chats/`. Пункты добавляются и меняются только по согласованию с автором. Сессия, сделавшая шаг, коммитит свою работу и помечает шаг «✅ … — сделано»; пока сборки на ноутбуке автора запрещены, — с припиской «не проверено сборкой». Помеченный шаг удаляется после проверки и согласия автора.

Отдельных шагов приёмки нет: реализация включает тесты по критериям приёмки docs/MAIN_IDEA.md и ТЗ фичи, проверку в собранном окне и в установленной сборке (установка — по согласованию с автором), правку документов фичи и руководства.

План переписан 03-11-2026 по раунду 33: главное — тихий фон и один понятный поиск, проверенный бенчем; работа по графу, окну, MCP и моделям, начатая раньше, отложена. Выполненные шаги прежнего плана — в handoff сессий `docs/chats/` до 03-11-2026.
