# bars

Локальная база знаний и RAG по Markdown-документации проектов. Один и тот же индекс доступен человеку через окно, агенту через MCP и в терминале через CLI. Ответ LLM поверх найденного bars не генерирует.

Направление с 19-10-2026: bars становится системой управления знаниями по образцу Obsidian. В окне появятся редактор Markdown, ссылки между документами с индексом ссылок, файл папки `index.md`, создание файлов и папок, аудиты знаний (битые ссылки, дубли, противоречия, новые темы) и создание проекта. Требования Т-29…Т-42 зафиксированы в [MAIN_IDEA.md](docs/MAIN_IDEA.md), реализации пока нет. Постановка и решения — [docs/features/knowledge-base/](docs/features/knowledge-base/Index.md).

Название рабочее.

## Стадия

Требования зафиксированы 14-10-2026. Реализованы ядро, воркер, MCP/CLI, интеграции клиентов, модели, окно с треем и поставка Windows; открытые проверки перечислены в [состоянии проекта](docs/project-status.md). GraphRAG реализован частично, полная смысловая и нативная приёмка не завершена.

## Коротко о составе

- **bars** — общий воркер с окном в трее (Rust + Tauri). Держит индексы всех зарегистрированных проектов.
- **bars-mcp** — маленький stdio-прокси для агентских клиентов. Если воркер не запущен, прокси его поднимает.
- **bars-cli** — отдельный exe: регистрация проекта, переиндексация, состояние, поиск, установка в Claude Code, Codex и Kimi Code.
- **`<проект>/.bars/`** — настройки проекта и его SQLite-индекс (FTS5 + векторы).

Платформы: Windows и macOS.
