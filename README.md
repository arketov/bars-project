# bars

Локальный RAG по Markdown-документации проектов. Один и тот же индекс доступен человеку через окно, агенту через MCP и в терминале через CLI. Только поиск: ответ LLM поверх найденного bars не генерирует.

Название рабочее.

## Стадия

Требования зафиксированы 14-10-2026. Реализованы ядро, воркер, MCP/CLI, интеграции клиентов, модели, окно с треем и поставка Windows; открытые проверки перечислены в [состоянии проекта](docs/project-status.md). GraphRAG реализован частично, полная смысловая и нативная приёмка не завершена.

## Коротко о составе

- **bars** — общий воркер с окном в трее (Rust + Tauri). Держит индексы всех зарегистрированных проектов.
- **bars-mcp** — маленький stdio-прокси для агентских клиентов. Если воркер не запущен, прокси его поднимает.
- **bars-cli** — отдельный exe: регистрация проекта, переиндексация, состояние, поиск, установка в Claude Code и Codex.
- **`<проект>/.bars/`** — настройки проекта и его SQLite-индекс (FTS5 + векторы).

Платформы: Windows и macOS.
